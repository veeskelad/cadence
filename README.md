# Cadence

Cadence превращает агента в Claude Code или Codex в монтажёра, моушн-дизайнера и звукорежиссёра. Говоришь словами, что нужно, а агент режет видео, рисует графику кодом, ставит эффекты и звук. Всё считается у тебя на компьютере и бесплатно.

Сайт: https://veeskelad.github.io/cadence/

## Установка

**Claude Code: плагином, одной командой.**

```bash
claude plugin install cadence --marketplace veeskelad/cadence
```

Чтобы новые версии приходили сами, один раз включи автообновление: `/plugin` → Marketplaces → cadence. Твои проекты, стиль и правки агент хранит отдельно от плагина, обновление их не трогает.

**Codex или без плагина: папкой.** Открой пустую папку в агенте и отправь ему промпт установки со страницы сайта, блок «Забери себе». Агент сам скачает выпуск, сверит каждый файл и скажет, какую папку открыть. Если разрешишь, раз в день он сам проверит, не вышла ли новая версия, и по слову «обнови» поставит её рядом со старой.

После установки просто поздоровайся с агентом: он расскажет, что умеет, и предложит, с чего начать.

## Что умеет

- **Монтаж:** вырезает паузы, собирает ролик из лучших дублей, делает субтитры, сводит звук с петлички, подкладывает музыку, которая притихает под голос. Из длинного видео без речи собирает короткий хайлайт под ритм трека.
- **Моушн кодом:** заставки, титры, 3D-сцены, частицы, шоурил одним пролётом камеры, ролик в бит своего трека.
- **Эффекты и переходы:** speed ramp, whip pan, crash zoom, вспышка, match cut и сотни приёмов из кино. Для DaVinci Resolve: свои шаблоны переходов и проверенные рецепты.
- **Звук:** эффекты под каждое событие в кадре, музыка остаётся главной, громкость проверяется числом.
- **Свой стиль:** цвета и шрифты под твой бренд. Если не знаешь, какой стиль твой, агент покажет варианты прямо на твоих кадрах. Дизайн-систем может быть сколько угодно.
- **Генерации:** агент готовит сценарий кадров, промпты и проверку результата для твоего сервиса. Сам набор ничего не генерирует и ключей не просит.
- **Проверка перед публикацией:** формат, громкость, вспышки на один кадр, текст в безопасных полях площадки, кадры для обложки.

## Что в этом репозитории

| Где | Что |
|---|---|
| `index.html` | страница сайта |
| `.claude-plugin/marketplace.json` | каталог для Claude Code: отсюда ставится плагин |
| `plugin/` | текущая версия Cadence, которую ставит плагин |
| `current/manifest.json` | указатель на текущий выпуск: по нему промпт установки и проверка обновлений узнают, что скачать |
| `releases/<версия>/` | архив каждого выпуска (`cadence-<версия>.zip`) и запись о том, как его проверили (`VERIFICATION.md`) |
| `patches/` | исправления и заметки к старым выпускам |
| `tests/`, `tools/` | проверки страницы, указателя и промпта установки |

Выпуски не перезаписываются: новая версия кладётся в свою папку рядом со старыми, а указатель переключается на неё последним шагом, после проверки установки и обновления.

## Версии

Текущая версия записана в `current/manifest.json` и в `plugin/.claude-plugin/plugin.json`. Что нового в каждой версии, смотри в `plugin/CHANGELOG.md`.
