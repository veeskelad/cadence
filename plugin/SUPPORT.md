# Поддержка

Набор бесплатный и идёт «как есть». Если что-то не работает:

1. Спроси агента: «что сломалось и какой одной вещи не хватает?». Он назовёт шаг и команду.
2. Проверь движок: `npm --prefix engine run doctor`.
3. Пришли автору:
   - текст ошибки без ключей, имени пользователя и путей домашней папки;
   - версию из `CHANGELOG.md`;
   - какой навык работал.

Канал связи указан на странице, откуда ты скачал набор.
