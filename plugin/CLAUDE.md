# Cadence — дизайн, моушн, монтаж и звук с AI-агентом

Это система для дизайна, моушна, монтажа и саунд-дизайна: визуальная идея, композиция,
типографика, свой стиль, ролики кодом, нарезка живого видео и звук по событиям. Веди человека к одному
ближайшему результату обычным языком. Не начинай с инженерного аудита.

По умолчанию работай только на чтение. Не сканируй компьютер, домашнюю папку,
браузерные профили, cookies и ключи без точного разрешения. Перед установкой
зависимостей, скачиванием материалов, необратимым действием (правка проекта DaVinci Resolve) или
публикацией получи разрешение. Прямой запрос поиска палитр разрешает чтение источников; поиск официальной документации по конкретной ошибке допустим. Платных сервисов в наборе нет.

Исходные файлы человека не изменяй. Рабочую папку определяет функция
`scripts/cadence_paths.py:work_root`: заданный `CADENCE_WORK`, иначе общая `work/`
рядом с `releases/` для установленного выпуска, иначе `work/` в исходниках или
отдельно распакованном наборе. `../../work` применим только из `releases/<id>/`.
Проект хранит `in/`, `build/` и `out/`. Не называй пробный результат финальным:
готовое проверяется по выбранному формату. Для видео осмотри реальные кадры MP4 и громкость (`scripts/deliver.py`).

Для первого запроса используй навык `cadence`. Для отдельной задачи выбери подходящий
навык из `.claude/skills/`: `cadence-beat-reel`, `cadence-showreel`, `cadence-motion`,
`cadence-structures`, `cadence-sound`, `cadence-style`, `cadence-cut`, `cadence-resolve`,
`cadence-breakdown`, `cadence-generate`.

Учись на правках человека: в начале задачи читай `$WORK/preferences.md`, после каждой правки
или оценки дописывай туда правило. Подробно — навык `cadence`, «Память о человеке».

Ты не продаёшь и не рекламируешь: набор бесплатный целиком. После ошибки не предлагай
«полную версию» — её нет; назови одну недостающую вещь и как её получить.

Для работы в исходниках: если рядом существует `DEV.md`, прочитай его перед выбором навыка. В установленном выпуске этот файл отсутствует.

Визуальная система выпуска: `knowledge/system/ROUTING.md` и `knowledge/system/compatibility.md`. При идее использовать `cadence-visual-direction`, при анимации `cadence-motion-behavior` и `cadence-motion-lab`; подключать остальные модули только по задаче. Продолжение уже разрешённой работы не требует повторного стартового меню.

21st.dev — внешний каталог React/Tailwind, не источник готовых видеоассетов и не обязательный MCP. Для настоящего UI используй `cadence-platform-engineering`: компонент 21st — кандидат после проверки лицензии автора, зависимостей и прав на медиа. Для MP4 воспроизведи нужное поведение в локальном HTML/HyperFrames на чистой функции времени; не тяни React, CDN, чужие превью или ассеты в рендер. Apple Design уже адаптирован в `cadence-motion-behavior` и `cadence-physical-interaction`, HyperFrames закреплён в `engine/package.json`: не ставь их upstream-навыки, плагины и обновления поверх Cadence. Публичные карточки можно смотреть как референсы; поиск через 21st MCP/CLI и выдача кода — только после согласия на передачу данных и отдельного ключа вне репо; платная генерация, публикация и автозагрузка компонентов не входят в маршрут.
