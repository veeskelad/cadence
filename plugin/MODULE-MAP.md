# Модули и решения человека

| Модуль | Навык | Инструменты | Решение человека |
|---|---|---|---|
| Ролик в бит | `cadence-beat-reel` | движок, ffmpeg, Python | трек, хук, знак; согласовать план; принять или переделать |
| Ролик в бит «одна форма» | `cadence-beat-reel`, шаблон `one-shape` | движок, ffmpeg, Python | трек, хук, знак; какая форма — кадр на удар или одна форма |
| Шоурил одним дублем | `cadence-showreel` | движок, ffmpeg, Python | трек, две работы и их отрезки, тексты; проверка стыков |
| Структуры роликов | `cadence-structures` | движок | какая форма; свои экраны и знак |
| Код-эффекты и текст | `cadence-motion` | движок | эффект, слова, формат 9:16 или 16:9 |
| Звук | `cadence-sound` | ffmpeg, `sounds/` | какие события озвучить; громкость эффектов |
| Стиль | `cadence-style` | — | цвета и шрифты; выбрать стиль вместе (лист вариантов на своём кадре); утвердить пак |
| Нарезка живого видео | `cadence-cut` | ffmpeg, Whisper (по желанию) | порог пауз; вшивать ли субтитры; музыка |

| Хайлайт длинного видео без речи | `scripts/highlight_cut.py`, `cadence-cut` | ffmpeg, numpy | длина, обязательные кадры, музыка |
| Голос и музыка | `scripts/voice_music_mix.py`, `cadence-sound` | ffmpeg | трек, где дроп, громкость подложки |
| Уровни эффектов | `skills/cadence-sound/scripts/level_check.py`, `cue_mix.py`, `sfx_probe.py` | ffmpeg, numpy | своя библиотека звуков |
| Финальная проверка ролика | `scripts/frame_flashes.py`, `scripts/safe_zone_check.py`, `cadence-motion` | ffmpeg, numpy | обложка; принять ролик |
| Сцены по словам | `scripts/word_anchors.py`, шаблон `kinetic-explainer` | Python | какие слова держат сцены |
| Сборка на экране, экран в фото устройства | `cadence-structures` | движок | свой экран и фото своего устройства |
| Шаблоны переходов Resolve | `scripts/resolve_transition_template.py`, `cadence-resolve` | DaVinci Resolve (по желанию) | ставить ли шаблон в Resolve |
| DaVinci Resolve | `cadence-resolve` | DaVinci Resolve (по желанию) | разрешить правку копии проекта |
| Разбор референса | `cadence-breakdown` | ffmpeg | какой ролик разобрать; что повторять |
| Генерация (подготовка) | `cadence-generate` | сервис генерации человека | генерировать ли; какой сервис; бюджет; выбрать кандидата |
| Новый проект | `scripts/new_project.py` | Python | имя проекта, какие файлы скопировать |
| Кино-эффекты на живом видео | `scripts/video_fx.py` | ffmpeg, OpenCV, Pillow | выбрать момент и точку интереса, согласовать результат |
| Проверка перед публикацией | `scripts/check_reel.py`, `guides/BEFORE-POSTING.md` | ffmpeg | смотреть ролик и решать о публикации |
| Проверка Resolve | `scripts/resolve_check.py` | DaVinci Resolve (по желанию) | — (только чтение) |

## Заменяемость

Движок рендера один — HyperFrames (`engine/`). Субтитры — openai-whisper ↔
faster-whisper ↔ бинарь `whisper`. Монтаж — DaVinci Resolve ↔ любой редактор, который читает
EDL. Правила при замене не меняются:
- исходники не трогать;
- результат — в новую папку;
- сеть и необратимое — только с согласия;
- готовое проверять по кадрам из MP4.

## Визуальная система

«Найди современную палитру под идею», «Собери свой пак по референсу», «Покажи несколько вариантов композиции», «Сделай преобразование карточки в результат», «Проверь длинный текст и состояния интерфейса». Маршруты и самостоятельные знания — [ROUTING.md](knowledge/system/ROUTING.md). Дополнительные модули применяются по задаче и сохраняют текущий пак, если его смена не заказана.
