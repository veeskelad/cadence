# Перед публикацией

Две проверки: техническую делает скрипт, смысловую — ты глазами. Публикуешь сам: агент
ролики не выкладывает.

## 1. Скрипт — около минуты

```bash
python3 scripts/check_reel.py work/<проект>/out/reel.mp4
```

Только читает файл и пишет по строке на каждую проверку: «ок», «внимание» или «стоп».

| Строка | «Стоп» или «внимание» — что делать |
|---|---|
| пик выше −1 dBTP | `python3 scripts/deliver.py <ролик> --out <новый файл>` — убавит одним шагом громкости, без лимитера |
| громкость ниже −17 LUFS | тот же `deliver.py`: поднимет, насколько позволяет пик |
| кадр не 1080×1920 / 1920×1080 | пересобрать с нужным `--format`; площадка иначе пережмёт и обрежет |
| кодек не `yuv420p` | пересобрать рендер движком Cadence: он пишет `yuv420p` |
| чёрные кадры, замершие куски | посмотреть это место: задумано (затемнение, пауза) или сбой |
| тишина в начале | первая секунда решает, листают или нет — звук с первого кадра |

## 2. Глазами — 3–5 минут

Смотри ролик **на телефоне**, со звуком и без.

- Первая секунда: понятно, о чём ролик, без звука?
- Текст: каждую надпись успеваешь прочитать дважды; нет опечаток; длинные слова не обрезаны.
- Безопасные поля: текст не уходит под подпись, кнопки и ник площадки (снизу ~320 px,
  сверху ~160 px в 9:16).
- Звук: эффекты слышны, но тише музыки; голос разборчив.
- Вспышки — не чаще трёх в секунду.
- Обложка: какой кадр будет в сетке профиля.

## 3. Права

- Музыка: свой трек или из библиотеки площадки. Чужой трек из интернета — риск блокировки
  звука или ролика.
- Чужие видео и картинки в кадре — только с разрешения автора.
- Звуки и демо-бит Cadence можно использовать свободно (MIT).

Технический «ок» — не разрешение на публикацию. Решение — твоё.
