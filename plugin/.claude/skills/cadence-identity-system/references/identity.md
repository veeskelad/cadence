# Построение системы идентичности

## Карточка основания

```text
Имя и назначение:
Для кого и в каком контексте:
Отличие, подтверждённое материалом:
Ожидаемое впечатление:
Уже утверждено:
Недопустимые сходства и смысловые ассоциации:
Носители и минимальный размер знака:
Центральная идея:
```

Начать с действия или отношения, которое отличает предмет: собирает разрозненное, сохраняет порядок, делает связь видимой. Выбрать один смысл, который знак сможет выражать геометрией. Не переводить каждое существительное в набор случайных пиктограмм.

## Формообразование

Выбрать подходящий путь:
- буквенная форма: отличительный разрез/соединение буквы несёт смысл, а не только начальную букву;
- форма действия: движение, соединение, разворот, граница или раскрытие сводятся к статическому силуэту;
- смысловое соединение: две узнаваемые идеи используют общий контур; убрать часть, без которой идея остаётся;
- внутренняя пустота: отрицательное пространство создаёт второй смысл, не исчезающий при уменьшении;
- модуль: повторение ограниченного геометрического набора создаёт устойчивую семью.

Для каждого кандидата записать связь формы с основанием, способ уменьшения и отличия от распространённых знаков. Существующий логотип не переделывать в процессе поиска стиля. Варианты создавать только в объёме, который разрешает сравнить реальные различия, без обязательной квоты.

## Перенос на носители

Составить список нужных применений с функцией каждого: знак отдельно; знак с названием; цветовые роли; типографика; реальный интерфейс или условная схема; предмет/упаковка; изображение кампании; детали компонентов. Не включать лишний физический носитель, если бренд существует только в цифровом продукте.

Общий обзор строить из неравных по важности областей: крупный знак, практическое применение, атмосфера и системные детали. Каждая область имеет подпись только если она необходима. Читаемость важнее заполненной сетки. Для сложной области сделать отдельный полноразмерный лист, а обзор использовать для связи между листами.

```text
application_id:
purpose:
asset_or_rule:
frame_ratio:
main_bounds:
text_exact:
identity_invariants:
allowed_variation:
acceptance:
```

Палитру собирать по функциям пака: фон, поверхность, основной/второстепенный текст, сигнал, линии. Один и тот же сигнал не меняет значения между носителями. Шрифты выбирать из доступных с нужными глифами; недоступную гарнитуру не обещать. Для фотографии описать предмет, кадрирование, свет и поверхность; изображения существующих работ не перекрашивать.

## Brief изображения

Передать цель носителя, центральную идею, точный материал/надписи, композиционные bounds, роли цвета/шрифтов, направление света, обязательные признаки, запрещённые изменения и критерии. Если генератор не воспроизводит текст/знак точно, оставить место и добавить утверждённые файлы при компоновке. Условный экран помечать как концепт; настоящий продукт показывать собственным материалом.

Не требовать изображения на каждый пустой блок. Использовать существующие разрешённые материалы прежде генерации. Число изображений определяется носителями, читаемостью и разрешённым объёмом, а не престижностью задачи.

## Проверка

Сопоставить знак на малом/крупном масштабе и в монохроме; убедиться в целостности внутренних просветов. Проверить единые варианты знака, палитру, глифы, безопасные поля, согласованность материалов и реальность применений. Для Reels/TikTok важное внутри x0.06W…0.82W/y0.15H…0.75H; фон может выходить. Проверить накладки UI и кропы обложки, а видео — dimensions, SAR/DAR, rotation. Протоколировать конкретные дефекты; изменять их причины, сохраняя работающие решения.
