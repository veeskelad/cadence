# Голос и музыка: когда главное — речь

Ролик, где человек говорит в камеру, устроен наоборот по сравнению с роликом в бит: здесь ведёт голос, а музыка слышна, но не спорит с ним. Скрипт — `scripts/voice_music_mix.py`, всё считается на этой машине через `ffmpeg`. Исходники не меняются: каждый шаг пишет новый файл и JSON с цифрами рядом.

Быстрый вариант уже есть в `scripts/audio_sync.py --music ... --duck` (раздел 7 `cadence-cut`): одна команда, трек на 10 дБ тише голоса. `voice_music_mix.py` — для аккуратной работы: голос готовится отдельно, подложка ставится по абсолютному уровню, дроп трека садится на финальную фразу.

## 1. Голос

```bash
python3 scripts/voice_music_mix.py measure "$WORK"/<проект>/in/<исходник>.mp4
python3 scripts/voice_music_mix.py voice "$WORK"/<проект>/out/<нарезка>.wav
```

Цепочка: срез низа 80 Гц → шумодав (только с `--denoise`) → замер → одно усиление к −14 LUFS.

- **Без лимитера.** Скрипт сначала меряет громкость и истинный пик, потом ставит одно усиление: столько, сколько нужно до −14, но не больше, чем позволяет пик −1 dBTP. Если в голосе резкие пики (смех, хлопок, «п» в микрофон), до −14 не дотянуть — голос выйдет тише, и скрипт напишет «Тише цели». Это честнее, чем прижать пики: прижатый голос звучит плоско.
- **Шумодав — только на шумной записи.** Сначала `measure` на исходнике **до** нарезки пауз: в нарезке пауз почти нет, и оценка шума получится по тихой речи. Шум тише −50 dBFS — запись чистая, шумодав только добавит «булькающих» артефактов, и скрипт откажет. Шум громче — `voice ... --denoise --noise-floor <число из measure>`.
- Вход лучше брать без сжатия (WAV из монтажа), а не звук из готового MP4: на каждом сжатии теряется качество.

## 2. Дроп трека на финальную фразу

Трек не обязательно начинать с нуля. Сильнее, когда дроп (самое резкое раскрытие трека) приходится на финальную фразу: перед ней музыка подводит, на ней раскрывается.

```bash
python3 scripts/voice_music_mix.py find-drop "$WORK"/<проект>/in/<трек>.mp3
```

Скрипт показывает три места, где громкость растёт резче всего. Это кандидаты, а не ответ — послушать каждый. Доли, брейки и возврат бита точнее находит `scripts/track_structure.py`.

Начало финальной фразы в ролике — по словам с временем: `scripts/captions_whisper.py` пишет `<имя>.words.json`. Брать время из файла нарезки, а не исходника.

Сдвиг трека = время дропа в треке − начало финальной фразы в ролике.

- Сдвиг больше нуля — трек берётся с середины.
- Сдвиг меньше нуля — в начале ролика тишина, трек входит позже.
- Трека не хватает до конца ролика — скрипт откажет и покажет цифры: взять другой кандидат или другой трек.

## 3. Подложка

```bash
python3 scripts/voice_music_mix.py mix --voice "$WORK"/<проект>/out/<нарезка>-voice.wav \
  --music "$WORK"/<проект>/in/<трек>.mp3 --drop-at 42.3 --land-at 11.8
```

Уровень музыки задаётся не процентом громкости (он ничего не говорит: треки сведены по-разному), а разносом с голосом.

| Что | Значение |
|---|---|
| подложка | −24 LUFS при голосе −14 (разнос 10 дБ до приглушения) |
| приглушение по голосу | ratio 3, threshold 0.10, attack 20 мс, release 380 мс |
| что получается | голос над приглушённой музыкой примерно на 15 дБ: музыка слышна, голос не вязнет |
| громче / тише | `--music-lufs -22` (разнос ≈13 дБ) / `--music-lufs -26` (≈17 дБ) |
| итог | −14 LUFS, истинный пик не выше −1 dBTP, одно усиление без лимитера |

- **Приглушение обязательно.** После нарезки пауз речь идёт сплошняком: ровная подложка либо давит голос, либо её не слышно. Пока человек говорит, музыка уходит вниз, в паузах возвращается.
- **Уровень идёт за голосом.** Если голос после шага 1 вышел тише −14 (упёрся в пик), подложка опускается на столько же, и ключ приглушения тоже: разнос и работа приглушения не меняются. `--music-lufs` задаёт уровень подложки напрямую.
- **Длина.** Приглушение в `ffmpeg` отдаёт звук чуть короче, чем получило, — так незаметно пропадает финальный удар. Скрипт дополняет входы тишиной, обрезает итог ровно по длине голоса и сверяет длину; разошлось больше чем на кадр — файл удаляется, и скрипт говорит об этом.
- В JSON: откуда взят трек, уровень подложки, разнос голоса и приглушённой музыки (`separation_db`, по всей дорожке — ориентир, а не замер по фразам), итоговые LUFS и пик.

Слушать решает человек: тихая громкость, наушники, телефон. Если на телефоне музыку не слышно — `--music-lufs -22`; если голос тонет — `-26`.

## 4. Мастер

```bash
python3 scripts/voice_music_mix.py master --video "$WORK"/<проект>/out/render.mp4 \
  --audio "$WORK"/<проект>/out/<нарезка>-voice-mix.wav
```

Микс ставится в готовый рендер. Картинка **копируется без перекодирования**: она уже финальная, второй проход только испортит её. Звук — AAC 256k, 48 кГц, `+faststart` (плеер стартует сразу). Кодек AAC сам поднимает пик на 0,3–0,6 дБ, поэтому скрипт меряет готовый файл и, если пик вылез выше −1 dBTP, собирает заново чуть тише. Если длины видео и звука не совпадают, мастер обрезается по короткому, и скрипт об этом пишет.

После мастера `deliver.py` не нужен: громкость уже выставлена.
