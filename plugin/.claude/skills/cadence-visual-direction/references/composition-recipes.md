# Воспроизводимые конструкции визуальной композиции

Вход: content_ids с реальным материалом, W/H, доступный прямоугольник A=(x,y,w,h), роли пакета и события. Для Reels/TikTok A лежит внутри x0.06W…0.82W/y0.15H…0.75H и фактического UI. Все итоговые bounds сначала измерить после fonts/assets; вычисления ниже используют локальные координаты A. Не применять весь набор в одной сцене. Движение считать от t; event-driven preview получает явный progress; обычный CSS timer не является видеочасами.

## Сетка и группа

**Главный плюс вспомогательные:** content героя имеет наибольшую область; остальное делит отдельную полосу. Для r доли героя и gap g: widthHero=r×(w−g), widthSupport=(1−r)×(w−g). В узком формате полосы становятся вертикальными с одинаковым порядком чтения. Проверка: все items существуют, пояснение не потеряло кегль.

**Неравные модули:** задать явную occupancy matrix по content_id и spans; суммарный gap учитывается один раз на границу. Отсутствие content_id означает намеренную пустую область только если она записана; не дополнять фиктивными карточками. Проверка: нет случайной дыры и перестановки смыслового порядка.

**Разновысокая галерея:** ширина колонок равна, высота каждого медиа из его aspect ratio, очередной элемент ставится в предусмотренную сценарием колонку на текущую нижнюю границу+gap. Смысловой порядок не заменять shortest-column без разрешения. Проверка: стабильные axes и crop, текст не оказывается вне A.

**Две части:** задать границу, одинаковые оси/масштабы сравниваемого, локальные clip. При противоположном ходе yA=y0+d×p,yB=y0−d×p; устойчивый кадр сохраняет названия обеих частей. Проверка: движение не создаёт ложное превосходство.

## Отбор и раскрытие

**Стек:** задать final bounds слоёв и owner трансформа каждого; при следующем событии предыдущий слой меняет scale/opacity до согласованного значения, сохраняя край/название. Не закрывать evidence. Проверка: идентичность видна до/после; порядок layers детерминирован.

**Лента обзора:** track содержит измеренные widths+gaps, X(p)=−p×max(0,trackWidth−viewportWidth). Для цикла длина L измеряется после fonts; X(t)=−((v×t) mod L), дублирование только декоративного обзорного ряда, не ложного количества. При L=0 статично. Для нужного чтения остановить на объекте.

**Расширяемые полосы:** inactive widths заданы, activeWidth=w−sum(inactiveWidths)−totalGaps. Между состояниями интерполировать widths, медиа crop отдельно, labels не растягивать. Для настоящего hover обработать keyboard/touch альтернативу; в видео активный ID из события. Проверка: activeWidth положительна, чтение возможно.

**Фокусная галерея:** расстояние d_i=i−activeIndex; position_i=origin+d_i×spacing, yaw_i=clamp(d_i×angle,−limit,limit), scale_i уменьшается по abs(d_i). Центральный объект крупнейший, боковые сохраняют узнаваемость. Проверка: перспектива не ломает текст, clipping не скрывает нужный material.

**Панорама:** позиции медиа на цилиндре/дуге θ_i, x=Rsinθ,z=Rcosθ; camera yaw из p. Реальные captions не наносить на дальний невидимый слой. При нехватке качества заменить плоской фокусной галереей. Проверка: frame selection видно, seed/time воспроизводимы.

**Большое поле:** content plane ограничен реальными bounds; cameraOffset ограничить доступными диапазонами. Для действия просмотра показать путь к заранее видимой цели; при drag preview связать pointer с локальными координатами. Проверка: важное не потеряно в бесконечном декоре.

## Поверхность и реакция

**Наклон:** normalized pointer/сценарная точка q∈[−1,1]² задаёт малый yaw/pitch; вращается shell, text защищён либо амплитуда ограничена. Возврат описан отдельной функцией. Проверка: диагональный край не режет A.

**Локальный свет края:** highlight центр q, свет действует только на stroke/surface через clipped gradient. Если это реакция, q принадлежит событию; без действия оставить стабильным. Проверка: text contrast не зависит от блика.

**Переливающийся материал:** reflected angle зависит от нормали поверхности и light direction; палитра ограничена material-паком, не случайная rainbow. Использовать только собственный декоративный объект. Проверка: маленький блик не заменяет основной signal.

**Раскрытие из объекта:** исходный и конечный bounds связаны общей оболочкой; frame от общей функции progress, text отдельно появляется после появления области. Это container-morph, а не новый independent clock. Проверка: identity сохранена, символ не растянут.

**Ответ на нажатие:** причина в p0, лёгкое смещение/scale shell, затем конечное состояние; визуальная реакция начинается на событии. Для волны radius=rMax×p,alpha=(1−p)×a, clipped inside component. Проверка: реакция не скрывает label.

**Меню вокруг вызова:** item_i расположен origin+[Rcosθ_i,Rsinθ_i], радиус R(p) из easing; angles и order заданы сценарием, подписи вне кривой. Для жидкой связи между shapes использовать union/маску, не blur текста. Проверка: touch/focus только в настоящем preview; MP4 показывает нужные состояния.

**Магнитная реакция:** displacement=limitedGain×(q−center), ограничить maxDistance, icon может иметь меньший gain. Return по motion-behavior. Проверка: объект не убегает от нужного действия; в видео q задано, а не зависит от реальной мыши.

**След изображения:** на известных событиях e_i появляется asset_i; age=t−e_i, alpha и scale из life(age), seed фиксирован. Следы удаляются по конечной жизни, не множатся каждый render. Проверка: след не содержит неизвестных/несогласованных материалов.

## Типографика и маска

**Текстовое окно:** text alpha-mask применяется к отдельному media layer; под ним устойчивый контрастный фон, перед ним нужное пояснение. Проверка: глифы читаются в худшем состоянии медиа.

**Контур → заливка:** один и тот же outline path получает stroke, fillAlpha=p; не менять glyph metrics. Для stroke-progress dashoffset=(1−p)×pathLength. Проверка: край не мерцает и исходный шрифт загружен.

**Раскрытие знаков:** конечный текст неизменен; промежуточные глифы выбираются сидированно по индексу/фазе, каждый знак имеет stopEvent. Не scramble факты в момент чтения. Проверка: full final text появляется и получает hold.

**Буквы по дуге:** измеренные glyph advances суммировать по длине path; midpoint каждой буквы определяет position и tangent rotation. Ограничить curve так, чтобы важное оставалось читаемым. Проверка: не отзеркалить/перевернуть чтение.

**Слова с медиа-вставкой:** medиа имеет фиксированный inline-box, высоту и baseline; wrap по измеренной строке. В узком кадре вынести asset отдельным блоком, не сломать фразу. Проверка: вставка несёт смысл, exact text не теряется.

**Реактивная буквенная сетка:** glyph_i привязан к homePosition; displacement от расстояния до q ограничен, return детерминирован. Для читаемого состояния displacement=0. Проверка: эффект не делает сообщение загадкой.

**Рисующаяся линия:** измерить totalLength, revealed=p×length; маркер движется по той же длине дуги, не по независимой декоративной easing. Проверка: connector означает реальную связь, нулевая длина даёт конечную точку.

**Частицы результата:** на событии seed определяет velocity_i,position=origin+velocity×age+gravity×age²/2; alpha заканчивается при life_i. Частицы принадлежат reaction, важный итог остаётся устойчивым. Проверка: real success не подменён декоративным.

**Неглубокий перелив загрузки:** bright band проходит по skeleton соответствующего будущего bounds, text не внутри фильтра. Loading показывать только для реального промежуточного состояния. Проверка: после readiness skeleton исчезает, а не играет рядом с итогом.

**Фокус и мягкий фон:** blur применяется к background-layer, а не общему контейнеру текста. Геометрия foreground стабильна; при выходе восстановить фон. Проверка: readable contrast сохраняется, costly filter имеет solid fallback.

**Распределённый фон:** центры мягких пятен следуют сидированным функциям времени; их amplitudes/alpha ограничены паком, signal не размывается. Проверка: ни фон, ни glitch/RGB split не окрашивают собственную работу пользователя; если это цель стилизовать исходную работу, нужно отдельное разрешение.

## Выбор и проверка

Сначала выбрать отношение объектов и основной смысл. Названный паттерн не означает обязательное использование библиотеки. Сложный вид можно выполнить существующим renderer; неподдерживаемая деталь получает явный fallback с тем же смыслом. Для масок/свайпа/параллакса использовать общий clock и motion-behavior; специальные поля в каталоге motion-lab уже задают самостоятельные рецепты. Новое название не дублирует другой алгоритм: если задача совпала, использовать существующий recipe_id.

Проверка каждой конструкции: content_ids настоящие, bounds известны, A соблюдена, reading state устойчив, layers/owner/clip однозначны, край/начало/конец непрерывны, результат одинаков при повторном seek. Просмотр итогового MP4 и формата файла обязателен для заявленного видео; схема/изображение проверяет только свою часть.

## Дополнительные пространственные операции

**Увеличение ближайшего пункта:** size_i=base+gain×max(0,1−distance(q,center_i)/reach); center/padding вычислить так, чтобы соседние пункты не налезали. В MP4 q из сценария; интерактивный вариант поддерживает focus. Проверка: порядок объектов остаётся и избранный пункт имеет реальный смысл.

**Штора:** две clip boundaries движутся от общего раздела к краям; revealing content находится под ними. Начальные boundaries совпадают, final reveal показывает всё нужное A. Проверка: одна мысль не разрезана на две разные, буквы резкие.

**Отбрасывание карточки:** active shell уходит по известному вектору и rotation вокруг pivot, следующий слой уже подготовлен. Если это выбор, действие имеет подтверждённый смысл, не изображает реальный пользовательский input зрителя. Проверка: следующий item не появляется пустым/неизвестным, предыдущий не закрывает итог.

**Наезд и параллакс:** camera progress задаёт единый маршрут; foreground и background смещаются с разными gain, focus_detail остаётся заданным якорем. Scale не меняет aspect ratio. Проверка: crop защищает существенное; не приписывать плоской картинке реально снятую 3D-геометрию.

**Привязанный медиаряд:** frame_index(p)=clamp(floor(p×(N−1)),0,N−1), все N состояний доступны до render. Это просмотр конечной последовательности, не wall-clock playback. При N=1 всегда первый кадр. Проверка: события/подписи совпадают с выбранным состоянием, видео/3D имеет корректный seek.

**Жидкая граница:** smooth mask edge задаётся ограниченной функцией положения/времени, из одной области в другую без прорех. Seed и coefficient сохраняются; text в собственной плоскости. При неподдержке shaders заменить простой reveal с тем же направлением. Проверка: в финале не осталось маски и мерцающих мелких дыр.

**Направленное заполнение:** старт границы в фактической стороне q входа; p расширяет fill внутри clip компонента. В видео side задан событием. Проверка: label контрастен во всей фазе и существующее действие не меняется.

**Контекстное выделение:** сначала readable content, затем active bounds слова/строки, затем toolbar возле этих bounds внутри A. Toolbar получает собственный motion owner, текст не движется вслед за ним. Проверка: инструменты соответствуют объясняемому действию, не фиктивной функции продукта.

**Сортировка:** entries имеют stable_id; порядок до/после задан реальным правилом. Измерить обе позиции и интерполировать по ID, не по текущему arrayindex. Проверка: content не меняет identity при обмене мест, выбранное правило имеет объяснение.

**Контролируемое техническое искажение:** канал/texture/filter относится к собственному графическому материалу и ограниченной фазе; после неё точный readable оригинал. Не применять к работам человека без разрешения. Проверка: data и глифы не искажены в чтении; частота эффекта не мешает восприятию.
