# Свой стиль: пак

**Где запускать команды.** Корень Cadence: `${CLAUDE_PLUGIN_ROOT}`. Если выше стоит путь к папке — Cadence стоит плагином: команды этого навыка запускать из этой папки (`cd` туда), свои файлы человека — в `$WORK`, не в ней. Если видна сама запись в фигурных скобках — это папка выпуска или исходников, команды запускаются из неё.

Пак `pack.json` хранит цвета, шрифты, скругления, толщину линий и характер движения. Движок `--pack` автоматически применяет цвета; остальные свойства агент явно связывает со сценой и проверяет по кадрам. Встроенные паки лежат в `design/packs/<id>/`, свои паки человека — в `$WORK/packs/<id>/`: рабочая папка не меняется при обновлении набора, а папка выпуска заменяется новой. Сменить вид всех роликов = собрать новый пак и собирать с `--pack <id>`; движок сначала ищет пак в `$WORK/packs/`, потом в `design/packs/`. `$WORK` в командах — рабочая папка человека (как задать — `cadence-motion`, «Где лежат файлы»); команды запускаются из корня выпуска.

| Файл | Что в нём | Кто меняет |
|---|---|---|
| `design/DESIGN.md` | правила для всех паков: сетка, безопасные поля, иерархия, движение | только по прямой просьбе человека |
| `design/tokens.json` | общие числа: поля кадра, размеры текста, длительности, кривые | только по прямой просьбе |
| `design/packs/<id>/pack.json` | встроенный стиль | никто: обновляется вместе с набором |
| `$WORK/packs/<id>/pack.json` | свой стиль человека | этот скилл |
| `engine/fonts/` | шрифты с кириллицей и их лицензии (OFL) | новый шрифт — только с согласия (сеть и проверка лицензии) |

По умолчанию — пак **`cadence-ember`**: тёплая тёмная тема. Его не правим: новый вид — всегда новый пак.

| Роль | `cadence-ember` | Зачем |
|---|---|---|
| `canvas` | `#0E0C0B` почти чёрный | фон кадра |
| `surface` | `#1C1917` | карточки, панели |
| `ink` | `#F0EEE6` | основной текст |
| `muted` | `#B4ADA3` | второстепенный текст, подписи |
| `signal` | `#D97757` коралл | главный акцент |
| `signalSecondary` | `#F2A65A` янтарь | второй акцент |
| `signalSoft` | `#3A2A22` | мягкая подложка акцента, свечение |
| `line` | `#51483F` | тонкие линии, рамки |
| `positive` | `#FF8A4C` | «успех», рост |
| `onSignal` | `#0E0C0B` | текст поверх акцента |

Шрифты: заголовки — Literata (антиква), текст — Manrope, код, числа и время — JetBrains Mono.

## Человек не знает, какой стиль хочет

Не расспрашивать, а показывать: 2–4 варианта на его собственном кадре, рекомендуемый — первым, всегда с вариантом «ближе к монохрому», один вопрос за шаг. Отказы сужают выбор и записываются в `work/preferences.md`. Весь сценарий — в [choose-style.md](references/choose-style.md). Инструменты:

- `scripts/wada_pick.py` — подбор сочетаний из словаря Сандзо Вады под фон: один акцент, ближе к монохрому, исключённые тона, по одному тону на сектор;
- `scripts/style_sheet.py` — лист сравнения 2–6 паков на кадре человека (`--render` снимает его движком в `sheet.jpg`).

Итог выбора — пак (или два режима: строгий и с акцентом), лист-превью и `DESIGN.md` стиля по шаблону [style-system.md](references/style-system.md): движение, физика, переходы, цвет для генерации, изолированные слои, список ассетов.

## Собрать свой пак

1. **Имя пака** — латиницей через дефис: `my-brand`, `sunny-light`.
2. **Откуда вид.** Один из входов:
   - описание словами («тёплый минимализм, кремовый фон, тёмно-зелёный акцент»);
   - один или несколько референсов: читать только файлы, которые назвал человек, и смотреть их глазами (Read). Папки не сканировать, ничего не скачивать;
   - CSS приложения человека: взять переменные цветов и шрифтов из его темы.
3. **Выбрать палитру и роли.** Прочитать [самостоятельную процедуру](../cadence-visual-direction/references/palette-selection.md): идея, референс или поиск актуальных примеров по запросу. Выбрать гармонию, яркостную иерархию, роли и доли цвета; проверить реальный контраст и sRGB. Площадь цвета на картинке сама по себе не определяет роль. Запрос нового пака разрешает выбирать новую гамму и совместимые локальные шрифты; Ember не ограничивает выбор. Источники и смысл решений записать в provenance.
4. **Характер.** `typography` — три лица: `display` (заголовки), `body`, `mono`. `radii` — острые углы (4–8) для строгого стиля, крупные (28–44) для мягкого. `stroke` — толщина линий. `decor` — сетка, уголки-скобки, пятно акцента. `motion.character`:
   - `hard` — быстро и резко, без вращений (техника, спорт);
   - `soft` — медленно и плавно (уют, забота);
   - `editorial` — спокойный ритм по умолчанию.
5. **Шрифты — только из `engine/fonts/`** (там проверена кириллица). Шрифт референса не установлен — взять ближайший локальный и записать замену в `provenance.notes`. Новый шрифт — спросить человека: это скачивание и проверка лицензии.
6. **Записать** `$WORK/packs/<id>/pack.json` по образцу `design/packs/cadence-ember/pack.json` (поле `schemaVersion` — как у него) и проверить. Внутрь папки выпуска свой пак не класть: следующее обновление его не перенесёт.
   ```bash
   python3 skills/cadence-style/scripts/validate_pack.py "$WORK/packs/<id>/pack.json"
   ```
   В установленном выпуске тот же скрипт лежит в `.claude/skills/cadence-style/scripts/` или `.agents/skills/cadence-style/scripts/`.

## Контраст — проверка, а не вкус

Валидатор считает контраст по WCAG и падает, если:

| Пара | Порог |
|---|---|
| `ink` и `muted` на `canvas` и на `surface` | 4,5 : 1 |
| `onSignal` на `signal` | 4,5 : 1 |
| `signal` на `canvas` (крупная графика) | 3 : 1 |

`signalSecondary` и `positive` на `canvas` ниже 3 : 1 — предупреждение. Для каждой провальной пары скрипт предлагает ближайший цвет того же оттенка, который проходит. Подставить его, проверить снова. Порог не снижать: правится цвет, а не проверка.

## Проверить пак в результате

Применить новый пак на нужных сценах текущей задачи: текст, панель, акцент и крайний контент. Проверить схему, цветовые пары, длинную кириллицу, UI safe area и фактический вид кадров. Отдельный демонстрационный ролик нужен только по задаче; его длительность не является обязательным этапом. Шрифты, радиусы, тени, декор и характер движения явно реализовать в композиции: успешный `--pack` подтверждает только применение цветовых переменных. Сохранить полезный кадр как `$WORK/packs/<id>/preview.png`; текущая авторизация работы сохраняется.

## Правила, которые держат вид

- Одна мысль на сцену; главный, второй и третий уровень чтения различимы.
- Безопасные поля: токены формата из `design/tokens.json`; для Reels/TikTok ужесточить до x=0.06W…0.82W и y=0.15H…0.75H. Проверить реальный UI-overlay и кропы обложки.
- Сетка 8 px. Заголовок на русском — 2–5 слов, подпись — до двух коротких строк.
- Площадь акцента выбирается по иерархии; небольшой акцент выделяет действие, большая цветовая плоскость может задавать среду. Не выдавать фиксированный процент за универсальное правило.
- Одновременно двигаются не больше трёх смысловых групп.
- Один шрифт заголовков на ролик, максимум один дополнительный. Не менять шрифт от сцены к сцене.
- Код, числа, время — моноширинным.
- Перед рендером проверить длинное русское слово, заглавные, цифры и знаки препинания: перенос и ширина строки на кириллице другие.

## Чего не делать

- Не копировать чужой бренд: логотипы, маскоты, фирменные надписи и платные шрифты. Пак передаёт характер, а не клон. Источник вдохновения записать в `provenance`.
- Не править `cadence-ember` и чужие паки — новый вид всегда новым файлом.
- Не скачивать картинки и шрифты из сети без согласия.
- Не обходить проверку контраста.
- Одобренный пак — не разрешение публиковать ролики: это отдельное решение человека.
