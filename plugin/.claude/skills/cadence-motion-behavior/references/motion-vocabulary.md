# Словарь поведения для спецификации

Название уточняет наблюдаемое действие, но не заменяет from/to, anchor, расписание и критерий. При неясном описании выбрать наиболее близкое и назвать различие; не придумывать обязательный библиотечный компонент по имени эффекта.

| Группа | Термины и рабочее различие |
|---|---|
| Видимость | fade меняет прозрачность; reveal открывает область через clipping/mask; enter/exit обозначают сценарное появление и уход |
| Прибытие | slide переносит объект; scale меняет размер относительно origin; pop добавляет краткий перелёт перед посадкой |
| Геометрия | translate — перенос; rotate — поворот; skew — сдвиг осей; perspective и 3D tilt — отношение глубины к камере; transform-origin — неподвижная точка преобразования |
| Смена состояния | morph меняет форму одного носителя; shared element сохраняет идентичность через новый layout; layout transition переставляет существующие объекты; crossfade накладывает прозрачности разных поверхностей и не равен морфу |
| Связность | continuity сохраняет ориентир; direction-aware связывает направление с «дальше/назад»; orchestration согласует несколько track |
| Время | keyframe задаёт опорное состояние; interpolation вычисляет промежуточное; delay откладывает событие; duration ограничивает интервал; stagger распределяет старты группы; fill определяет состояние вне интервала; stepped выдаёт дискретные изменения |
| Scroll | scroll reveal открывает при достижении области; scroll-driven зависит от позиции; parallax разделяет скорости планов; page/view transition связывают состояния навигации |
| Ввод | hover — подсказка указателя; press — местная реакция контакта; hold — выполнение при удержании; drag — прямое следование; reorder — изменение порядка; swipe dismissal — уход после жеста; rubber-band — сопротивление вне границы |
| Реакция | shake сообщает отказ локально; ripple связывает реакцию с точкой контакта; anticipation показывает намерение до действия; follow-through даёт отстающей части доехать; squash/stretch деформирует оболочку для массы, не читаемые буквы |
| Скорость | easing — закон прогресса; ease-out тормозит; ease-in разгоняет; ease-in-out совмещает; linear сохраняет скорость; bezier задаёт отображение времени в progress; asymmetric распределяет разгон/посадку неравномерно |
| Пружина | stiffness тянет к цели; damping подавляет осцилляции; mass меняет инерцию; bounce — перелёт; velocity задаёт направление/темп; momentum переносит скорость; perceptual completion — уже воспринимаемая посадка; interruptible — новое событие меняет цель без прыжка |
| Фон | loop повторяет; yoyo возвращает; orbit движется вокруг; marquee течёт вдоль; pulse локально усиливает; float дрейфует; idle сохраняет минимальное действие — применять только с причиной |
| Деталь | clip имеет резкую границу; mask допускает мягкую; blur смягчает поверхность; before/after совмещает сравнимые состояния; line drawing раскрывает длину пути; text morph меняет символы; shimmer сообщает placeholder; ticker показывает число; tabular digits сохраняют ширину; typewriter раскрывает ввод |
| Стоимость | FPS — частота вывода; jank — неравномерное отображение; dropped frame — пропущенный показ; compositing — сборка слоёв; will-change — подсказка подготовки, не гарантия; layout thrashing — повторяемые измерения/изменения, заставляющие пересчитать layout |
| Проверка | purposeful — объясняющее движение; spatial consistency — известное местоположение/идентичность; reduced motion — менее возбуждающая эквивалентная передача смысла; perceived response — момент видимого отклика, не заявление о скорости выполнения |

Пример разрешения неоднозначности: «изображение стало карточкой» — shared element, если узнаваемое изображение переместилось в новый контейнер; morph, если изменяется сама оболочка; reveal, если карточка только открывается маской. Видеостыки соблюдают текущий канон: название crossfade не разрешает запрещённый наплыв. Метрики web 60/120 FPS не заменяют выбранный fps MP4.
