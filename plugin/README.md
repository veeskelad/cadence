# Cadence — дизайн, моушн, монтаж и звук с AI-агентом

Система для Claude Code и Codex. Агент помогает с дизайном, моушном, монтажом и саунд-дизайном: от идеи и визуального стиля до готового материала.
- ролики в бит трека;
- шоурил одним пролётом камеры;
- эффекты, звук под картинку, любой свой стиль по идее или референсу;
- визуальная система: композиция, типографика, палитры, состояния и самостоятельные рецепты анимации;
- нарезка живого видео: убирает паузы и делает субтитры.

Всё работает локально и бесплатно, без ключей.

Техническое имя сборки: `cadence-motion-studio`.

## Как запустить

1. Поставь Cadence одним из способов:
   - **плагин Claude Code** (обновляется сам):
     ```bash
     claude plugin marketplace add veeskelad/cadence
     claude plugin install cadence@cadence
     ```
     Чтобы новые версии приходили сами, включи автообновление этого marketplace в `/plugin` → Marketplaces.
     Твоя рабочая папка — `~/Cadence/work` (другую можно указать в `~/.config/cadence/config.json`: `{"work": "<папка>"}`).
   - **папкой** (Claude Code или Codex): промпт установки с сайта, затем открыть папку выпуска как проект.
2. Поздоровайся. Агент расскажет, что умеет, и предложит четыре способа начать: рассказать идею,
   и агент сам сделает первый ролик; дать материал; попросить идеи; разобрать ролик, который нравится.
3. Дай согласие на установку движка: `python3 scripts/engine_setup.py install`. Это один раз на
   компьютер, нужна сеть, около 300 МБ; следующие версии подключат его без скачивания.
4. Смотри план и соглашайся. Готовый ролик появится в `work/<проект>/out/` рядом с набором.

## Что можно попробовать

- «Сделай ролик в бит моего трека, заголовок: …» — 10–15 с, хук, кадры моушна на каждый удар, знак.
- «Собери шоурил из двух моих видео» — 27–36 с одним пролётом камеры в 3D.
- «Порежь это видео: убери паузы и сделай субтитры» — новый MP4 и SRT, исходник не меняется.
- «На 7-й секунде прыжок — замедли его, как в кино» — speed ramp, whip pan, crash zoom, тряска,
  вспышка, стоп-кадр на твоём видео.
- «Сделай заставку: логотип собирается из плиток» и другие эффекты из `knowledge/effects-bank/`.
- «Как сделан этот ролик?» — разбор референса и рецепт, как повторить.
- «Проверь ролик перед публикацией» — громкость, пик, формат, чёрные и замершие кадры.
- «Нужна сцена, которой у меня нет» — агент подготовит генерацию: что приложить, какую модель
  взять, промпты; генерируешь в своём сервисе, агент вставляет результат в ролик.

Агент запоминает твои правки в `work/preferences.md` и дальше применяет их сам.

Больше готовых фраз — [guides/PHRASES.md](guides/PHRASES.md).

## Первый локальный результат

Готовый запрос:

> Сделай ролик в бит. Трека нет — возьми демо-бит. Хук: «Весь этот ролик» / «— код» /
> «его написал агент». Знак: «Cadence», подпись «моушн-студия для агента».

Путь по шагам — [guides/FIRST-RESULT.md](guides/FIRST-RESULT.md). Для видео —
[guides/FIRST-CUT.md](guides/FIRST-CUT.md). Перед публикацией —
[guides/BEFORE-POSTING.md](guides/BEFORE-POSTING.md).

В версии 1.8 — 26 навыков и 18 карточек элементов с входами, слоями, формулами и проверкой. Выбор дополнительных модулей — [маршрутизация](knowledge/system/ROUTING.md); согласование правил — [совместимость](knowledge/system/compatibility.md).

## Как устроен набор

| Папка | Что |
|---|---|
| `skills/` | навыки агента; вход — `cadence` |
| `engine/` | рендер HTML → MP4 (HyperFrames): шаблоны, общий код, three.js, шрифты, сборщик |
| `scripts/` | новый проект, структура трека, нарезка пауз, кино-эффекты на видео, паспорт видео, субтитры, сведение звука, сдача, проверка перед публикацией, проверка Resolve, демо-бит, звуки, подбор сочетаний цвета и лист сравнения стилей, проверка и установка обновлений, монтаж из дублей, хайлайт без речи, голос и музыка, уровни эффектов, вспышки и безопасные зоны, сцены по словам, шаблоны переходов Resolve |
| `sounds/` | звуки, синтезированные кодом: клавиши, клик, вух, подлёт, райзер, удар, колокол |
| `design/` | дизайн-система и паки стиля |
| `knowledge/` | банк эффектов, словарь 424 приёмов, монтаж и звук |
| `examples/` | сценарии-примеры |
| `guides/` | первые результаты по шагам, готовые фразы агенту, проверка перед публикацией |
| `requirements.txt` | Python-зависимости: `python3 -m pip install -r requirements.txt` |

## Обновление

Агент спросит один раз, проверять ли новую версию раз в день. Если согласишься, он сам скажет
одной строкой, когда выйдет новая, и по твоему «обнови» поставит её рядом со старой
(`python3 scripts/cadence_update.py apply`). Проверка — один запрос к сайту Cadence, файлы
никуда не уходят; выключить — `python3 scripts/cadence_update.py disable`.

Обновить вручную: вставь тот же промпт установки в агента, открыв папку `Cadence` (ту, где лежат `releases/` и
`work/`). Он сверит версию и ответит одно из трёх: «уже актуально», «обновление» или «ничего
не меняю». Новый выпуск встаёт рядом со старым в `releases/`, старый не удаляется.

- Твоё в `work/` не трогается: проекты, ролики, свои паки стиля (`work/packs/`), рецепты и
  память о твоих правках (`work/preferences.md`).
- Движок не скачивается заново, если его зависимости не менялись: `python3 scripts/engine_setup.py install` подключит уже скачанный.
- Правки, сделанные прямо внутри папки выпуска, в новый выпуск не переезжают. Всё своё держи в `work/`.

## Безопасность

- Агент работает только на чтение, пока ты не согласишься на план.
- Исходники не меняются: результат — всегда новый файл в `work/<проект>/out/`.
- Установка движка, модели и отправка материалов — с разрешения. По запросу агент читает актуальные источники для палитры; при ошибке ищет официальную документацию.
- Ключей, платных сервисов и публикации в наборе нет.
- Проект DaVinci Resolve меняется только с копией и согласием.
