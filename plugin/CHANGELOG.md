# 2.3.2 — 2026-11-20

- **Смена сцены одним движением.** Переход `push` идёт по очереди: старая сцена растёт и исчезает, потом новая подрастает из глубины и проявляется. Текст двух сцен не стоит друг на друге, кадр не затемняется и не моргает. `tear` — узкая полоса-шторка: слева старая сцена, справа уже новая, без заливки всего кадра цветом.
- **Без пустого экрана.** Сцена, которую приносит камера, собирается уже во время перехода и приезжает с текстом. Переход короче: 0,7 с (`smooth`) и 0,55 с (`snappy`).
- **По центру кадра.** Каждая сцена ролика по словам стоит по центру кадра и сдвигается к центру рабочей зоны, только если иначе зайдёт под кнопки площадки. Сцены со своей зоной `safe` и `layout: "free"` не трогаются.
- **Печать без рывка.** Терминал, поиск и комментарий сразу держат место под весь текст: карточка не прыгает на переносе строки.
- **Новые проверки.** `board-check` ловит пустой экран между сценами, мигание элемента, сцену не по центру и надписи двух сцен друг на друге. Новый `npm --prefix engine run video-check -- <файл.mp4>` проверяет готовый ролик по кадрам: вспышку, затемнение всего кадра, моргание.

# 2.3.1 — 2026-11-20

Последняя сцена ролика по словам разбирается: элементы уходят по очереди за 0,4 с, всплывают и тают (`film.exit: "leave"` по умолчанию). На склейке `cut` между сценами — так же. Смена сцены камерой длиннее (0,9 с), строки квитанции, рейтинга, таблицы и терминала въезжают, а не мигают.

# 2.3 — 2026-11-19

- **Доска поверх записи.** Ролик по словам встаёт поверх своих кадров игры, экрана или съёмки, а не отдельным тёмным экраном посреди ролика. `film.over: true` даёт прозрачный фон (рендер `--format mov` с альфой). У каждой сцены своя рабочая зона `safe`, чтобы обходить людей своего плана. Последняя сцена уходит нырком камеры (`film.exit`) и не пропадает на склейке. Поверх записи сцена держит целое предложение, от 2,5 с. Порядок и команда наложения — раздел «Доска поверх записи» в `code-board-explainer.md`.
- **Проверка раскладки доски.** `npm --prefix engine run board-check -- <сборка> [--heroes heroes.json]` до рендера находит штамп на тексте или на соседнем предмете, надпись на надписи, выход за рабочую зону вертикали. С рамками героев — ещё и графику на лицах, людях и главном предмете под доской.
- **Штампы читаются.** У листа с маркером и у фото штамп висит под нижним краем, у карточек стоит в правом верхнем углу своей карточки. Подложка у штампа светлая, красный читается на любом цвете. Карточки стопкой, веер и «размер» в вертикали помещаются в рабочую зону.
- **Вставки прилетают и улетают.** Знак, врезка, статья и сравнение по умолчанию всплывают снизу из размытия (`enter: "rise"`) и уходят отлётом вверх с размытием, без перелёта и исчезновения в один кадр. Прежний вход — `enter: "pop"`.
- **Стиль не назван — агент спрашивает.** `cadence-motion` одним сообщением спрашивает, в каком стиле делать (2–3 варианта и «подбери сам») и что добавить: доску поверх записи, вставки, счётчик, титр, клик, музыку.

# 2.0 — 2026-11-17

Cadence превращает агента в Claude Code или Codex в монтажёра, моушн-дизайнера и звукорежиссёра. Ролики считаются у тебя на компьютере: рендер идёт на HyperFrames 0.9.55, анимация на своём движке Cadence Tween (`engine/lib/cadence-tween.min.js`), из сети при рендере ничего не грузится.

Что в выпуске:

- **Монтаж.** `scripts/takes_cut.py` собирает ролик из лучших дублей по речи, `scripts/highlight_cut.py` вырезает лучшие моменты длинного видео под доли трека. Субтитры сами определяют язык и держат 17 знаков в секунду, `audio_sync.py --preview` даёт три коротких клипа для проверки синхрона.
- **Моушн кодом.** Ролик в бит своего трека: по умолчанию форма `one-shape`, пёстрая `beat-reel` по желанию. Шоурил одним дублем, заставки, титры, 3D и шейдерные фоны. Постерный моушн (`engine/templates/poster-motion`): плывущий градиент с зерном, фокус по слоям, смаз по оси, липкие буквы, жидкая деформация, полутон по маске и ASCII-рендер.
- **Модули.** В `modules/` 36 инструментов под отдельные задачи: нарезка шортсов из длинной записи, перебивки поверх говорящего, рилс из папки клипов, таймлайн для Resolve, Premiere и Final Cut, локальная расшифровка и озвучка, эксплейнеры, промо продукта, знак и библиотека из 400 с лишним блоков с превью. Агент находит модуль через навык-вход и `knowledge/system/ROUTING.md`. Тяжёлые части ставятся по согласию командой `python3 scripts/module_setup.py install <id>`, со сверкой sha256.
- **Ролик по идее человека.** Шаблоны и примеры служат заготовкой формы, ролик собирается по словам, знаку и стилю человека.
- **Звук и стиль.** Эффекты под события в кадре, музыка остаётся главной, громкость проверяется числом. Свои паки цветов и шрифтов, варианты стиля на кадрах человека.

Плагин ставится одной командой: `claude plugin install cadence --marketplace veeskelad/cadence`. Установки папкой обновляются промптом установки с сайта.
