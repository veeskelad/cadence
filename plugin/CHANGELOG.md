# 2.1.1 — 2026-11-19

- **Клик без дублей.** Пока кнопка «подписаться» на экране, подпись не повторяет её слово: «Подпишись» под «Подписаться» или «Subscribe for more» под «Subscribed» — ошибка сборки с именем вставки. В рецепте `code-proofs.md` — правило: клик встаёт на место своей кнопки-призыва, лупа — только на неподвижной детали.

# 2.1 — 2026-11-19

- **DaVinci Resolve — в Cadence Pro.** Работа агента внутри Resolve переходит в подписку Cadence Pro: проверка Resolve скриптом, импорт скриптом, эффекты и переходы, шаблоны переходов, карта API и протоколы проверки рендером. Навык `cadence-resolve` стал клиентом: рецепты и скрипты он берёт с сервера Cadence Pro по ключу подписки, по одному под шаг (`scripts/cadence_pro.py`). Бесплатно остаются ручная передача в Resolve и монтаж EDL из нарезки (`cadence-cut`).
- **Что ушло из бесплатной поставки.** Рецепты банка эффектов с исполнителем `cadence-resolve` (11 приёмов: строки в `knowledge/effects-bank/INDEX.md` остались с пометкой Pro), своя библиотека внутри Resolve, скриптовая часть словаря монтажа, скрипты `resolve_check.py` и `resolve_transition_template.py`, модули `frame-inspector-plugin` и `resolve-frame-pipeline`.
- **Если пользовался `cadence-resolve` раньше.** После обновления навык скажет, что работа в проекте Resolve — в Cadence Pro, и предложит ручную передачу. Прежние выпуски у тебя остаются как были.
- **Ролик по словам.** Новый шаблон `board-explainer`: объясняющий ролик без съёмки собирается из сцен, у каждой одно слово словаря (`счётчик`, `чек`, `весы`, `банка`, `конвейер`, `терминал`, `шаг`, `рейтинг` и ещё 31). Вид задают пак и материал сцены (бумага, стекло, плоско), формат 16:9 или 9:16 — из того же сценария. Словарь и инструкция — `knowledge/effects-bank/code-board-explainer.md`, пример всех слов — `examples/board-explainer/film.json`, 66 залитых значков с русскими именами — `engine/lib/board-icons.js`.
- **Слова поверх записи.** Слой доказательств `kinetic-explainer` понимает слова: `уголки` (прицел на детали), `лупа` (кусок кадра крупно на своём месте), `титр` («было» и «стало» курсивом сверху), `тревога` (значок предупреждения и свечение у края), `клик` (курсор жмёт «подписаться», кнопка меняет состояние), а прежние виды — `знак`, `врезка`, `статья`, `дорожки`, `кольцо`, `рамка`, `замер`, `дорога`. Переход «вспышка» — в `film.lightbars`. Пример — `examples/hud/film.json`.
- **Разбор моушн-ролика.** `cadence-breakdown` раскладывает объяснение без съёмки по словам словаря; `npm --prefix engine run measure -- cuts|events <файл>` находит склейки и моменты, когда на экране что-то появляется.

# 2.0.1 — 2026-11-18

- **Обновление плагином.** Когда вышла новая версия, а Cadence стоит плагином Claude Code, навык-вход говорит об этом одной строкой в конце ответа и по слову «обнови» запускает `claude plugin marketplace update cadence && claude plugin update cadence@cadence`. Новая версия включается после перезапуска Claude Code.
- **Автообновление.** Вместе с вопросом о ежедневной проверке агент один раз подсказывает, где его включить: `/plugin` → Marketplaces → cadence → Enable auto-update. Для сторонних каталогов Claude Code по умолчанию держит его выключенным.
- **Модули после обновления.** Если пакет модуля уже скачан, `module_setup.py status` так и говорит: `install` подключит его в новой версии без сети.

# 2.0 — 2026-11-17

Cadence превращает агента в Claude Code или Codex в монтажёра, моушн-дизайнера и звукорежиссёра. Ролики считаются у тебя на компьютере: рендер идёт на HyperFrames 0.9.55, анимация на своём движке Cadence Tween (`engine/lib/cadence-tween.min.js`), из сети при рендере ничего не грузится.

Что в выпуске:

- **Монтаж.** `scripts/takes_cut.py` собирает ролик из лучших дублей по речи, `scripts/highlight_cut.py` вырезает лучшие моменты длинного видео под доли трека. Субтитры сами определяют язык и держат 17 знаков в секунду, `audio_sync.py --preview` даёт три коротких клипа для проверки синхрона.
- **Моушн кодом.** Ролик в бит своего трека: по умолчанию форма `one-shape`, пёстрая `beat-reel` по желанию. Шоурил одним дублем, заставки, титры, 3D и шейдерные фоны. Постерный моушн (`engine/templates/poster-motion`): плывущий градиент с зерном, фокус по слоям, смаз по оси, липкие буквы, жидкая деформация, полутон по маске и ASCII-рендер.
- **Модули.** В `modules/` 36 инструментов под отдельные задачи: нарезка шортсов из длинной записи, перебивки поверх говорящего, рилс из папки клипов, таймлайн для Resolve, Premiere и Final Cut, локальная расшифровка и озвучка, эксплейнеры, промо продукта, знак и библиотека из 400 с лишним блоков с превью. Агент находит модуль через навык-вход и `knowledge/system/ROUTING.md`. Тяжёлые части ставятся по согласию командой `python3 scripts/module_setup.py install <id>`, со сверкой sha256.
- **Ролик по идее человека.** Шаблоны и примеры служат заготовкой формы, ролик собирается по словам, знаку и стилю человека.
- **Звук и стиль.** Эффекты под события в кадре, музыка остаётся главной, громкость проверяется числом. Свои паки цветов и шрифтов, варианты стиля на кадрах человека.

Плагин ставится одной командой: `claude plugin install cadence --marketplace veeskelad/cadence`. Установки папкой обновляются промптом установки с сайта.
