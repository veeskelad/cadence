# Дизайн-система Cadence

Правила, по которым собираются все шаблоны. Цвета и шрифты задаёт пак (`design/packs/<id>/pack.json`),
остальное — общие токены (`design/tokens.json`). Свой пак — навык `cadence-style`.

## Цвет

Восемь ролей, в шаблонах — CSS-переменные:

| Роль в паке | Переменная | Для чего |
|---|---|---|
| `canvas` | `--canvas` | фон кадра |
| `surface` | `--surface` | карточки, панели |
| `ink` | `--ink` | основной текст |
| `muted` | `--muted` | подписи, второстепенное |
| `signal` | `--signal` | акцент: слово, кнопка, сыгранный удар |
| `signalSecondary` | `--signal-2` | второй акцент, плейхед |
| `line` | `--line` | линии, неактивное |
| `onSignal` | — | текст на акценте (кнопка) |

Правила:
- один акцент на кадр, второй — только для плейхеда и подсветки;
- текст к фону — контраст не ниже 4,5:1, подписи на видео — с тенью или подложкой;
- **цвет работ человека не трогать**: без цветокоррекции, ACES, аберрации и цветных заливок
  поверх видео. Яркость экрана — только скаляром (экран «выключен» и «загорается»).

## Шрифты

| Роль | По умолчанию | Где |
|---|---|---|
| display | Literata (антиква) | заголовки, хук, знак |
| body | Manrope | подписи, кнопка |
| mono | JetBrains Mono | номера, BPM, код, теги |
| impact | Onest 800 | кинетическая типографика |

Шрифты лежат в `engine/fonts/` (OFL). Canvas грузит шрифт с образцом кириллицы, иначе текст
уходит в системные засечки.

Библиотека для своих стилей — все с кириллицей, имя семейства в CSS как в таблице. Образец всех
начертаний — `engine/fonts/specimen.html`.

| Характер | Семейства |
|---|---|
| узкие жирные (ключ, ярлык, проезд фразы) | Oswald, Sofia Sans Extra Condensed, Alumni Sans, Roboto Flex (`wdth` 25–151), Tektur (`wdth` 75–100) |
| гротески (подписи, столбик слов) | Inter Tight, Golos Text, Geologica, Jost, Montserrat, Wix Madefor Display |
| широкие и тяжёлые | Unbounded, Dela Gothic One, Rubik Mono One |
| антиква | Playfair Display, Cormorant, Yeseva One |
| пиксель и рукопись | Pixelify Sans, Press Start 2P, Caveat |

Узкий шрифт берётся узким начертанием, а не `scaleX`: сжатие истончает вертикальные штрихи.

## Кадр и безопасные зоны

- Форматы: 1080×1920 (9:16) и 1920×1080 (16:9), 30 fps.
- Для Reels/TikTok существенное содержание внутри x=0.06W…0.82W и y=0.15H…0.75H с учётом токенов и фактического UI. Проверять UI-overlay и кропы обложки.
- Поля формата — из токенов; область площадки может их ужесточить. Ширину строки проверять по реальному шрифту и кириллице.

## Движение

- **Смена кадра — на удар.** Сетка в долях трека, не в секундах.
- **Хук — до дропа**, главное движение — на дроп, тихое действие (печать) — в брейк.
- Въезд — `expoOut` за 0,35–0,5 с; кадр держится не меньше 0,5 с; декоративный акцент может держаться 0,5 с. Читаемый тезис держать столько, сколько нужно для чтения после посадки последнего слова.
- Толчок масштаба на смене: 1,045 → 1 за четверть доли.
- **Цель движения видна заранее:** камера летит к тому, что уже в кадре.
- **Смаз движения** — из подкадров (6–16 на кадр по скорости камеры), а не размытием.
- **Звук описывает движение:** подлёт звучит, только когда есть к чему подлететь.

## Громкость

Около −14 LUFS, пик не выше −1 dBFS, без лимитера (`scripts/deliver.py`). Музыка главная,
эффекты тише, но слышны.
