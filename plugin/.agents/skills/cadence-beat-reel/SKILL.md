# Ролик в бит

**Где запускать команды.** Корень Cadence: `${CLAUDE_PLUGIN_ROOT}`. Если выше стоит путь к папке — Cadence стоит плагином: команды этого навыка запускать из этой папки (`cd` туда), свои файлы человека — в `$WORK`, не в ней. Если видна сама запись в фигурных скобках — это папка выпуска или исходников, команды запускаются из неё.

10–15 секунд, собирается кодом за пару минут, без съёмки и генерации:
1. **Хук до дропа.** Заголовок расшифровывается из глифов, пока трек ещё тихий.
2. **Дроп.** Заголовок разлетается вперёд. Дальше на каждый удар — новый кадр моушна,
   нарисованный кодом: 21 генератор × 8 тонов тёплой гаммы. В последнем такте кадры
   идут на полдоли. Внизу полоса ударов трека с плейхедом: видно, что смена — ровно на удар.
3. **Знак.** Маленькие кадры слетаются в кольцо вокруг названия, затем подпись и кнопка.

Вторая форма на той же сетке — **`one-shape`, «одна форма»**: девять плиток весь ролик в кадре и на каждую долю перестраиваются в новую фигуру (линия, полосы по бочке трека, кольцо, сетка, волна, крест, ромб, спираль, столбик), каждая смена — своей пружиной по роли (`cadence-motion-behavior`); в конце плитки встают строкой под названием. Спокойнее и цельнее, чем смена кадров: глаз всё время следит за одной вещью. Выбор между формами — один вопрос человеку с превью обеих; сценарий тот же, меняется имя шаблона: `--film one-shape` в `new_project.py` и `node engine/build.mjs one-shape …`.

Сетку строит сборщик по самому треку: темп, первая доля, дроп
(`scripts/track_structure.py`). Ролик входит в трек так, что хук заканчивается ровно на дропе.

## Что спросить (одно сообщение)

- трек: путь к файлу (mp3/wav/m4a). Нет трека — демо-бит кодом;
- хук: строка, акцент, подпись — например «Весь этот ролик» / «— код» / «его написал агент»;
- знак: название, подпись, кнопка (кнопку можно не ставить).

## План → согласие → сборка

```bash
# 0. проект в рабочей папке: копия трека со сверкой хэша и сценарий-пример с путём к треку
python3 scripts/new_project.py <проект> --copy "<трек>" --film beat-reel   # W = work/<проект>
# нет трека: проект без --copy, затем демо-бит (путь в film.json уже in/demo-beat.wav)
python3 scripts/new_project.py <проект> --film beat-reel
python3 scripts/demo_beat.py --out "$W/in/demo-beat.wav"

# 1. проверить трек: темп и дроп (только чтение)
python3 scripts/track_structure.py "$W/in/<трек>"

# 2. в $W/film.json поправить хук и знак
# 3. сборка, проверка, рендер, сдача, техпроверка
node engine/build.mjs beat-reel --film "$W/film.json" --out "$W/build"
npm --prefix engine run check -- "$W/build"
npm --prefix engine run render -- "$W/build" --quality high --fps 30 --output "$W/out/reel-raw.mp4"
python3 scripts/deliver.py "$W/out/reel-raw.mp4" --out "$W/out/reel.mp4"
python3 scripts/check_reel.py "$W/out/reel.mp4"
```

Пути в `npm --prefix engine run …` указывай абсолютными или относительно папки `engine/`.

`film.json`:

| Поле | Что | По умолчанию |
|---|---|---|
| `music.src` | путь к треку относительно `film.json` | — |
| `music.volume` | громкость музыки | 0,6 |
| `music.start` | секунда входа в трек | хук заканчивается на дропе |
| `hook.title`, `hook.accent`, `hook.sub` | три строки хука | — |
| `mark.name`, `mark.tag`, `mark.cta` | знак в финале | — |
| `trackTitle` | название трека на кадре со счётчиком BPM | «твой трек» |
| `hookBeats`, `cutBeats`, `markBeats` | длина частей в долях | ≈ 1,9 с · ≈ 8 с · ≈ 2,8 с |
| `sfx` | свои звуки вместо `sounds/` | клавиши, райзер, удар, клик, вух, колокол |

Цвета — из пака: `--pack <id>` (свой — `$W/../packs/`, встроенные — `design/packs/`). Формат 16:9 — `--format 1920x1080`.

## Проверка перед тем, как показать

- `check` без ошибок;
- кадры из готового MP4, не из браузера. Обязательные моменты:
  - хук прочитан;
  - дроп: заголовок ушёл, первый кадр встал на удар;
  - середина;
  - последний такт;
  - знак с кнопкой.

  ```bash
  ffmpeg -v error -i "$W/out/reel.mp4" -vf "fps=2,scale=216:384,tile=8x3" -frames:v 1 "$W/out/sheet.jpg"
  ```
- громкость: `deliver.py` печатает LUFS и пик. Цель ≈ −14 LUFS, пик ≤ −1 dBFS. Тише — потому
  что упёрлись в пик; эффекты сделать тише в `sfx`, лимитером не разгонять.

## Частые ошибки

- **Дроп не нашёлся** (трек без вступления, бит с первой секунды). Сборщик возьмёт 8-ю долю.
  Лучше задать `music.start` вручную — на сильную долю за 3–4 доли до нужного места.
- **Медленный трек (< 80 BPM).** Кадр живёт больше 0,75 с — смена читается вяло. Возьми
  `cutBeats` поменьше или трек быстрее.
- **Длинный заголовок** уменьшается по ширине. Строка хука — до 16 знаков, акцент — до 8.
- **Чужая музыка** годится для черновика. Для публикации — свой трек или трек из библиотеки
  площадки. Права на чужой трек не обещать.
