# Отношения в предметной композиции

Применять для предметного каталога, бренда со своими фотографиями или последовательности «объект → процесс → коллекция → действие». Входы: своё изображение предмета, достоверные названия и описания, утверждённый пак и цель. Не придумывать цены, отзывы и обещания результата.

## Большой предмет и тихая область текста

Найти спокойную область собственного изображения. Поместить главный предмет на противоположной стороне, сохранить его силуэт и природный цвет. Текст имеет одну общую ось; сначала тезис, затем краткое объяснение, затем действие. Если фон за буквами сложный, отделить текст геометрически или локальной подложкой, не перекрашивая само изображение. Крупный контраст между заголовком и пояснением даёт иерархию; одинаковый контраст всех строк её уничтожает.

В web это может быть горизонтальная пара текст/предмет. В Reels композицию перестроить в вертикальную safe area: главное изображение над/под текстом, действие без перекрытия интерфейсом. Не переносить широкий screenshot растянутым на9:16.

## Каталог с ритмом

Для нескольких предметов сохранить равные правила crop, подписи и расстояния; можно изменить высоту или положение одного блока, если это выделяет фактический главный объект. Неровность служит роли, а не случайной декорации. Подписи остаются привязанными к изображению. Крупный блок может открыть тему, меньшие — уточнить варианты; они не означают рейтинг без данных.

## Объяснение процесса

Пара «контекстное изображение + шаги» показывает последовательность. В шаге: маркер, действие, результат; соединительная линия означает порядок, не просто заполняет пустоту. В MP4 шаги раскрываются по событиям, уже прочитанные остаются; text hold не ограничивается скоростью музыки. Без фотографии процесс можно выразить схемой с тем же порядком.

## Разные типы доказательства

Архив своих работ организовать по реальным категориям; не выдавать количество карточек за размер опыта. Отзывы использовать только реальные и с корректным разрешением; декоративные звёзды без оценок не включать. Отсутствие отзывов компенсировать видимым примером работы или объяснением процесса, а не выдуманным social proof.

Финальное действие вытекает из предыдущей темы. В веб форма работает с label, error и success. В MP4 она изображает реальное состояние продукта либо заменяется честным текстовым CTA; анимация нажатия не означает отправку настоящей заявки.

## Проверка

Крупный предмет различим, заголовок имеет тихий фон, подписи не оторваны от материала; порядок «зачем → что → как → действие» соответствует задаче и может быть сокращён. Проверить узкую композицию, самый длинный русский текст и уменьшенный размер. Для видео отдельные критерии: материалы не искажены, факты точны, чтение завершено, safe area и экспорт подтверждены.
