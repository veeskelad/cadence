# Каталог элементов и эффектов движения

Использовать при придумывании идеи и проектировании сцен. Выбрать элемент по тому, что зритель должен понять; карточка содержит всё необходимое для исполнения. Материал, текст, число объектов и длительность определяются задачей. Библиотека не задаёт обязательный формат или длину ролика.

## Выбор при генерации идеи

1. Сформулировать обещание ролика и одно новое понимание на каждую сцену.
2. Определить отношение: набор → веер/навигация/список; преобразование → морф/портал/вход-результат; время → таймлайн/число/progress; сравнение → совмещённые состояния/кривые; деталь → линза; вывод → стекло/финальный адрес.
3. Проверить, что необходимые входы существуют. Нет данных для сравнения — выбрать объяснение, а не выдумывать before/after.
4. Выбрать минимальный набор механизмов, прочитать нужные карточки и адаптировать параметры к материалу, формату, речи и паку.
5. Передать взгляд между сценами через общий объект, положение или направление. На читаемом тексте удержать композицию; декоративное движение не заменяет смысловое действие.

## Спецификация сцены

```text
Смысл: что зритель поймёт
Вход: текст, данные, материал, состояния
Элемент: ID карточки и причина выбора
Компоновка: W/H, safe zones, герой, слои, clipping, родители transform
События: причина → действие → результат
Расписание: start, entry, hold, exit; связь с речью/музыкой
Движение: начальные/конечные значения, функция progress, якорь взгляда
Неизменное: общая шкала, идентичность, условия честного сравнения
Готовность: критерии карточки и проверка итогового MP4
```

## Исполнение и устранение проблем

Собирать выбранные элементы непосредственно в ролике по его сценарию. Отдельный демонстрационный фрагмент не является обязательным этапом. Проверять результат по соответствию смыслу сцены и критериям карточки, а не по сходству с чужим монтажом. Звук назначать на причины, реакции и передачи внимания через звуковой навык Cadence; не озвучивать каждую декоративную деталь.

При сбое сначала проверить clock, bounds, загрузку шрифтов, z-порядок, clipping, matrix order, поддержку API и работу вложенного видео. Для конкретной нерешённой ошибки допускается поиск публичной документации и исходников используемого инструмента в интернете: запрос включает симптом и установленную версию. Предпочитать официальный источник; найденное решение сверить с локальным контрактом. Не отправлять приватные материалы в поиск. Скачивание зависимостей, платные вызовы, обновление движка и публикация остаются отдельными действиями.

## Площадка, промпт и проверка интерфейса

Для Instagram Reels/TikTok 9:16: top 15%, bottom 25%, left 6%, right 18%; важное содержание примерно x=65…886, y=288…1440 при 1080×1920. Это консервативные defaults, уточняемые по фактическому интерфейсу. Применить к layout и передать эти ограничения в промпт при генерации изображения/видео. Проверять не только полный кадр: наложить top navigation, right actions, bottom account/caption/audio. Обложку проверить отдельно в кропах профиля и ленты. Если overlay недоступен, сохранить поля и явно назвать предел проверки; попадание в полные 9:16 само по себе не является приёмкой.

Проверить экспортированный файл через ffprobe: по умолчанию 1080×1920, SAR 1:1, DAR 9:16 и правильная ориентация с учётом rotation metadata. Промпт и скриншот телефона не подтверждают параметры файла; возможность перемещения в Instagram не доказывает ошибку пропорций.
