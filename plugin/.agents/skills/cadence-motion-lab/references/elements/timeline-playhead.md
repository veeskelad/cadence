# Таймлайн и указатель текущего шага

## Назначение

Сделать видимыми порядок, длительность и текущую позицию процесса. Семейство: время.

## Входные данные

Список интервалов [start,end,label], общее время или нормированный диапазон, currentTime; аудиоданные только если нужна waveform.

## Параметры и компоновка

Общая шкала x0…x1; интервалы лежат на одной оси; фиксированные подписи не наследуют движение playhead.

## Контракт исполнения

Все размеры заданы относительно ширины W и высоты H кадра. Пак задаёт цвета и шрифты; safe zones берутся из design/tokens.json и ограничений сцены. До движения загрузить шрифты и материал, вычислить окончательный layout. Для Instagram Reels/TikTok 9:16 рабочая безопасная область важного содержания: x=0.06W…0.82W, y=0.15H…0.75H (при 1080×1920 примерно x=65…886, y=288…1440). Это консервативные рабочие поля, не официальная универсальная спецификация. Заголовки, captions, CTA, логотип, лицо и существенные детали помещаются в пересечение этой области с safe zones токенов и сцены. Фон и несущественный декор могут доходить до края. Геометрические defaults ниже адаптировать к доступному прямоугольнику; не сохранять размер карты ценой перекрытия интерфейсом. При наличии фактического UI уточнить поля.

Расписание задаёт start, entry, hold, exit и смысловые события; длительности выбираются по речи, читаемости и сетке музыки, фиксированная длина сцены не требуется.

Локальный progress `u=clamp((t−start)/duration,0,1)`; при t<start вернуть исходное состояние; при duration=0 и t≥start состояние сразу конечное. `E(u)=1−(1−u)^3` для мягкой остановки, `E(u)=u` для равномерного движения; `lerp(a,b,u)=a+(b−a)u`. Один кадр полностью вычисляется из t, входных данных и seed. Без накопленной физики, Date.now, независимых CSS timers и несидированной случайности.

## Слои

Track → блоки интервалов → playhead с дочерним маркером → подписи. Waveform отдельным слоем; строится из локальных аудиоданных или обозначается схемой.

## Порядок анимации

Вход: проявляется шкала и интервалы. Действие: playhead проходит последовательность, активный интервал меняет акцент. Hold: важная позиция удерживается для пояснения. Выход: текущий результат становится главным объектом.

## Вычисление состояния

range=rangeEnd−rangeStart. При range>0: x(t)=x0+(x1−x0)×clamp((currentTime−rangeStart)/range); width_i=max(0,end_i−start_i)/range×trackWidth. При range≤0 не делить: вывести статическую конечную позицию x1 и метку единственного события, интервальные blocks не строить. Входные start/end/currentTime должны быть конечными числами; end<start — ошибка входа, не отрицательная ширина.

## Критерии результата

Шкала, подписи, blocks и playhead используют один диапазон; нулевой интервал не вызывает деление на ноль. Проверить начало, события изменения, завершение каждого entry/exit, стыки по соседним кадрам и устойчивый финал в итоговом MP4. Если внутри есть видео, проверить, что оно играет. Один и тот же t после разных порядков seek должен давать одинаковую композицию.

Проверить экспортированный файл через ffprobe: по умолчанию 1080×1920, SAR 1:1, DAR 9:16 и правильная ориентация с учётом rotation metadata. Промпт и скриншот телефона не подтверждают параметры файла; возможность перемещения в Instagram не доказывает ошибку пропорций.

## Когда отказаться и как исправлять

Для иерархии без времени использовать дерево или список. При скачках позиции проверить единицы, in/out и начальный offset. Если локальная диагностика не объяснила сбой, искать в публичной официальной документации конкретного API или renderer по симптому и версии. Исправить причину, затем повторить проверку затронутого участка в итоговом ролике.
