# Появление смысловых фрагментов

## Назначение

Провести зрителя через тезис в порядке речи или аргумента. Семейство: внимание.

## Входные данные

text, разбиение на слова/фрагменты, расписание смысловых событий, ширина строки, шрифт.

## Параметры и компоновка

Начальный сдвиг 0.02W; blur до 0.008W только в явно выбранном альтернативном режиме; конечные x и baseline вычислены заранее; выбранный кегль читается в итоговом размере.

## Контракт исполнения

Все размеры заданы относительно ширины W и высоты H кадра. Пак задаёт цвета и шрифты; safe zones берутся из design/tokens.json и ограничений сцены. До движения загрузить шрифты и материал, вычислить окончательный layout. Для Instagram Reels/TikTok 9:16 рабочая безопасная область важного содержания: x=0.06W…0.82W, y=0.15H…0.75H (при 1080×1920 примерно x=65…886, y=288…1440). Это консервативные рабочие поля, не официальная универсальная спецификация. Заголовки, captions, CTA, логотип, лицо и существенные детали помещаются в пересечение этой области с safe zones токенов и сцены. Фон и несущественный декор могут доходить до края. Геометрические defaults ниже адаптировать к доступному прямоугольнику; не сохранять размер карты ценой перекрытия интерфейсом. При наличии фактического UI уточнить поля.

Расписание задаёт start, entry, hold, exit и смысловые события; длительности выбираются по речи, читаемости и сетке музыки, фиксированная длина сцены не требуется.

Локальный progress `u=clamp((t−start)/duration,0,1)`; при t<start вернуть исходное состояние; при duration=0 и t≥start состояние сразу конечное. `E(u)=1−(1−u)^3` для мягкой остановки, `E(u)=u` для равномерного движения; `lerp(a,b,u)=a+(b−a)u`. Один кадр полностью вычисляется из t, входных данных и seed. Без накопленной физики, Date.now, независимых CSS timers и несидированной случайности.

## Слои

Фон → текстовая группа → отдельные слова. Сначала загрузить шрифт и выполнить переносы, затем сохранить позиции каждого фрагмента.

## Порядок анимации

Вход: очередной фрагмент появляется на своём событии и садится в свою позицию; уже показанные слова стоят. Действие: новые фрагменты добавляются по смысловым событиям. Hold: фраза остаётся целиком. Выход: текст уходит группой по направлению следующего действия.

## Вычисление состояния

Для слова j при t<event[j] фрагмент скрыт. После события использовать uj=clamp((t−event[j])/entry[j],0,1), при entry[j]=0 сразу uj=1; x=xFinal+offset×(1−E(uj)). Канонический каскад Cadence: opacity=1 и blur=0 с момента события.

Альтернативный мягкий reveal с opacity=uj и blur=blurMax×(1−E(uj)) применять только при явно выбранном режиме, совместимом с активным паком и motion-laws. Этот вариант не заменяет канонический каскад по умолчанию.

## Критерии результата

Нет reflow, исчезающих слов и размытия после посадки; завершённая фраза получает время чтения. Проверить начало, события изменения, завершение каждого entry/exit, стыки по соседним кадрам и устойчивый финал в итоговом MP4. Если внутри есть видео, проверить, что оно играет. Один и тот же t после разных порядков seek должен давать одинаковую композицию.

Проверить экспортированный файл через ffprobe: по умолчанию 1080×1920, SAR 1:1, DAR 9:16 и правильная ориентация с учётом rotation metadata. Промпт и скриншот телефона не подтверждают параметры файла; возможность перемещения в Instagram не доказывает ошибку пропорций.

## Когда отказаться и как исправлять

Для длинного определения показывать целый блок. Если слова начинают теснить друг друга, исправить конечный layout, а не тайминг. Если локальная диагностика не объяснила сбой, искать в публичной официальной документации конкретного API или renderer по симптому и версии. Исправить причину, затем повторить проверку затронутого участка в итоговом ролике.
