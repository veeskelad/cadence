# Что агент может в Resolve скриптом, а что — только рукой

Скриптовый интерфейс Resolve (Python, `DaVinciResolveScript`) умеет меньше, чем меню. Ниже — что ставится напрямую, что заменяется обходом и что остаётся человеку. Проверено на Resolve Studio 21.x; на другой версии сначала перепроверить на пробном проекте. Справка по методам — в самом Resolve: **Help → Documentation → Developer** (файл `README.txt` в папке `Scripting`).

## Карта

| Действие в меню | Скриптом | Обход, если напрямую нельзя |
|---|---|---|
| Положить кусок клипа на таймлайн | `MediaPool.AppendToTimeline([{mediaPoolItem, startFrame, endFrame, recordFrame, trackIndex}])` | разрезать клип на таймлайне нельзя — собирать таймлайн заново из кусков |
| Импорт таймлайна из EDL, XML, FCPXML | `MediaPool.ImportTimelineFromFile(path, {...})` | — |
| Встроенный переход | `TimelineItem.AddTransition({type, category, position, alignment, duration})`; у клипов нужен запас кадров с обеих сторон склейки, иначе ответ `None` | — |
| Настройки перехода (угол, сила) | нет | свой шаблон Fusion-перехода: копия встроенного макроса `.setting` с изменёнными значениями — `scripts/resolve_transition_template.py`, порядок в [verified-effects.md](verified-effects.md); установка в личную папку шаблонов Resolve — с согласия; Resolve подхватывает его без перезапуска |
| Масштаб, позиция, поворот, кроп, прозрачность, режим наложения | `TimelineItem.SetProperty(...)`, режим — `CompositeMode` | — |
| Ключи в Inspector | методов нет | ключи в Fusion-композиции клипа; или импорт таймлайна из FCPXML с анимацией масштаба и прозрачности — тогда ключи видны в Inspector и их можно двигать руками |
| Adjustment Clip | вставляется, но без выбора дорожки, со сдвигом соседних клипов, свойства не читаются | любой клип на дорожке выше + Fusion-композиция, где у узла `MediaIn` источник `Background` вместо `Timeline`: узел читает всё, что под ним, и эффект ложится на нижние дорожки |
| ResolveFX на клипе | через Fusion-композицию клипа: `AddFusionComp` или `ImportFusionComp(path)`, инструменты ResolveFX по их идентификатору | — |
| Грейд на странице Color | только целиком из still: `ApplyGradeFromDRX(path, режим)`; узлы по одному не правятся | человек один раз делает грейд руками, агент снимает still и тиражирует |
| Render in Place | нет | рендер диапазона клипа в ProRes в `$WORK/<проект>/bake/`, импорт и укладка дорожкой выше; исходный клип выключить. Откат — удалить запечённый клип и включить исходный |
| Постоянная скорость, стоп-кадр | `SetSpeed` (только постоянная) | плавный ramp — ключами в Fusion или руками |
| Свой эффект кодом | DCTL — текстовый файл с функцией на каждый пиксель, применяется узлом DCTL в Fusion-композиции | — |
| Рендер | `AddRenderJob`, `StartRendering`, опрос `GetRenderJobStatus` | конец рендера определять по 100 % и существованию файла: текст статуса локализован |

## Ловушки

- **Составной клип (Compound Clip) эффекты не пропускает.** Композиция на нём создаётся, а рендер выходит как без неё. Эффект ставить на сами клипы или клипом-адъюстментом выше.
- Чтение настроек обратно не доказывает эффект. Анимированный параметр читается значением первого ключа. Доказательство — только кадр рендера.
- `AppendToTimeline` молча пропускает куски, которые налезают на занятое место. Считать клипы после вставки.
- Вставка титров и генераторов игнорирует номер дорожки и падает, если V1 заблокирована.
- Наличие метода проверять через `dir(объект)`: `hasattr` у объектов Resolve отвечает «да» на что угодно.
- Fusion считается **до** трансформаций из Inspector.
- Анимировать точку (центр, позицию) в Fusion — через путь (`XYPath`); обычная кривая молча оставит последнее значение.
- Надёжнее живого редактирования графа — собрать композицию текстом: создать пустую, экспортировать (получить правильную обвязку `MediaIn`/`MediaOut`), вписать узлы и ключи, импортировать обратно. Файл можно проверить до применения.
- Модальное окно (менеджер проектов, диалог сохранения) останавливает всё: вызовы отвечают `None` или висят.
- С 21-й версии внешний скриптинг, по сообщениям пользователей, работает только в Studio и только с настройкой **External scripting using: Local**.
- Режим без интерфейса не для рендера: проект может пропасть вместе с упавшим процессом.
