# Что проверено рендером в Resolve

**Версия: DaVinci Resolve Studio 21.1.0.14, macOS.** Прогоны 18–22.09.2026 в одноразовых проектах на синтетических клипах, рендер в ProRes 422 HQ, сравнение кадров через `ffmpeg psnr`. Проекты и пробные рендеры удалены после записи. На другой версии каждую строку сначала повторить по протоколу ниже: на 21.0.4, по чужим замерам, Fusion-композиция, созданная скриптом, читалась обратно, а рендер выходил без эффекта. На 21.1 этого расхождения нет.

Карта «что скриптом, что рукой» — [api-map.md](api-map.md). Здесь — только то, что подтверждено кадром.

## Таблица

| Маршрут | Чем подтверждено |
|---|---|
| Свой шаблон Fusion-перехода + `AddTransition` | шаблон подхвачен **без перезапуска** Resolve; окно перехода отличается и от склейки без перехода, и от встроенного Stretch Blur (PSNR 12–25 дБ), вне окна кадры совпадают точно |
| Fusion-композиция с ResolveFX на клипе | инверсия и обесцвечивание видны в рендере; вне клипа кадры равны базовому рендеру точно |
| Ключи в Fusion-композиции | искажение линзы 0 → 0,77 → 0: отличие от базового рендера нарастает и спадает симметрично вокруг среднего кадра |
| `SetProperty('CompositeMode', …)` | Hard Light против Normal на той же паре дорожек — разница около 19 дБ на всех кадрах |
| Запекание через очередь рендера вместо Render in Place | отрендеренный файл кадр в кадр равен тому же участку полного рендера (PSNR `inf`) |
| Силуэт по карте глубины слоями: запечённая карта, шум на V1, Hard Light на V2, клип-адъюстмент с Film Grain и Glow на V3 | ролик 180 кадров: бледная тёплая линия по форме, объём без белых плато; кадры сличены с референсом глазами |
| Поправка уровней карты глубины до изоляции | уровни 0,45–0,85 превращают белое плато на плоском лице в узкую полосу — видно на пробных кадрах |
| `MediaPoolItem.ReplaceClip` на запечённом клипе | новый файл встал в тот же элемент таймлайна; режим наложения и композиция сохранились |
| Слой-адъюстмент: клип на V2, у `MediaIn` в композиции источник `Background` | в рендере обработано изображение нижней дорожки, собственное содержимое верхнего клипа не появилось |
| `InsertGeneratorIntoTimeline("Adjustment Clip")` | клип создаётся, но со сдвигом соседних клипов на дорожке назначения; свойства не читаются и не пишутся |
| Вставка Fusion-генератора по имени | работает в трёх формах имени: `"Noise Gradient"`, `"/Generators/Noise Gradient"`, `"Templates/Edit/Generators/Noise Gradient"` |
| DCTL как узел композиции | эффект применился; вход `DCTLs` принимает имя **с подпапкой и расширением** (`<подпапка>/<имя>.dctl`) — простое имя, абсолютный путь и имя без расширения молча не дают эффекта; анимация по номеру кадра подтверждена ростом средней яркости 212,9 → 220,5 → 227,7 без единого ключа |
| Ключи через импорт FCPXML | таймлайн импортирован, медиа привязано, масштаб в рендере растёт по кадрам |
| Эффект на составном клипе (Compound Clip) | **не работает**: рендер кадр в кадр равен исходному (PSNR `inf`), цепочка от `MediaIn` обходится |

**Не проверено:** перенос грейда с ключами через `ApplyGradeFromDRX` — нужен эталон, который человек сделал в интерфейсе.

Две детали DCTL, без которых маршрут молча не работает: выбор файла в композиции читается обратно пустым, поэтому проверить его можно только рендером; ползунки из `DEFINE_UI_PARAMS` видны как входы `sliderFloatParam0…63`.

## Свой шаблон перехода

Скрипты ставят встроенный переход, но не меняют его настройки. Встроенные Fusion-переходы — текстовые макросы `.setting` в архиве `Templates.drfx` внутри приложения; Stretch Blur, например, — группа из направленного размытия, наложения и кривых, наружу выведены Blur Scale (по умолчанию 2) и Blur Angle (180). Копия макроса с другими значениями — это новый переход.

```bash
python3 scripts/resolve_transition_template.py list                              # встроенные переходы
python3 scripts/resolve_transition_template.py inputs --base "Stretch Blur"      # что можно поменять
python3 scripts/resolve_transition_template.py make --base "Stretch Blur" \
    --name "Cadence Stretch Blur 45" --set "Blur Scale=0.7" --set BlurAngle=45   # файл в $WORK/resolve-templates/
python3 scripts/resolve_transition_template.py make ... --install                # план: куда ляжет и как откатить
python3 scripts/resolve_transition_template.py make ... --install --yes          # запись — после согласия человека
```

- Resolve для этого не нужен, открытые проекты скрипт не трогает: он читает архив приложения и пишет новый файл.
- `--install` пишет в личную папку шаблонов Resolve — это правка его файлов, поэтому без `--yes` скрипт только печатает план. Согласие спрашивается словами: «Положить переход «Cadence Stretch Blur 45» в шаблоны Resolve? Откат — удалить файл <путь>».
- Существующий файл не перезаписывается, имя начинается с `Cadence ` и не совпадает со встроенным.
- Путь к архиву и к папке шаблонов проверен на macOS; на другой системе — `--drfx` и `--templates-dir`, путь спросить у человека, по диску не искать.
- Скрипт предупредит, если у входа поменялось только значение по умолчанию, а у инструмента за ним значения нет: такой переход проверить рендером.

Дальше переход ставится как обычный, по имени (у клипов нужен запас кадров с обеих сторон склейки, иначе ответ `None`):

```python
item.AddTransition({"type": "Cadence Stretch Blur 45", "category": "fusion",
                    "position": "end", "alignment": "center", "duration": 10})
```

Без шаблона тот же рывок даёт Fusion-композиция на двух кадрах: направленное размытие с ключами длины и угла.

## Протокол проверки нового маршрута

Так проверялась каждая строка таблицы; так же проверяется всё новое и всё на другой версии Resolve.

1. **Только одноразовый проект** с явным именем (`cadence-fx-test-<дата>`). Открытый проект человек сначала сохраняет сам; существующие проекты не трогать.
2. **Один свой короткий клип, один маршрут за раз.** Синтетический клип (градиент, сетка, цифры кадра) удобнее: видно любое изменение.
3. **Два рендера одного диапазона:** без эффекта и с эффектом. Различие подтверждает кадр или PSNR, а не чтение настроек обратно:
   ```bash
   ffmpeg -i base.mov -i fx.mov -lavfi psnr=stats_file=psnr.log -f null -
   ```
   В окне эффекта PSNR падает, вне окна — `inf` (кадры равны). Везде `inf` — эффекта в рендере нет, что бы ни отвечал API.
4. **Записать человеку:** маршрут, версия Resolve, дата, чем подтверждено (цифры PSNR или кадр рядом с референсом).
5. **Убрать за собой:** пробные рендеры удалить сразу; пробный проект — только с согласия человека.
