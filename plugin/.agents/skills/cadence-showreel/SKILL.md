# Шоурил одним дублем

**Где запускать команды.** Корень Cadence: `${CLAUDE_PLUGIN_ROOT}`. Если выше стоит путь к папке — Cadence стоит плагином: команды этого навыка запускать из этой папки (`cd` туда), свои файлы человека — в `$WORK`, не в ней. Если видна сама запись в фигурных скобках — это папка выпуска или исходников, команды запускаются из неё.

Ролик на 27–36 с (зависит от темпа трека): один непрерывный ход камеры по тёмному залу в three.js.
Пол — дорожка из ударов трека. Работы стоят экранами, камера пролетает сквозь «вход» в «результат».

| Доли | Что в кадре |
|---|---|
| 0–3 | хук: заголовок расшифровывается, экран A выключен |
| 3 | дроп: пролёт сквозь заголовок прямо в экран A, экран загорается |
| 4–10 | экран A: первая работа играет до конца, держится полсекунды |
| 11–25 | отлёт над дорожкой → экран моушна: кадры кодом меняются на каждый удар, внизу таймлайн |
| 26–29 | полёт над дорожкой, камера садится перед карточкой строки |
| 29–35 | строка печатается; на сильной доле буквы взрываются частицами в шар; облёт |
| 41–44 | карточка кода: строки расшифровываются, render до 100 % |
| 44–47 | пролёт сквозь код в экран B — вторая работа |
| 47–55 | кран, кадры-генераторы двумя рядами слетаются в кольцо-знак, название, подпись, кнопка |

Сетка — 55 долей. Сборщик сам находит дроп трека и ставит его на долю 3.

## Что спросить

- **трек** с явным дропом, длиной не меньше 55 долей после входа (при 100 BPM — 35 с);
- **две работы-видео** (A и B): путь, отрезок `from`–`to` в секундах (3–4 с самого сильного
  места) и скорость. Работы — только свои;
- **тексты:**
  - хук (три строки);
  - подписи четырёх блоков;
  - строка для шара;
  - 6–9 строк кода для карточки (свой код, без ключей и секретов);
  - фраза-итог;
  - знак: название, подпись, кнопка.

## План → согласие → сборка

```bash
W=work/<проект>                                    # рядом с набором, не внутри
python3 scripts/new_project.py <проект> --copy "<трек>" "<работа A>" "<работа B>" --film one-take-showreel
python3 scripts/track_structure.py "$W/in/<трек>"   # только чтение: темп, дроп
# в $W/film.json пути уже вписаны — поправить отрезки работ и тексты
node engine/build.mjs one-take-showreel --film "$W/film.json" --out "$W/build"
npm --prefix engine run check -- "$(pwd)/$W/build"
npm --prefix engine run snapshot -- "$(pwd)/$W/build" --no-end --at 1,2.5,8,15,20,25,32
npm --prefix engine run render -- "$(pwd)/$W/build" --quality high --fps 30 --output "$(pwd)/$W/out/showreel-raw.mp4"
python3 scripts/deliver.py "$W/out/showreel-raw.mp4" --out "$W/out/showreel.mp4"
python3 scripts/check_reel.py "$W/out/showreel.mp4"
```

Рендер идёт 3–5 минут на ноутбуке: в каждом кадре 6–16 подкадров для смаза движения.
Цвета — `--pack <id>`.

## Проверка перед показом

Снимки `snapshot` видео на экранах не перематывают: экраны проверяются **только по кадрам
готового MP4**.
```bash
ffmpeg -v error -i "$W/out/showreel.mp4" -vf "fps=2,scale=216:384,tile=9x8" -frames:v 1 "$W/out/sheet.jpg"
```
Смотреть отдельно стыки:
- дроп: заголовок → экран A, без повтора картинки;
- уход с экрана A: готовое состояние не висит дольше полсекунды;
- подлёт к строке: карточка видна заранее, звук подлёта приходит вместе с камерой;
- код → экран B: работа B начинается с первого кадра, без хвоста петли;
- знак: кольцо ровное, кнопка читается.

## Правила жанра

- **Цель подлёта всегда в кадре заранее.** Ничего не «вылезает» сбоку, перенос камеры не
  прячется вспышкой.
- **Звук описывает камеру.** Подлёт звучит, только когда камера прилетает к видимой цели.
- **Цвет работ не трогать.** Без ACES, аберрации и цветных заливок. Яркость экрана меняется
  только скаляром: экран «выключен» в хуке.
- **Работа, которая сама становится входом** (скан → фото): карточку входа перед ней не ставить —
  зритель увидит одно и то же дважды.
- **В знаке только кадры, нарисованные кодом.** Работы человека уже показаны в зале.

Приёмы целиком — `cadence-motion` (камера, пост, генераторы) и `cadence-sound` (звук по событиям).
Рецепт — `knowledge/effects-bank/code-one-take-showreel.md`.

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| «Трек короче нужного» | после дропа меньше 55 долей | трек длиннее или `music.start` раньше |
| экран A показывает конец ролика до начала | работа короче, чем держится экран | выбрать отрезок 3–4 с, скорость 0,85–1,1 |
| подписи налезают на заголовок работы B | у работы свой заголовок сверху | `screens[1].labelTop`: 300 |
| дроп не там | во вступлении есть бочка | задать `music.start` вручную: за 3 доли до дропа |
