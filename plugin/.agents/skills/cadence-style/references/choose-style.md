# Выбрать стиль вместе с человеком

Нужен, когда человек не знает, какой вид хочет: «помоги выбрать стиль», «покажи варианты», «не знаю, какие цвета», — или когда он отвечает на варианты отказами («не нравится», «слишком», «скучно»).

Главное правило: **показывать, а не расспрашивать.** Вопрос «какой цвет любите?» почти ничего не даёт; два-три варианта на его собственном кадре сразу вызывают реакцию. Каждый шаг устроен одинаково:

- 2–4 варианта на кадре человека, рекомендуемый — первым, с одной строкой «почему»;
- среди вариантов всегда есть «ближе к монохрому»;
- один вопрос за шаг, с готовыми ответами;
- отказ записывается в `work/preferences.md` и больше не предлагается.

## Шаг 0. Исходники

1. Попросить то, что уже есть: логотип (лучше SVG), заставку или интро, 1–2 кадра из роликов, название шрифта, если человек его знает.
2. Проверить, каким шрифтом на деле нарисован логотип или заставка. Часто в файле указан один шрифт, а отрисован системный: шрифта не было на машине, и программа молча подставила замену. Сравнить буквы глазами с `engine/fonts/specimen.html`; в SVG посмотреть `font-family` и есть ли текст кривыми. Расхождение сказать человеку прямо.
3. Взять опорный кадр — фон для всех листов:
   ```bash
   ffmpeg -ss 12 -i "$WORK/<проект>/in/<ролик>.mp4" -frames:v 1 "$WORK/<проект>/in/frame.jpg"
   ```
   Кадр должен быть типичным: обычная сцена ролика, а не самая тёмная или самая пёстрая.

## Шаг 1. Первый лист: три направления

Собрать три пака в `$WORK/packs/` и проверить каждый `validate_pack.py`:

| Вариант | Что внутри |
|---|---|
| строгий монохром | чёрный, белый, серые; `signal` = `ink`, выделение инверсией (светлая плашка, тёмный текст) |
| монохром плюс один акцент | те же нейтральные, один цветной тон для выделения и цифр |
| цветной | фон или карточки в цвете, акцент контрастный |

Шрифт во всех трёх один и тот же, чтобы человек сравнивал цвет, а не всё сразу. Лист:

```bash
python3 scripts/style_sheet.py --frame "$WORK/<проект>/in/frame.jpg" \
  --pack <id>-mono --pack <id>-accent --pack <id>-color \
  --headline "Короткий *заголовок*" --render
```

Показать `sheet.jpg`, рекомендацию первой. Вопрос: «Какое направление ближе?» Ответы: три варианта и «ни одно».

## Шаг 2. Реакция → следующий шаг

| Человек говорит | Что сделать |
|---|---|
| «этот цвет не нравится» | исключить тон: `wada_pick.py --avoid-hue <диапазон>`, показать 3 новых акцента |
| «этот хороший, но хочу и другие» | оставить его цвет и добавить 2–3: соседний тон (±30°), противоположный (+180°) и вариант из словаря Вады |
| «подбери по классическим сочетаниям» | `wada_pick.py --canvas <фон> --mode one-accent --diverse --limit 6` |
| «что ближе к монохрому» | `wada_pick.py --mode near-mono`; или пак без цвета, где выделение — инверсия |
| «разные цвета, но в монохроме» | `wada_pick.py --mode one-accent --diverse`: по одному тону на каждый сектор круга |
| «слишком много шрифтов», «жирно», «капсом» | одно семейство, 2–3 начертания (например 500, 600, 700), `transform: none` |
| «скучно» | одно изменение за раз: акцент ярче или заголовки крупнее; не всё сразу |
| «ни одно» | спросить, что раздражает сильнее: цвет, шрифт или плотность; сменить только это |

Команды запускаются из корня выпуска: `python3 scripts/wada_pick.py …`, `python3 scripts/style_sheet.py …`.

Диапазоны тона для `--hue` и `--avoid-hue` (градусы):

| Тон | Диапазон | Тон | Диапазон |
|---|---|---|---|
| красный | 345-15 | бирюзовый | 160-190 |
| оранжевый | 15-45 | голубой | 190-235 |
| жёлтый | 45-70 | синий | 235-260 |
| зелёный | 70-160 | фиолетовый | 260-300 |
| | | розовый | 300-345 |

`wada_pick.py` ищет в первом томе словаря цветовых сочетаний Сандзо Вады (348 сочетаний) и сразу отбрасывает те, где акцент не читается на фоне. HEX пересчитан из печатных CMYK, поэтому перед паком контраст проверяется заново валидатором. Номер сочетания назвать человеку: по нему его можно найти в книге.

Каждый новый круг — новый лист теми же командами, опорный кадр тот же.

## Шаг 3. Сузить

Обычно хватает 2–4 кругов. Итог — один пак или два режима одного стиля: строгий (монохром) и с акцентом. Второй режим не обязан быть ярким: сливочный или тёплый серый вместо белого — уже акцент.

Спросить: «Оставляем один режим или оба: строгий для схем и инфографики, с акцентом для заголовков?»

## Шаг 4. Что отдать

1. Пак или паки в `$WORK/packs/<id>/pack.json`, проверенные `validate_pack.py`.
2. Кадр выбранного пака из листа: его снимок `shots/frame-NN-at-*.png` (NN — номер пака в листе, с нуля) скопировать в `$WORK/packs/<id>/preview.png`.
3. `$WORK/packs/<id>/DESIGN.md` — правила стиля по шаблону [style-system.md](style-system.md): движение, физика, переходы, цвет для генерации, слои, список ассетов.
4. В `work/preferences.md` — что выбрано и что отвергнуто, одной строкой на решение: «оранжевый — нет», «один шрифт, без капса».

Одобренный стиль — не разрешение публиковать ролики: это отдельное решение человека.

## Чего не делать

- Не задавать больше одного вопроса за шаг и не показывать больше четырёх вариантов.
- Не возвращать отвергнутое: ни тон, ни шрифт, ни приём.
- Не менять несколько вещей между листами: человек должен видеть, что именно поменялось.
- Не показывать варианты на абстрактном фоне, когда есть кадр человека.
- Не скачивать шрифты и картинки без согласия.
