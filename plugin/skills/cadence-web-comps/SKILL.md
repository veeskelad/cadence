# Визуальные композиции для веб-поверхности

Результат — изображения или готовые briefs нужных разделов. Для выполнения кода после принятого вида использовать [cadence-reference-build](../cadence-reference-build/SKILL.md). Прочитать [процедуру разделов](references/web.md), для формы — cadence-visual-direction. Вход: цель страницы, аудитория, существующий пак, нужные разделы, точный текст и реальные активы.

Число отдельных листов определяется запросом и читаемостью. Не объединять нужные разделы в нечитаемую миниатюру и не добавлять страницы ради фиксированной квоты. Не создавать код, если просили только изображения. Генерацию подготовить через skills/cadence-generate/SKILL.md; пользовательское согласие и доступный провайдер обязательны для внешнего исполнения. Не менять стек сайта, токены Cadence или публичную поставку.

Граница и приоритеты — совместимость внутренних модулей (`knowledge/system/compatibility.md`, от корня выпуска). Дополнительные layout/material/behavior поля хранить в спецификации сцены, не расширять pack.json: актуальные поля и валидатор определяет cadence-style.
