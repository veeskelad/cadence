# Выразительные семейства как управляемые варианты

Выбирать семейство по задаче/паку, а не включать все сразу. Все значения ролей цвета/гарнитуры берутся из принятого пака. Семейство задаёт отношения, не новый обязательный бренд. Вход: смысл, материалы, формат, текущая идентичность, разрешённая выразительность. Выход: axes, grid, type_roles, spacing, surfaces, motion_roles и правила упрощения.

## Спокойная плоскость

Для обучения, обзора, заметок и интерфейсного объяснения. Один основной axis, clear grouping расстояниями, материал в стабильном frame. Заголовок/пояснение различаются без декоративного микротекста. Surface плоская, края показывают реальную границу, texture необязательна. Motion раскрывает очередность и затем останавливается. При нехватке места разбить содержание, не уменьшать его. Проверка: смысл понятен без фонового эффекта, существенное читается.

## Слоистая мягкость

Для бережного, предметного или спокойного пластичного бренда. Отделить оболочку от содержимого только когда она показывает слой/материал. Вложенный радиус связан с внешним radius и inset; не применять одинаковое округление ко всем масштабам. Свет один, тени мягкие согласно глубине, text вне blur. Можно показать умеренную отдачу предмета, но буквам дать устойчивую посадку. Проверка: глубина помогает отличить планы, вложенные рамки не отнимают content area. При дорогом фильтре заменить материал непрозрачной surface, сохранив композицию.

## Структурная типографика

Для сильного тезиса, культурного анонса, инженерного объяснения. Type формирует geometry: крупная смысловая масса и мелкое, но читаемое пояснение. Оси и интервалы явны; углы/границы следуют паку. Шкалы, registration marks и технические метки присутствуют только с функцией. Разделить ровный информационный участок и сильный акцент. Grain/halftone можно наложить на собственный декоративный материал; исходную работу не деградировать. Проверка: содержание не заменено выдуманной телеметрией; при уменьшении рамки/линии не мерцают.

## Изображение и редакционная иерархия

Для истории, наблюдения, реального продукта и людей. Определить crop по свойству, которое показывает изображение; защитить важную деталь. Заголовок рядом либо в тихой области, одна логика подписи. Материал является доказательством, не заполнением пустоты. Смена близкого/общего вида сохраняет объект и тему. Проверка: изображение уместно и узнаваемо, text не прячет доказательство, серия имеет общую грамматику.

## Сигнал и контраст

Для короткого акцента или ритма. Крупное отношение масс, ограниченное число смысловых объектов, signal выделяет одно событие. Ударный акцент чередуется с устойчивым чтением. Пружина/масштаб допустимы согласно motion-behavior, не в каждом объекте. Проверка: целевой смысл остаётся при выключенном звуке; мерцание/декор не заслоняют текст.

## Вариация без имитации случайности

Составить совместимые кандидаты из отношения объектов, material_role и motion_role. Отфильтровать по pack/safe area/evidence. Выбрать по функции и читаемости. Seed нужен только для повторяемых процедурных частиц/вариантов; запрещено изображать неисполненный скрипт или mock RNG как доказательство выбора. Случайное слово/число/asset не делает дизайн оригинальным.

При продолжении старого проекта сохранить его явно записанный профиль и события; не включать новый стиль только из-за версии инструкции. Профиль хранит geometry, pack_id, recipe_id, behavior и renderer. Обновление профиля разрешено конкретной задачей и проверяется на затронутых состояниях. Несовместимые семейства не суммировать; сознательный переход фиксирует причину и сохраняемые признаки.
