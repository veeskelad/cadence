# Элементы и эффекты Cadence

При генерации идеи сначала выбрать визуальное решение через [cadence-visual-direction](../cadence-visual-direction/SKILL.md); при проектировании действия — [cadence-motion-behavior](../cadence-motion-behavior/SKILL.md). Системы дополняют выбор конкретного элемента и не запускают повторную маршрутизацию всего ролика.

Прочитать `skills/cadence-motion/SKILL.md`, `skills/cadence-motion/references/motion-laws.md` и память о человеке. Затем [каталог](references/mechanics.md): выбрать элемент уже на стадии идеи, прочитать его карточку и заполнить спецификацию сцены. Входы, параметры, слои, формулы и критерии результата находятся в каждой карточке; внешние материалы для понимания рецепта не требуются.

Смысл сцены определяет движение. Несколько вариантов → иерархия; один объект становится другим состоянием → преобразование; порядок → таймлайн; реальное исправление → совмещённые состояния; важная деталь → линза; вывод → стабильная панель или один адрес. Набор механизмов и длина ролика выбираются по содержанию.

Исполнять через `cadence-motion`, звук — `cadence-sound`, форму целого ролика — `cadence-structures`. Использовать материал человека и его пак. Собрать ролик по сценарию, проверить итоговый MP4 по критериям выбранных карточек и правилам движка. Разрешение на задачу сохраняется; обязательного промежуточного демонстрационного ролика нет.

При конкретной ошибке сначала выполнить локальную диагностику по каталогу. Если причина не найдена, можно искать публичную официальную документацию и исходники инструмента в интернете по симптому и версии. Не передавать приватные данные; найденное исправление проверить в своей композиции. Установка, платный сервис и публикация требуют отдельного разрешения.



Для Reels/TikTok применить safe area и проверку с UI-overlay из каталога до сдачи. Ограничения передать в промпт генерации, если нужен генерируемый материал; кропы обложки проверить отдельно.
