# Шоурил одним дублем

Весь ролик — один непрерывный ход камеры по тёмному залу в three.js. Пол — дорожка из ударов трека. Работы стоят экранами на своих долях. Камера пролетает сквозь карточку входа (фото, трек, строка, код) прямо в экран результата. Если в `engine/templates/` есть `one-take-showreel` — начинать с него. Если нет — с копии `beat-reel` (там уже есть хук с расшифровкой, огибающая бочки, кадры на удар и знак): добавляется three.js-зал, камера и экраны по разделам ниже.

Годится, когда надо показать «что было на входе → что вышло» без говорящей головы. Не годится, если видео-результатов меньше двух: дубль держится на смене экранов. Больше четырёх — ролик длинный и рендер тяжёлый.

## 1. План — от трека

1. `python3 scripts/track_structure.py <трек> --hook-beats 3 --json "$WORK"/<проект>/track.json` — темп, первая доля, дроп, брейки, точка входа.
2. Каркас ролика ставится на структуру трека:

| Место в треке | Что в ролике |
|---|---|
| до дропа (2–4 доли) | хук: строка расшифровывается из глифов |
| дроп | камера пролетает сквозь хук в первый экран |
| ровная часть | экраны «вход → результат», смены на ударах |
| брейк | тихое действие: печать строки, клавиши слышно |
| возврат бита | взрыв: буквы разлетаются частицами, смена секции |
| начало новой фразы (дроп + 8, 16, 32 доли) | знак и призыв |

3. Все времена — в долях. Медленный трек даёт длинный ролик: 55 долей при 91 BPM — это 36 с.

## 2. Хук

- Обещание, которое ролик дальше доказывает. Одна-две строки.
- Расшифровка: строка открывается слева направо, на месте ещё не открытых букв бежит глиф-шум. Перед пролётом шум идёт обратно, справа налево. Шум — `glyph(i, j, кадр)` из `engine/lib/shots.js`: детерминированный хэш от строки, позиции и кадра.
- Экран за хуком до пролёта выключен (яркость ×0,1): за буквами — тёмный зал, а не чужая картинка.

## 3. Камера

- Ключи камеры — по долям: доля, позиция, точка взгляда, плавный или линейный ход.
- Скорость в ключе: внутри цепочки линейных ключей — по соседям; на стыке плавного и линейного — скорость линейного отрезка; между двумя плавными — ноль. Иначе на длинном удержании камера сама уезжает вбок.
- Момент пролёта сквозь карточку считается по ходу камеры (где камера пересекает плоскость карточки), а не числом на глаз. Пройденная карточка сразу прячется, иначе на отлёте видна её изнанка.
- Цель подлёта уже в кадре: карточка развёрнута к дорожке, взгляд заранее уходит на неё.
- Камера не проходит сквозь корпус экрана: перед разворотом — ключ отхода.
- Первые доли у стартовой камеры на дорожке пустые, иначе столбики встают стеной и пересвечивают кадр.

## 4. Мир и пост

- Дорожка — столбики по огибающей бочки (`film.reel.kick`, её считает `engine/build.mjs`), четыре на долю. Сыгранное горит основным акцентом пака, у текущей доли — вторым.
- Отражение пола: мир, отражённый по вертикали, рендерится отдельно и размывается по расстоянию.
- Bloom — несколько уровней, светится только яркая графика, видео не светится.
- Ореол экрана — только спереди и гаснет, когда камера уходит вбок. Иначе на выходе из экрана — цветная вспышка.
- Пост: мягкое плечо по максимуму канала с сохранением оттенка, виньетка, статичное зерно. Без ACES, аберрации, цветных заливок.
- Подкадровый смаз 6–16 подкадров, затвор полкадра. Небольшой подпиксельный сдвиг подкадров заодно сглаживает края.

## 5. Экраны с видео

- Видео — `VideoTexture`, сам `<video>` — прямо в `#root`.
- Если важен порядок кадров (скан превращается в фото), экран ставится без петли: до начала стоит первый кадр, после конца — последний. Иначе хвост петли покажет результат раньше времени.
- Готовое состояние держится не дольше полсекунды, иначе кажется, что видео зависло.
- Цвет экрана с исходником меняется только скаляром яркости.

## 6. Экран «трек → моушн» и финальный знак

- Canvas 1080×1920, на нём сменяются кадры-генераторы из `engine/lib/shots.js` ровно на удар. На каждой смене — короткий толчок масштаба (~1,045). Внизу — таймлайн с плейхедом и огибающей бочки, стыки кадров на ударах.
- Генераторы — функции `shot*(g, x, y, w, h, p, beat)`: `p` — доли от начала кадра, `beat` — доля ролика. Перед использованием — `configure({bpm, kick, perBeat, title, ...})`. Список: типографика, кольца, сетка, счётчик, срез, кинетика, волна, каркас, гиперпрыжок, инструменты, мозаика, полутон, изолинии, спираль, эквалайзер, глиф, орбиты, полосы, расшифровка, пятна, фигура Лиссажу; все вместе — массив `ALL`.
- 8 тонов тёплой гаммы — массив `TONES`: базовый, сливочный, коралл, янтарь, шоколад, терракота, персик, ночь. Тон включается на время отрисовки: `withTone(TONES[k], () => shotX(...))`. Соседние кадры — разного тона.
- Финальный знак собирается из маленьких живых плиток-генераторов двумя рядами по дуге, шаг по дуге одинаковый. Мелкие плитки разных тонов складываются ровнее, чем два десятка крупных одного тона.

## 7. Строка → шар

Частицы стартуют с пикселей набранной строки (точки текста из canvas), летят по дуге и собираются в шар, который «дышит» на каждую долю. На строке частицы тусклые, иначе буквы пересвечены.

## 8. Звук идёт за камерой

- Подлёт (свист, нарастание) звучит, только если камера действительно прилетает к видимой цели.
- Riser ведёт к настоящему приходу: дроп, пролёт сквозь заголовок, возврат бита.
- Клавиши печати — в брейке, где их слышно.
- Подробно — `cadence-sound`.

## 9. Частые поломки

| Симптом | Причина | Решение |
|---|---|---|
| Камера уезжает вбок посреди удержания | касательные сплайна смотрят на далёкого соседа | правило скоростей из раздела 3 |
| Стробоскоп из копий на пролёте | мало подкадров | 6–16 по скорости и повороту камеры |
| Цветная вспышка на выходе из экрана | камера прошла сквозь ореол | ореол только спереди, гаснет до ухода, ключ отхода |
| «Подлетаем, а экран вылезает сбоку» | цель вне кадра | карточка смотрит на дорожку, взгляд уходит на неё заранее |
| Пересвет плиток в финале | генераторы ярче фото | меньше усиления плиток, порог bloom выше |
