# Текущий пак: применение системы

Встроенный default — design/packs/cadence-ember/pack.json. Его коралл/янтарь, тёплый чёрный, Literata/Manrope/JetBrains Mono сохранены. Подпись сделана светлее, линии различимее, заголовок без лишнего увеличения, радиусы спокойнее, тень направленная вместо цветного свечения, accentBlob выключен по умолчанию. Разнообразие получается отношениями объектов, а не заменой бренда.

Полный машинно-читаемый контракт — [ember-direction.json](ember-direction.json). Он живёт отдельно от pack.json: текущий валидатор не допускает произвольных дополнительных полей. Агент читает профиль при работе с default Ember и применяет решения в сцене. У другого утверждённого пака сохраняется его вид, профиль Ember не навязывается.

Существующий build.mjs применяет из --pack только color CSS-переменные (one-take маршрут тоже color mapping). Он не автоматически исполняет typography/radii/shadow/decor/motion. Поэтому при реализации сцены явно связать нужные свойства с выбранным паком, сохранить корневые токены и убедиться, что визуал действительно использует их. Не заявлять смену шрифта или тени по одному успешному --pack. Новый runtime-adapter, если понадобится, — конкретная реализация задачи, а не скрытая зависимость профиля.

Для поля и текста использовать compatibility.md: реальные safe zones, чтение после посадки, motion-laws textcascade и общий track стыка. Неподвижное читаемое состояние не ограничено старым maxDoneHold0.5. Макет выдерживает длинную кириллицу, пустой список и разное число элементов; факты и скриншоты не меняются.

Проверка пакета: python3 skills/cadence-style/scripts/validate_pack.py design/packs/cadence-ember/pack.json. Проверка результата — реальные кадры экспортированного MP4; бумажная спецификация этого не заменяет. Профиль входит в выпуск 1.3; опубликованный архив 1.2 остаётся прежним.
