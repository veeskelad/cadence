# Своя библиотека эффектов внутри DaVinci Resolve

Как подключить свою папку со звуками, видеоэффектами и LUT к Resolve, чтобы искать прямо во время монтажа. Проверено 16.09.2026 на Resolve Studio 21.1. Ниже `<библиотека>` — путь к своей папке, например `~/Media/library` с подпапками `SFX`, `VFX`, `LUT`.

Скриптовый API этого не умеет: ни Sound Library, ни избранного Media Storage, ни Power Bins в нём нет. Поэтому шаги делаются руками, один раз. Агент [cadence-resolve](../../skills/cadence-resolve/SKILL.md) может подсказать их по шагам.

## Звуки — Sound Library

1. Страница **Fairlight** (переключатель страниц внизу окна).
2. В верхнем ряду кнопок слева нажать **Sound Library** — откроется панель. В меню `Fairlight` наверху экрана её нет: это панель, а не пункт меню.
3. В панели справа вверху `⋯` → **Add Library** → папка `<библиотека>/SFX`.
4. Поиск начинается от трёх символов. Чтобы увидеть всё, что проиндексировалось, ввести `***`.

Если `⋯` не нажимается, в панели выбрана база «Blackmagic Fairlight Sound Library» — переключить на свою.

Найденный звук перетаскивается на таймлайн; кнопка **Audition** слушает без вставки.

## Видеоэффекты — два разных инструмента

**Ярлык на папку.** Страница **Media** → панель **Media Storage** → дойти до `<библиотека>/VFX` → правый клик по папке → **Add Folder to Favorites**. Папка закрепляется в списке и видна в любом проекте.

**Power Bins** — то, что берётся постоянно. Они общие для всех проектов базы, в отличие от обычных бинов. В Resolve 20 и 21 включаются не правым кликом: страница **Edit** → панель **Media Pool** → значок `⋯` в правом верхнем углу панели → **Show Power Bins**. Дальше создать бин и перетащить в него нужные клипы.

Разница: избранное — ссылка на папку на диске, Power Bin — клипы уже внутри Resolve, с превью и метаданными.

## LUT

LUT копируются в каталог Resolve, в свою подпапку:

```
/Library/Application Support/Blackmagic Design/DaVinci Resolve/LUT/<своя папка>
```

Именно копия, а не символическая ссылка: по ссылке Resolve в эту папку не заходит, список остаётся пустым. Проверено 16.09.2026. Копирование в системный каталог — только с согласия человека.

Чтобы Resolve перечитал список: **Project Settings → Color Management → Update Lists**. После этого в панели LUTs на странице Color появляется своя папка.

Если библиотека LUT пополнится, копию нужно обновить заново: автоматической связи с `<библиотека>/LUT` нет.

## Что держать рядом с библиотекой

- Каталог `CATALOG.csv`: имя файла, пак, раздел, **лицензия**. Без лицензии звук не идёт в ролик на публикацию — правила в [лицензиях SFX](../sound/sfx-rules.md#лицензии-какие-звуки-можно-класть-в-свой-продукт).
- Библиотека на гигабайты — вне папки, которая синхронизируется в облако или на сервер; в рабочую папку проекта — только ссылка.
