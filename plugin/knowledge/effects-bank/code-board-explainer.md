# Ролик по словам: словарь инфографики на доске

Ещё называют: объяснялка на доске, доска объяснений, инфографика-объяснение, анимированная инфографика, моушн-инфографика, видео-инфографика, объяснение без лица, explainer, board explainer. Каждое слово словаря — это приём; у слова в таблице ниже свои синонимы в скобках колонки «Голос».

Статус: проверено рендером 19.11.2026 (все 39 слов и составная сцена: MP4 16:9 на бумаге в паке cadence-ember и 9:16 на стекле в голубом паке, `npm --prefix engine run check` без ошибок; `flat` и `snappy` — на пробах из 8 сцен; голос с якорями — на пробе 7 с)
Маршрут: resolve
Исполнитель: cadence-motion (время по словам речи — cadence-cut и `scripts/word_anchors.py`, звук — cadence-sound)
Вход: текст или голос с расшифровкой; по желанию свои картинки и знаки с правом на показ
Цена: минуты монтажа
Источник: свой покадровый разбор моушн-объяснения без съёмки (9 мин, 94 плана по машинному замеру), 19.11.2026

## Как выглядит
Лица в кадре нет, весь ролик собран из графики под голос. На каждую фразу своя сцена: число бежит к итогу на цветных плитках, чек заполняется суммой, весы перевешивают, банка доливается до черты, конвейер превращает вход в три результата, в терминале печатается запрос. Элементы сцены встают по очереди, примерно по одному на слово голоса. Между сценами камера едет по доске: сцена уезжает вверх или влево, следующая приезжает, иногда камера ныряет в сцену или кадр закрывает полоса рваной бумаги. Внутри сцены всегда что-то меняется: счётчик, печать, заливка, штамп в конце.

## Когда применять
- объясняющий ролик без съёмки: как устроен процесс, сколько это стоит, почему так, по шагам;
- голос опирается на числа, сравнения и шаги, и каждой мысли нужна своя картинка;
- ролик длиннее 30 секунд, где одна и та же плашка надоедает: словарь даёт 39 разных форм;
- вертикаль и горизонталь из одного сценария: раскладка перестраивается сама.

В одной сцене не больше трёх слов (главное и два в `with`): больше не прочитать за 3–4 секунды.

Поверх своей записи (игра, экран, съёмка) доска тоже встаёт — раздел «Доска поверх записи».

Не для: эффекта на живом видео (cadence-resolve или cadence-cut), подписей поверх говорящего (`kinetic-explainer`), вставок-доказательств поверх кадра (`film.proofs`).

**Составная сцена.** Одной фразе часто нужно два-три предмета сразу: телевизор и число зрителей, весы и итог. Поле `with` ставит рядом ещё одно или два слова со своими полями: рабочая зона делится на колонки (в вертикали — на ряды), главное слово получает 58 %, остальные встают следом с задержкой (`delay` у слова в `with`), доли можно задать `split: [0.5, 0.5]`.
```json
{"word": "телевизор", "device": "tv", "with": [{"word": "счётчик", "values": [0, 3970], "style": "tape", "caption": "зрителей у экрана"}]}
```

У любой сцены есть три общих поля: `head` (строка-заголовок сверху, содержимое съезжает ниже), `stamp` (штамп в конце сцены: `text`, `tone: good`, `at`, `x`, `y`) и `label` (ярлык внизу). Слова-варианты включают свой вид того же ключа: `нет` — значок с крестом, `телевизор` — телевизор, `телефон` и `экран` — телефон; поле сцены сильнее варианта. Русские имена принимаются без учёта регистра, «е» и «ё» не различаются; рядом с каждым словом работает и ключ (`counter` = `счётчик`). Значки — 66 залитых силуэтов из `engine/lib/board-icons.js`, у каждого русское имя (`кубок`, `копилка`, `шестерня`, `сейф` …).

## Как собрать ролик по словам
1. Текст ролика разбить на фразы: одна мысль — одна сцена, 2,5–5 секунд.
2. Каждой фразе подобрать слово по колонке «Голос». Подряд не ставить одно и то же слово: смена формы держит внимание.
3. Написать `work/<проект>/film.json`: список `words`, у каждой сцены `word`, её поля и `dur`. Пример всех 39 слов — `examples/board-explainer/film.json`.
4. Голос уже записан — время сцен берётся из речи: у сцены `at: "@якорь"` без `dur`, сцена длится до следующей. Якоря и расшифровка — `scripts/word_anchors.py` (`--words` из cadence-cut). Голос подключается полем `"voice": {"src": "голос.wav"}`.
5. Сборка в своём паке и формате:
   ```bash
   node engine/build.mjs board-explainer --film work/<проект>/film.json --pack <пак> --format 1080x1920 --out work/<проект>/build
   ```
   Без `--format` — 1920×1080. Пак человека из `work/packs/<id>/` подхватывается так же, как встроенный.
6. Кадр каждой сцены до рендера: `npm --prefix engine run snapshot -- work/<проект>/build --at <секунды>`. Смотреть, что надписи не налезают друг на друга и не выходят из рабочей зоны.
7. Рендер одним воркером: `npm --prefix engine run render -- work/<проект>/build --workers 1 --fps 30 -o work/<проект>/out/<имя>.mp4`, затем полоса кадров на каждом переходе по cadence-breakdown, шаг 2.

Маленький сценарий для начала:
```json
{
  "material": "paper",
  "words": [
    {"word": "заголовок", "text": "Сколько стоит одна чашка", "accent": ["чашка"], "dur": 3},
    {"word": "квитанция", "title": "ОДНА ЧАШКА", "rows": [{"label": "зёрна", "value": "32 ₽"}, {"label": "молоко", "value": "18 ₽"}], "total": 50, "suffix": " ₽", "dur": 4},
    {"word": "весы", "left": {"text": "зёрна", "icon": "монета"}, "right": {"text": "аренда", "icon": "дом"}, "heavy": "right", "dur": 3.4},
    {"word": "вопрос", "question": "а у вас сколько?", "button": "ПОДПИСАТЬСЯ", "dur": 4}
  ]
}
```

## Вид: пак, материал, характер
- **Пак** (`--pack`) задаёт цвета и шрифты. Палитра плиток и карточек — `signal`, `signalSecondary`, `positive` и светлый `ink`. Своя палитра сцены — `film.palette` (список цветов), свой шрифт заголовков — `film.font` (`display`, `weight`); пак при этом не меняется.
- **Материал** (`film.material`): `paper` — бумага с рваным краем, скотч, тени и зерно доски; `glass` — матовое стекло со светлым кантом, без скотча и зерна; `flat` — плоские скруглённые плашки.
- **Характер** (`film.motion`): `smooth` по умолчанию — вход 0,45 с с замедлением, без перелёта и удара; `snappy` — короткий щелчок 0,28 с с маленьким перелётом, как у вырезок, хлопающих по доске.
- **Переходы** (`transition` у сцены или `film.transition` для всех): `pan-up` (по умолчанию), `pan-left`, `push` (камера ныряет в сцену, следующая выходит из тени), `tear` (полоса рваной бумаги цветом палитры), `cut`. Два одинаковых перехода подряд допустимы, пять подряд утомляют: на смене темы — `push` или `tear`.
- **Уход в конце** (`film.exit`): последняя сцена к концу ролика уходит тем же движением — `push`, `pan-up`, `pan-left` или `fade`; уход кончается ровно на конце сцены. Без `exit` сцена стоит до последнего кадра. Нужен, когда доска — кусок внутри чужого монтажа: иначе графика пропадает на склейке за один кадр.
- **Доска поверх записи** (ещё называют: инфографика на фоне игры, графика поверх видео, коллаж поверх кадра, инфографика поверх футажа, доска на фоне ролика). Подробно — раздел «Доска поверх записи» ниже.
- **Первый кадр**: первая сцена уже собрана на кадре 0 (кадр 0 — обложка в ленте, хук стоит сразу); `film.hookAtZero: false` возвращает вход с пустой доски.
- **Печать** в `терминал` и `вопрос` сама ускоряется, если длинный текст иначе не оставит строкам времени постоять до конца сцены.
- **Числа**: разделитель разрядов — `film.defaults.sep` (`" "` для русского текста), знаки после запятой — `decimals` у сцены.
- **Рабочая зона**: в вертикали содержимое держится в x 6–82 %, y 15–75 % (место под интерфейс площадки), в горизонтали — 6–94 % и 9–91 %. Своя зона — `film.safe: [x, y, w, h]` долями кадра.

## Правила
- **Одна мысль — одна сцена**, и она получает всю фразу: вход, действие, паузу, чтобы прочитать. Лучше 8 полных сцен на минуту, чем 15 сжатых.
- **Сравнение показывается движением**: весы наклоняются, столбики растут, банка доливается. Движение идёт один раз и останавливается.
- **Числа — только настоящие.** Счётчик и чек делают число убедительным, поэтому придуманное число в них хуже, чем без инфографики. Пример в наборе подписан как условный.
- **Значки — залитые силуэты**, без тонких линий и висящих хвостов; графики тоже залиты под кривой.
- **Чужое в кадр не берётся.** Картинки (`src`) — свои или с правом на показ, знаки чужих сервисов не рисуются: вместо них нейтральный значок (`плей`, `чат`) и подпись словом.
- Штамп и обводка ставятся только туда, о чём говорит голос.

## Ограничения
- В `экран` и `фото` идут картинки; видео внутри экрана пока не перематывается вместе с роликом.
- Сюжетные мини-сцены (машина съезжает в воду, погоня) словарь не собирает: их делает cadence-motion отдельной сценой.
- Карта с пином, глобус с маршрутами и диаграмма-круг не входят в словарь.

## Доска поверх записи

Ещё называют: инфографика на фоне игры, графика поверх видео, коллаж поверх кадра, инфографика поверх футажа, доска на фоне ролика.

Доска во весь кадр своим тёмным экраном посреди ролика выглядит как дашборд. Посреди ролика по записи её ставят поверх идущих кадров: запись продолжается, чуть притушенная, бумажные предметы ложатся на неё. Своим экраном — только хук на первом кадре.

1. **Сценарий.** `film.over: true` (прозрачный фон: без подложки, зерна и затемнения старой сцены), `material: "paper"`, `transition: "push"`, `exit: "push"` (последняя сцена улетает в камеру к концу куска и не пропадает на склейке). Сцена — целое предложение голоса, от 2,5 с: короче `validateFilm` не пропустит. Предметы бумажные: `маркер` (лист со штампом), `карточки` (со штампом-вердиктом), `фото`, `карточка`. Плоские значки на пустом поле поверх записи выглядят наклейками.
2. **Планы под доской.** Общие планы без людей и без главного предмета в середине: вид сверху, улица, пейзаж, интерьер без героя. В вертикали человек стоит во всю высоту, свободно только над головой, и любая доска на нём его закроет. Кроп таких планов не ведётся по герою.
3. **Место сцены.** У каждой сцены своя рабочая зона `safe: [x, y, w, h]` в долях кадра: свободная полоса выше или ниже людей и предмета своего плана. У каждого плана свободное место своё.
4. **Сборка и проверка.** `node engine/build.mjs board-explainer --film film.json --format 1080x1920 --duration <с> --out build`, затем `npm --prefix engine run board-check -- build [--heroes heroes.json]`. Проверка находит штамп на тексте или на соседнем предмете, надпись на надписи, выход за рабочую зону, а с `--heroes` ещё и графику на лицах, людях и главном предмете. Рамки героев снимаются детектором каждые 0,25 с сцены. Не прошла — менять план под доской или `safe` сцены, а не отключать проверку.
5. **Рендер с альфой и наложение.** `npm --prefix engine run render -- build --output board.mov --format mov --workers 1` (ProRes 4444 с прозрачностью). Наложение на запись:
   `ffmpeg -i bg.mp4 -i board.mov -filter_complex "[0:v]eq=brightness=-0.05:saturation=0.85,vignette=angle=PI/4.5[b];[b][1:v]overlay=0:0:format=auto,format=yuv420p" -c:v libx264 -crf 16 out.mp4`
6. **Глазами.** Лист кадров доски с частотой от 2 к/с: штампы не на тексте, красный читается (у штампа светлая подложка), под графикой нет людей. Зелёная проверка не отменяет просмотр.
