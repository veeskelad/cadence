# Переход из тряски — рывки по 2 кадра, размытие, негативная вспышка

Статус: из гайда, рендером не проверено
Маршрут: resolve
Исполнитель: cadence-resolve
Вход: трясущиеся, «бракованные» куски живой съёмки — 3–6 пар по 2 кадра с самым резким смещением; чистый кадр для остановки
Цена: минуты монтажа
Источник: два референсных ролика от 17.09.2026 (удалены после разбора); варианты с маркером — ролики [14](https://www.instagram.com/p/DdWjGY_tGns/) и [15](https://www.instagram.com/p/DddeCoiS-fp/); вариант с масками и двухкадровой инверсией — [гайд](https://www.instagram.com/p/DeuNiZ7Dq_M/) от 22.10.2026

## Как выглядит

Брак — резкие рывки камеры — превращается в переход: серия коротких размытых рывков, негативная вспышка и резкая остановка на чистом кадре. Сборка в DaVinci Resolve; числа ниже — ориентиры.

## Когда применять

- Смена локации или главы, когда между планами есть трясущийся материал, который иначе пошёл бы в корзину.
- Усиление слабого стыка под сильную долю трека.
- Не применять там, где важна читаемость лица или предмета на стыке: рывки его съедают. Серию негативов не растягивать на весь ролик.

## Что показано в гайде

1. **Материал.** Взять куски с самой сильной тряской или рывком камеры. Из каждого оставить по 2 кадра с самым резким смещением и поставить 3–6 пар подряд.
2. **Размытие на склейках.** На каждую склейку — Fusion-переход **Stretch Blur** длиной 2 кадра. Blur Scale около 0,5–0,8, угол — по направлению рывка, на соседних склейках разный (например 180° и 43°). Настроенный переход скопировать на остальные склейки. Blur Scale и угол можно анимировать ключами.
3. **Негативная вспышка.** В середину серии поставить маркер и Adjustment Clip на 2–4 кадра. На странице Color инвертировать кривую и убрать насыщенность; режим наложения клипа подобрать по картинке (Darker Color и соседние). Встроенная замена без Adjustment Clip — Fusion-переход **Inverse Flash**. Вариант из гайдов 14–15: маркер на пике действия, стоп-кадр в X-ray-версии на 2 кадра и следом инверсия на 2 кадра — [X-ray flash](xray-flash.md). В [гайде о многослойной маске](layered-mask-reveal.md) автор на 0:00–0:14 отдельного фрагмента кладёт на стык ровно **2 кадра** Adjustment Layer с Invert и Difference, под ним обесцвечивает нарезанный исходник. В Resolve это ориентир для сравнения: проверенный локально путь к инверсии — Fusion `MediaIn=Background` → `InvertColor` на верхнем клипе либо `Inverse Flash`; точного совпадения Difference с Premiere рендером не проверяли.
4. **Удар оптикой.** Копию того же Adjustment Clip очистить от эффектов и поставить **Lens Distortion** с ключами: искажение нарастает около 0,77 и возвращается.
5. **Выход.** Остановиться на резком кадре и держать его. Акцент усиливает поворот кадра на 90°.

## Действия в Resolve

| Шаг | Страница и инструмент | Параметры | Кто делает |
|---|---|---|---|
| 1 | Edit → нарезка пар по 2 кадра | `AppendToTimeline` с `startFrame`/`endFrame` | скрипт |
| 2 | Edit → Fusion-переход Stretch Blur на каждой склейке | длина 2 кадра, Blur Scale 0,5–0,8, угол по рывку | скрипт через обход: свой шаблон перехода с нужным углом |
| 3 | Edit → негативная вспышка | встроенный переход `Inverse Flash` (`category: "fusion"`) либо `InvertColor` и нулевая насыщенность в композиции клипа на 2–4 кадра | скрипт |
| 4 | Fusion → Lens Distortion с ключами | искажение 0 → ≈0,77 → 0 | скрипт |
| 5 | Edit → hold на чистом кадре, при нужде поворот 90° | — | рука: выбор кадра-остановки |

Что ставится скриптом и какие обходы нужны — [cadence-resolve](../../skills/cadence-resolve/SKILL.md). Здесь API не пересказывать.

## Проверка

- [Eye trace](../editing/eye-trace.md): направление размытия последнего рывка ведёт взгляд туда, где стоит главный объект кадра-остановки.
- Вспышки: не больше трёх за секунду (порог [WCAG 2.3.1](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)).
- Смотреть на нормальной скорости: если пары рывков сливаются в кашу, убрать одну-две.

## Звук

Каждой паре — короткий щелчок или глитч с атакой на кадр склейки, вспышке — удар; хвост гасить к кадру-остановке. Подбор — [sound design](../sound/sound-design.md), [правила SFX в монтаже](../sound/sfx-rules.md), скилл `cadence-sound`.

## Ограничения

- Числа (Blur Scale, угол, 0,77 у Lens Distortion) сняты с экрана чужого гайда и на своём материале рендером не проверены; проверены только маршруты API для каждого шага.
- Параметры встроенного перехода Stretch Blur через API не выставляются — нужен свой шаблон перехода с нужным углом, см. [cadence-resolve](../../skills/cadence-resolve/SKILL.md).
