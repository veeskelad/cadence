# Банк эффектов

Каталог приёмов и эффектов Cadence: разобранные из чужих роликов-гайдов и проверенные рендером. Один файл — один приём. Банк пополняет скилл [cadence-breakdown](../../skills/cadence-breakdown/SKILL.md); исполняют скиллы из колонки «Исполнитель».

- **Как пользоваться.** Найти приём по колонкам «Вход» (что на руках) и «Как выглядит», открыть рецепт. Шапка рецепта — шесть полей: Статус · Маршрут · Исполнитель · Вход · Цена · Источник. По ним агент решает, кому отдать задачу, ещё до чтения тела.
- **Маршрут.** `resolve` — собирается монтажом или кодом, без генерации; `generate` — кадры создаёт модель; `both` — генерация плюс сборка.
- **Исполнители.** [cadence-motion](../../skills/cadence-motion/SKILL.md) — моушн и ролики без живой съёмки по шаблонам `engine/templates/<id>/`; [cadence-showreel](../../skills/cadence-showreel/SKILL.md) — шоурил одним дублем; [cadence-resolve](../../skills/cadence-resolve/SKILL.md) — DaVinci Resolve: живая съёмка, монтаж и эффекты на ней. «Генерация (вне Cadence, позже)» — кадры создаёт внешняя модель, которую человек выбирает и оплачивает сам; Cadence её не вызывает.
- **Цена** — словами: «минуты монтажа», «часы монтажа», «платная генерация N кандидатов». `unknown` — только у строки без рецепта.
- **Статус.** «Из гайда, рендером не проверено» — пересказ чужого ролика и перенос в Resolve на бумаге. «Проверено рендером <дата>» ставится только после пробной сборки, сличения кадров с референсом и просмотра MP4. У рецептов `code-*` это проверка шаблона, а не реального ролика.
- **Как дополнять.** Приём уже есть — дополнить его файл и поле «Источник», дубль не заводить. Новый — файл по [шаблону рецепта](../../skills/cadence-breakdown/references/recipe-template.md) и строка здесь.

## Подбор по материалу

Когда человек показывает кадры, эффект или рассуждает, что с ними можно сделать, агент сам напоминает подходящее отсюда — коротко, до трёх вариантов, первый — рекомендация. По каждому: приём → почему он ложится на эти кадры (колонка «Вход») → кто делает (колонка «Исполнитель») → статус проверки → цена словами. Плюс одно «как сделать лучше» к идее самого человека: путь внимания на стыке, звук, порог вспышек, читаемость на нормальной скорости. Совет ничего не запускает.

Приёма под материал нет — так и сказать, затем искать по имени в [словаре 424 приёмов](../techniques/INDEX.md): кто делает, читается по колонке «Как получить» (правило — в [README словаря](../techniques/README.md)). Нужна не склейка, а форма всего ролика — [форматы подачи](../editing/presentation-formats.md) и [cadence-structures](../../skills/cadence-structures/SKILL.md). Предлагать монтаж или код раньше генерации, если результат сопоставим: они бесплатны и повторяемы.

- Строки с номерами роликов — разбор 20 открытых Reels-гайдов по монтажу, 21.09.2026. - Рецепты `code-*` — шаблоны Cadence, собраны по разбору открытых роликов, сделанных кодом, и проверены рендером как пробная сборка шаблона.
