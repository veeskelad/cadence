# Shader looks — dither, halftone и другие процедурные стилизации

Статус: из гайда, рендером не проверено
Маршрут: resolve
Исполнитель: cadence-resolve
Вход: акцентный план, титульный кадр, обложка, смена регистра
Цена: часы монтажа (DCTL пишется под задачу)
Источник: ролик [05](https://www.instagram.com/p/DdbUanRTl9T/)

## Как выглядит
На клип накладывается процедурный шейдер со своей панелью параметров. В ролике один и тот же клип показан в четырёх видах: Edge Map (белые контуры на чёрном), Halftone (ч/б растр из точек), Contour (постеризация в жёлто-красно-синюю палитру с контурами), Dither (ч/б упорядоченный dithering по сетке).

## Когда применять
- стилизованный акцентный план, титульный кадр, обложка, смена регистра внутри ролика (реальность → «цифровой» слой);
- материал с крупными формами и ясным силуэтом: квантование до двух уровней съедает мелкую деталь;
- не применять на лице, когда важна мимика, на мелком тексте и на интерфейсах, которые зритель должен прочитать;
- не держать на весь ролик: приём работает как контраст к обычной картинке.

## Что показано в гайде
1. 3,4–4,8 с — загрузить картинку или видео в редактор из ролика.
2. 4,8–7,4 с — описать эффект агенту текстом; в поле набран промпт «Japanese Blockify».
3. ≈7 с (по контактному листу) — лог агента: «Starting Editor for Japanese Blockify shader, pass 2 of 2», «Creating "custom" effect», «Created "custom" effect».
4. 13,2–17,7 с — второй пример: «The agent wrote a custom shader and applied it to my clip»; ответ агента: «Building the Dither shader now and applying it to the selected clip on 1.1. I'll report back with the control[… unknown]».
5. 19,7–26,0 с — у клипа появляется эффект «custom» с панелью слайдеров, параметры правятся вручную.
6. 26,3–32,9 с — экспорт: 1920×1080, 24 fps, H.264.

Промпты дословно, оба видны не целиком:
> I want to create a fully customizable effect called "Japanese Blockify" for the currently selected clip. Build it from scratch as a custom GPU shader, apply it directly to the selected [… unknown]

> I want to create a fully customizable Dither Effect for the currently selected clip on the timeline. Build this effect from scratch as [… unknown]

Над полем виден хвост предыдущего сообщения — «- The final default values used»: промпт заканчивается списком того, о чём агент должен отчитаться; сам список `unknown`. Как выглядит «Japanese Blockify», карточка разбора не фиксирует — `unknown`.

Параметры панели «custom» с экрана (Dither): Dither Style — Bayer 8x8; Colour Mode — Colour; Dither Density 0.75; Pixel Size 1.00; Colour Levels 2.00; Threshold 0.50; Contrast 1.10; Gamma 1.00; Saturation 1.00; Pattern Scale 1.00. Мелко, по контактному листу: Pattern Rotation 0.00; Noise Seed 1.00; Animate Noise — выключен; Animation Speed 1.00; Dot Size 1.00.

## Действия в Resolve
Агент в ролике пишет код шейдера, а не генерирует изображение. В Resolve тому же соответствует DCTL: текстовый файл, который пишет агент, с собственными ползунками — раздел «Свой эффект кодом — DCTL» в [cadence-resolve](../../skills/cadence-resolve/SKILL.md).

| Шаг | Страница и инструмент | Параметры | Кто делает |
|---|---|---|---|
| 1 | Dither: написать `.dctl` | яркость пикселя сравнивается с ячейкой матрицы Bayer 8×8 по координатам кадра, цвет квантуется до N уровней | скрипт |
| 2 | Ползунки эффекта | имена как на панели из ролика: Dither Density, Pixel Size, Colour Levels, Threshold, Contrast, Gamma, Saturation, Colour ↔ Mono; стартовые значения — с экрана | скрипт |
| 3 | Fusion на клипе: узел DCTL между `MediaIn` и `MediaOut` | файл из шага 1; как указывать имя файла — в справочнике | скрипт |
| 4 | Pixel Size больше 1 | укрупнение сетки внутри DCTL выборкой соседних пикселей | скрипт |
| 5 | Halftone | тем же маршрутом: порог яркости по узору точек; Dot Size и Pattern Rotation — ползунки | скрипт |
| 6 | Edge Map, Contour | ResolveFX Edge Detect и постеризация в композиции клипа; имена инструментов в реестре Fusion не проверены | скрипт после проверки реестра, до неё рука |
| 7 | Анимация шума (Animate Noise) | номер кадра доступен внутри DCTL, ключи не нужны; в ролике выключена | скрипт |
| 8 | Look на несколько клипов сразу | клип-слой на верхней дорожке с тем же узлом | скрипт через обход (клип MediaIn=Background) |
| 9 | Look на странице Color | узел DCTL в грейде ставит человек, дальше still | рука делает still, скрипт тиражирует |

Что ставится скриптом и какие обходы нужны — [cadence-resolve](../../skills/cadence-resolve/SKILL.md). Выбор DCTL обратно не читается: применился ли эффект, показывает только рендер.

## Проверка
- [eye trace](../editing/eye-trace.md): после квантования главный объект остаётся самым контрастным пятном кадра; если растр выровнял всё — поднять Contrast или вернуть Colour Levels выше 2;
- на нормальной скорости и на экране телефона узор читается как узор; ориентир, не из гайда: смотреть на экспортированном H.264, а не во вьюере, — мелкий узор при Pixel Size 1.00 сжатие превращает в муар, тогда сетку укрупнять;
- вспышки: включённая анимация шума и быстрая смена looks дают мерцание — не больше трёх перепадов в секунду (WCAG 2.3.1).

## Звук
Статичный look на целом клипе — не событие, звук ему не нужен. Событие — включение и выключение look внутри плана: короткий цифровой слой, атака на первый кадр эффекта. Две цифровые фазы подряд — схема 6 в [рецептах сочетаний](../sound/sfx-combinations.md); правила — `cadence-sound`.

## Ограничения
- Ролик — реклама редактора в форме обзора: пошаговой инструкции нет, код шейдера не показан. Соответствие трактовки параметров (Density, Threshold) реальному шейдеру не подтверждено.
- `unknown`: полные тексты обоих промптов, вид «Japanese Blockify», цена вызова агента. «Free» в hook ролика относится к редактору; сам автор на 36–40 с оговаривает, что агент требует кредиты.
- Не подтверждено, что Edge Map, Halftone и Contour из hook сделаны тем же агентом и той же фразой.
- DCTL как узел композиции проверен рендером на общем примере (см. справочник); сами looks из этого рецепта не проверялись.
