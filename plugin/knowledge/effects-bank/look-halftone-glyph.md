# Буква из точек — полутон с бегущим светом

Статус: проверено рендером 16.11.2026 (шаблон poster-motion)
Маршрут: resolve
Исполнитель: cadence-motion
Вход: одна буква, цифра или простая форма
Цена: минуты монтажа
Источник: [Pinterest, пин 602637993938489796](https://ru.pinterest.com/pin/602637993938489796/), разобран 16.11.2026

## Как выглядит
Буква собрана из сетки кругов. Вся форма — мелкие тусклые точки, а по её штриху бежит «волна» крупных ярких точек, как свет, обходящий букву.

## Когда применять
- заставка, буквица, знак, «точки», «полутон», «пиксели», техно-эстетика;
- не для слова целиком: читается только одна крупная форма.

## Сборка кодом
Шаблон `engine/templates/poster-motion/`, сцена `halftone` (поле `glyph`). Код: `halftone(canvas, {text, font, cell})` из `engine/lib/looks.js` — маска глифа во внеэкранном canvas, точки по сетке, радиус = база + волна по углу вокруг центра формы.

## Проверка
- форма узнаётся и без волны (тусклые точки видны);
- шаг сетки не мельче 1/40 стороны: иначе в MP4 муар.

## Звук
Тихий тик на каждом «шаге» волны или ровный пэд.
