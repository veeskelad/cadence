# Приёмы для анонса: типографика, числа, переходы, знак, интерфейс

Статус: проверено рендером 19.11.2026 (пример всех сцен и переходов: MP4 16:9 и 9:16 в паке cadence-ember, `npm --prefix engine run check` без ошибок; каждый приём сверен по кадрам с образцом механики)
Маршрут: resolve
Исполнитель: cadence-motion (звук — cadence-sound)
Вход: текст анонса, числа из своего отчёта, название или знак продукта; свои картинки не нужны
Цена: минуты монтажа
Источник: Cadence. Механика знакома по анонсам продуктов и открытым каталогам моушна, код и вид свои

## Как выглядит
Короткий ролик или вставка из сцен по 2–6 секунд. Ключевые слова открываются из-под плашек, фраза проявляется сквозь косые полосы, число растёт с переносом в старший разряд, процент заливает соты, поле запроса разрастается в окно с результатом. Между сценами кадр режется на ленты или колонки, в конце гаснет как кинескоп. Цвета и шрифты берутся из пака, фон сцены задаёт тон.

## Когда применять
- анонс продукта, версии или даты: 5–10 сцен на 20–50 секунд;
- одна сцена как вставка в другой ролик: число, заставка знака, сочетание клавиш поверх записи экрана;
- смена сцен, где нужен заметный переход;
- вертикаль и горизонталь из одного сценария.

Не для объяснения по шагам с голосом (шаблон `board-explainer`, там свой словарь из 39 слов), подписей поверх говорящего (`kinetic-explainer`) и эффектов на живом видео (cadence-cut, cadence-resolve).

Переходы ставятся полем `via` у входящей сцены.

| Переход | Ключ | Что происходит | Длина |
|---|---|---|---|
| `встык` | cut | смена без движения, стоит по умолчанию | 0 |
| `ленты` | bands | кадр режется на горизонтальные ленты, соседние уезжают в разные стороны и тянут новую сцену, на швах едут цветные блоки | 1,2 с |
| `колонки` | columns | то же вертикальными колонками | 1,3 с |
| `выключение` | poweroff | уходящая сцена сжимается в светящуюся строку, строка в точку, точка гаснет; следующая сцена начинается с чёрного | 0,7 с |

`"end": "выключение"` в корне сценария гасит последнюю сцену.

## Как собрать
1. Разложить анонс на сцены: одна мысль на сцену. Подряд не ставить два приёма из одной группы.
2. Написать `work/<проект>/film.json`: список `moves`, у каждой сцены `move`, её поля и по желанию `dur`. Без `dur` сцена берёт длину сама, с запасом на чтение. Пример всех слов — `examples/moves/film.json`.
3. Собрать в своём паке и формате:
   ```bash
   node engine/build.mjs moves --film work/<проект>/film.json --pack <пак> --format 1080x1920 --out work/<проект>/build
   ```
   Без `--format` кадр 1920×1080.
4. Проверить сборку: `npm --prefix engine run check -- work/<проект>/build`. Ошибок быть не должно.
5. Рендер одним воркером: `npm --prefix engine run render -- work/<проект>/build --workers 1 --fps 30 -o work/<проект>/out/<имя>.mp4`. Затем посмотреть кадры MP4 в середине каждой сцены и на каждом переходе.

Сценарий для начала:
```json
{
  "moves": [
    {"move": "эмбарго", "lines": ["Версия [2.0]", "выходит [в пятницу]."], "slug": "Под эмбарго до пятницы", "lifted": "Эмбарго снято"},
    {"move": "соты", "value": 86, "label": "задач закрываются без правок", "via": "ленты", "tone": "surface"},
    {"move": "прожектор", "text": "Ритм"}
  ],
  "end": "выключение"
}
```

## Вид и время
- **Пак** (`--pack`) задаёт цвета и шрифты. Свой шрифт всего ролика — `film.font` (`display`, `weight`), одной сцены — `font` и `weight` у сцены. Имя шрифта берётся из `engine/fonts`.
- **Тон сцены** (`tone`): `dark` по умолчанию, `light` (светлый фон, тёмный текст), `surface` (поверхность пака), `accent` (фон цветом акцента). Соседним сценам стоит давать разный тон, тогда ленты и колонки читаются.
- **Вход** у всех приёмов один: 0,45 с с замедлением, без отскока. Единственный мах мимо цели есть у луча прожектора, это сама механика поиска.
- **Первый кадр** не пустой: первая сцена промотана на полсекунды, кадр 0 служит обложкой в ленте. `film.hookAtZero: false` возвращает вход с пустого кадра.
- **Длина** сцены считается по содержимому: длинный запрос печатается дольше, шесть плашек уходят дольше трёх. Заданный `dur` короче механики сборка не примет и назовёт нужное число.
- **Клавиши** подписаны словами (`Cmd`, `Shift`): так читается на любом компьютере. Значки `⌘ ⇧ ⌥` включает `glyphs: true`, они рисуются шрифтом системы и вне macOS могут выпасть. `at` у сочетания — секунда, когда нажата последняя клавиша; на неё ставят то, что сочетание открывает.
- **Рабочая зона** та же, что у ролика по словам: в вертикали x 6–82 %, y 15–75 %. Своя зона — `film.safe: [x, y, w, h]` долями кадра. Знак в `прожекторе` и карточка в `гармошке` стоят по центру кадра.

## Правила
- **Всё рисуется залитыми фигурами.** У сот пустые ячейки стоят приглушённой заливкой без контура, у разбора нет соединительной скобки, луч разлома идёт плашкой. Тонких висящих линий в приёмах нет.
- **Числа только настоящие.** Перенос и соты делают число убедительным, придуманное число в них хуже пустого кадра. Пример в наборе условный.
- **Эмбарго держит секрет честно:** пока плашка закрыта, слова под ней в кадре нет.
- **Переход ставится на смену мысли.** Подряд два одинаковых перехода утомляют, на 10 сцен хватает двух-трёх.
- **Знак свой.** В `прожектор` и `гармошку` идёт своё название или свой файл. Встроенного значка у приёмов нет, чужие знаки не рисуются.

## Ограничения
- Сцены стоят в ролике целиком; слово приёма внутри сцены `board-explainer` пока не работает.
- `запрос` показывает условную страницу из трёх блоков. Свой снимок экрана в окно не подставляется.
- `клавиши` держат на экране одно сочетание; прежнее уходит, когда входит следующее.
- Ленты и колонки перерисовывают копии двух сцен на каждом кадре перехода. Тяжёлую сцену с видео так резать не стоит.

## Звук
Сцены идут без звука. Музыка и акценты на событиях (плашка ушла, кружок перелетел, клавиша нажата, кадр погас) — cadence-sound.
