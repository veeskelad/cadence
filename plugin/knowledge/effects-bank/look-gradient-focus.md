# Плывущий градиент и фокус по слоям — постер с живым цветом

Статус: проверено рендером 16.11.2026 (шаблон poster-motion, сверено кадрами с референсом)
Маршрут: resolve
Исполнитель: cadence-motion
Вход: 3–6 цветов градиента, заголовок, дата и 4–8 мелких подписей
Цена: минуты монтажа
Источник: [Pinterest, пин 48202658506302202](https://ru.pinterest.com/pin/48202658506302202/), разобран 16.11.2026

## Как выглядит
Весь фон — мягкие цветные пятна (голубой, оранжевый, розовый), которые медленно перетекают, с лёгким зерном. Поверх постерная типографика: крупный заголовок, дата, мелкие белые подписи. Крупные слои по очереди уходят в расфокус и возвращаются в резкость, мелкие подписи остаются резкими. Получается «дышащий» постер, кадр всё время живой.

## Когда применять
- обложка, анонс события, заставка, фон под цитату; «градиенты», «блюр», «размытие», «как постер», «в стиле Apple»;
- не применять под длинный текст для чтения: расфокус мешает.

## Что видно в оригинале
1. Градиент без резких границ, пятна сдвигаются за 3–5 с, цвета смешиваются на стыках.
2. Волна фокуса проходит по крупным слоям примерно за 3–4 с: один слой резкий, соседние размыты.
3. Мелкие подписи белые, тонкие, стоят по сетке и не размываются.

## Сборка кодом
Шаблон `engine/templates/poster-motion/`, сцена `gradient` (поля `title`, `big`, `labels`, `colors`, `base`). Код: `meshGradient(слой, {colors, base, seed})` из `engine/lib/looks.js` рисует пятна на маленьком canvas и растягивает его на кадр, это дешевле огромного `blur()`; `focus(элемент, k)` и `focusWave(i, n, t, период)` ведут фокус по слоям.

## Проверка
- в MP4 нет полос на градиенте: зерно включено (на снимках браузера полосы не видны, судить по кадрам из файла);
- мелкий текст контрастен на самом светлом месте градиента;
- в каждый момент хотя бы один крупный слой резкий.

## Звук
Пэд или мягкая музыка; удар не нужен.
