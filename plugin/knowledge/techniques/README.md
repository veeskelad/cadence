# Словарь приёмов: 424 приёма кино и монтажа

Единый словарь для съёмки, монтажа, моушна и постановки задачи генерации. У каждого приёма есть имя, условие применения, отличие от похожего приёма и способ получить его без генерации — на съёмке или в постпродакшне.

Словарь опирается на структуру открытого каталога [melies.co/cinematic-techniques](https://melies.co/cinematic-techniques): 13 разделов, 424 приёма, прочитаны 16.09.2026. Все формулировки здесь — пересказ своими словами, тексты и промпты каталога не копировались.

## Как пользоваться

1. Сначала событие и смысл кадра, потом название приёма. Приём — это словарь и проверочный список, а не разрешение поставить эффект.
2. Нашёл строку в `INDEX.md` — открой файл раздела и прочитай строку приёма целиком.
3. Соседние приёмы легко спутать: match cut и graphic match, Rembrandt и Loop, Dappled и Gobo, Split Screen и Match Split. Для таких пар в файлах выписано различие — сверься до постановки задачи.
4. В монтаже бери колонку «Съёмка или пост»: там названы инструменты DaVinci Resolve. Если приём честно получается только на площадке или только генерацией, это сказано прямо. Не выдавай имитацию за съёмку.
5. Для генерации бери колонку «Что задавать в промпте»: термин приёма плюс параметры. Расплывчатые слова вроде «кинематографично» и «бесшовный переход» не работают.
6. Кто делает — по колонке «Как получить» в `INDEX.md`:

   | «Как получить» | Кто делает |
   | --- | --- |
   | `Съёмка: …` | человек на съёмке; в посте не имитировать |
   | `Пост: …` | [cadence-resolve](../../skills/cadence-resolve/SKILL.md): инструмент Resolve и статус API (скрипт / обход / рука) названы в строке раздела |
   | `Термин …` | генерация (вне Cadence, позже): готовая формулировка для промпта |
   | `Только съёмка` | честно сказать, что нужна площадка, и не имитировать |

   Статус API в строке поста: `скрипт` — ставится целиком через API (Fusion-композиция на клипе, свойства клипа); `обход` — нужный узел API не ставит, но есть замена (грейд через DRX, ResolveFX внутри Fusion); `рука` — один шаг делается только в интерфейсе (трекер, маска по контуру, подчистка), остальное скриптом.

   Приём из моушн-графики без живой съёмки (частицы, шейдер, текст, 3D-объект) делает [cadence-motion](../../skills/cadence-motion/SKILL.md) — сначала проверь [банк эффектов](../effects-bank/INDEX.md), там готовые шаблоны.

7. Если у приёма есть рецепт в [банке эффектов](../effects-bank/INDEX.md), в конце строки раздела стоит «Рецепт в банке: …», а в рецепте — строка `Словарь:` с обратной ссылкой. Так X-Ray и Flash Cut связаны с [xray-flash](../effects-bank/xray-flash.md), Graphic Match — с [generative-match-cut](../effects-bank/generative-match-cut.md). Ссылка ставится только на тот же приём, соседний не связывается. Исполнять по рецепту: его статус проверки главнее строки словаря.

## Границы

- Примеры фильмов в строках приёмов покадрово не проверялись.
- Числа в колонках («45° вбок», «3–5 ступеней») — ориентиры для постановки, а не измерения конкретного фильма.
- Правила остальной базы приоритетнее: путь внимания через склейку — [eye trace](../editing/eye-trace.md), звук по событию — [sound design](../sound/sound-design.md) и [правила SFX](../sound/sfx-rules.md), переходы со съёмки — [монтажные переходы](../editing/transitions.md).
