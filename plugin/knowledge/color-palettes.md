# Палитры-референсы: Сандзо Вада

Это **образцы для выбора цветовых отношений**, а не готовый StylePack и не «лучшие» для любого проекта цвета. Перед применением в кадре назначить роли canvas/surface/ink/signal, выбрать пропорции, проверить контраст и реальный материал по [процедуре](../skills/cadence-visual-direction/references/palette-selection.md). `design/packs/` предназначен только для готовых, проверенных стилей; не переносить туда книжные сочетания напрямую.

## Первый том: A Dictionary of Color Combinations

В `knowledge/palettes/sanzo-wada/vol1-colors.json` сохранён **полный проверенный набор: 348 сочетаний из 159 цветов**, где каждому цвету соответствуют его номера палитр. Посмотреть любое сочетание из корня Cadence: `python3 scripts/wada_palette.py 33` (номер от 1 до 348). Команда выводит имя, HEX и исходный CMYK, но не назначает роли StylePack: для ролика их выбирают под конкретную сцену и проверяют контраст. Подобрать сочетания под фон и вкус (один акцент, ближе к монохрому, без отвергнутого тона) — `python3 scripts/wada_pick.py --help`.

Для ориентира четыре сочетания № 033–036 видны на [официальном развороте издателя](https://shop.seigensha.com/cdn/shop/files/IMG_8732_grande.jpg?v=1693539614). Имена/номера/CMYK собраны в [цифровой версии Matt DesLauriers](https://github.com/mattdesl/dictionary-of-colour-combinations) (MIT, на основе оцифровки Dain M. Blodorn Kim); RGB/HEX получены преобразованием CMYK через SWOP v2 → sRGB, **не замером печатного экземпляра**. На экране и в другом цветовом профиле оттенки могут отличаться. Изображения издателя сюда не копировать.

| № | Цвета цифровой версии | Характер для пробы |
|---|---|---|
| 033 | Raw Sienna `#BB7125` + Slate Color `#34454C` | тёплая охра на холодном графите |
| 034 | Eosine Pink `#F37F94` + Neutral Gray `#B6BFC1` | лёгкий розовый против спокойного серого |
| 035 | Light Brown Drab `#B59392` + Carmine Red `#A62C37` | пыльная розовато-коричневая база и насыщенный красный |
| 036 | Sulphine Yellow `#C19F2C` + Turquoise Green `#B5DECC` | горчичный с бледной мятой |

Оригинальная книга: [Seigensha, ISBN 978-4-86152-247-5](https://www.seigensha.com/books/978-4-86152-247-5). Не приписывать ей расчётные HEX: книга печатает CMYK.

## Прикладной том: февраль

Полного открытого набора второго тома не найдено: **его 72 сезонные палитры и исторические примеры не сохранены как данные**. На [официальном сезонном развороте](https://shop.seigensha.com/cdn/shop/products/978-4-86152-772-2_02_grande.jpg?v=1616579771) справа видна пятицветная февральская гамма: чернильно-синий → сливовый → бледно-жёлтый → охристый → дымчато-голубой. Если нужна на экране, сначала работать с отношениями и свериться с книгой/чипами: фото при неустановленном освещении **не даёт достоверных HEX/CMYK**. Иллюстрация с условными цифровыми значениями находится в исследовательском артефакте, не в поставке Cadence.

Оригинальный том: [Seigensha, ISBN 978-4-86152-772-2](https://www.seigensha.com/books/978-4-86152-772-2). Для кимоно и графики того периода у издателя есть [отдельный разворот](https://shop.seigensha.com/cdn/shop/products/978-4-86152-772-2_04_grande.jpg?v=1616579771); графику и страницы не использовать в своём ролике без прав на изображения.
