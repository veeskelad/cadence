# Озвучка текста локальным голосом

**Когда брать.** Нужен закадровый голос или черновая озвучка сценария без микрофона: по-русски и ещё на 22 языках,
по желанию тембром из образца. Всё считается на этой машине, ключей и оплаты нет.

**Что дать.** Текст (`--text` или `--text-file`), язык (по умолчанию `ru`), по желанию образец голоса.

**Команда** (от корня Cadence):

```bash
python3 modules/voice-synthesis-toolkit/run.py --text-file <сценарий.txt> --language ru --project <проект>
```

**Что получится.** `$WORK/<проект>/out/voiceover.wav` (24 кГц, моно). Длинный текст режется по предложениям,
между ними пауза 0,35 с (`--pause`). Готовый файл не перезаписывается без `--overwrite`.

> Клонирование чужого голоса: только с согласия владельца голоса. Образец (`--voice-ref`) берём, если человек сказал, чей это голос и что владелец согласен.

## Шаги

1. Проверка без расчёта: `--dry-run` показывает модель, объём весов и есть ли они в кэше.
2. Зависимости: `python3 scripts/module_setup.py status voice-synthesis-toolkit`. Нет — спросить человека и только после
   согласия `python3 scripts/module_setup.py install voice-synthesis-toolkit` (около 4 ГБ вместе с весами).
3. Веса скачиваются отдельно и только по согласию: `--allow-download` (с Hugging Face, кэш `~/.cache/huggingface`).
   Без флага запуск идёт без сети и останавливается, если весов нет.
4. Запустить. Первую фразу послушать, потом гнать весь сценарий: тембр и темп видны сразу.
5. Свести с музыкой — `scripts/voice_music_mix.py` (навык `cadence-sound`).

## Параметры

| Параметр | Что делает |
|---|---|
| `--language` | `ru`, `en` и другие из 23 (ar, da, de, el, en, es, fi, fr, he, hi, it, ja, ko, ms, nl, no, pl, pt, ru, sv, sw, tr, zh) |
| `--variant` | `multilingual` (по умолчанию, все языки), `base`, `turbo`, `nano` (три последних только английский) |
| `--voice-ref` | образец голоса, 10 секунд чистой речи без музыки; без него звучит встроенный голос модели |
| `--exaggeration` | выразительность 0..1 (0,5); выше — театральнее |
| `--cfg-weight` | насколько жёстко держаться образца и темпа (0,5); ниже — спокойнее и медленнее |
| `--device` | `auto` (cuda, потом mps, потом cpu), `cuda`, `mps`, `cpu` |
| `--out`, `--project`, `--name` | куда писать |

## Язык и железо (проверено по коду)

- **Русский:** есть в варианте `multilingual` (`language_id="ru"`, список `SUPPORTED_LANGUAGES` в `src/chatterbox/mtl_tts.py`).
  `turbo`, `nano` и `base` только английские. Для русских ударений код использует пакет `russian_text_stresser`;
  в зависимости он не входит. Без него голос работает, ударения хуже. Цифры и латиницу в тексте лучше писать словами.
- **Железо:** NVIDIA (CUDA), Apple Silicon (MPS) или процессор. На процессоре медленно: абзац может считаться минутами.

## Веса моделей (в репозиторий не кладутся)

Скачиваются при первом запуске с `--allow-download`; объём на диске — оценка:

| Вариант | Модель | Объём |
|---|---|---|
| `multilingual`, `base` | chatterbox (файлы t3_mtl23ls_v2.safetensors или t3_cfg.safetensors, s3gen, ve, conds) | около 3 ГБ |
| `turbo` | chatterbox-turbo | около 2 ГБ |
| `nano` | chatterbox-nano | около 1 ГБ |

## Ограничения

- Модель вшивает в каждый файл неслышимый водяной знак; в озвучке он остаётся, обходить его не нужно.
- Образец короче 5 секунд отклоняется моделью `turbo`; грязная запись даёт грязный тембр.
- Платформы публикации могут требовать пометку «синтезированный голос»: сказать человеку до выкладки.
- Файлы `example_*.py` в папке: чужие примеры, пишут в текущую папку и сами качают веса; для работы брать `run.py`.
- Веб-интерфейсы модели убраны: они открывали публичную ссылку.
- Статус `beta`: запуск проверен только в режиме `--dry-run`, расчёт на этой машине не прогонялся (зависимости не стоят).
