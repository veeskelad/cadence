# Озвучка с тембром из образца и манерой словами

**Когда брать.** Нужно озвучить текст тембром из короткого образца, прочитать его на другом языке тем же голосом
или задать манеру словами («быстро», «медленно», «с улыбкой»). Модель тяжёлая: нужна видеокарта NVIDIA и Linux.
На Mac без NVIDIA брать `mlx-audio-engine`, на любом железе с русским языком — `voice-synthesis-toolkit`.

**Что дать.** Текст, образец голоса (локальный wav, 3–30 секунд чистой речи), для `zero-shot` — слова из образца,
папку с весами `--model-dir`.

**Команда** (от корня Cadence):

```bash
python3 modules/expressive-voice-synth/run.py --mode cross-lingual --text-file <сценарий.txt> \
  --prompt-wav <образец.wav> --model-dir <папка весов> --project <проект>
```

**Что получится.** `$WORK/<проект>/out/voiceover.wav`. Длинный текст режется по предложениям (до 160 знаков в куске),
между ними пауза 0,3 с. Готовый файл не перезаписывается без `--overwrite`.

> Клонирование чужого голоса: только с согласия владельца голоса. Образец берём, если человек сказал, чей это голос и что владелец согласен.

## Режимы

| `--mode` | Что делает | Нужно дополнительно |
|---|---|---|
| `zero-shot` | тембр и манера образца | `--prompt-text`: дословно, что сказано в образце |
| `cross-lingual` | тембр образца, текст на любом языке модели | в тексте можно ставить теги вроде `[breath]`, `[laughter]` |
| `instruct` | тембр образца и манера словами | `--instruct`, например «Говори быстро и бодро» |

## Шаги

1. Проверка без расчёта: `--dry-run` показывает режим, папку весов и есть ли она.
2. Зависимости: `python3 scripts/module_setup.py status expressive-voice-synth`. Нет — спросить человека и только после
   согласия `python3 scripts/module_setup.py install expressive-voice-synth` (около 12 ГБ вместе с весами; ставится
   пакет под NVIDIA CUDA 12).
3. Добавить пакет `matcha`: папка `third_party/Matcha-TTS` в модуле пуста, код без этого пакета не запускается. Команда
   (сеть, с согласия): `<python модуля> -m pip install --no-deps matcha-tts`, где путь к python даёт
   `python3 scripts/module_setup.py python expressive-voice-synth`. Эту установку на этой машине не проверяли.
4. Веса: положить в `--model-dir` (по умолчанию `~/.cache/cadence/models/Fun-CosyVoice3-0.5B`). Скачать их скрипт может
   только с `--allow-download` и согласия человека, имя модели задаёт `--model-id`.
5. Запустить на одной фразе, послушать, потом гнать весь сценарий.

## Язык и железо (проверено по коду)

- **Русский:** в коде его нет. Встроенная обработка текста различает только китайский и «остальное как английский», поэтому
  для кириллицы скрипт её отключает; числа и латиницу пиши словами, ударения не размечаются. Умеет ли русский сама модель, по коду
  не проверить (это решают веса): сделай пробную фразу и послушай. Основные языки модели: китайский, английский, японский, корейский.
- **Железо:** NVIDIA (CUDA) или процессор; `mps` в коде нет, на Apple Silicon только процессор, очень медленно. Ускорение через
  TensorRT и vLLM из исходного проекта скриптом не включается.

## Веса модели (в репозиторий не кладутся)

Модель `Fun-CosyVoice3-0.5B`, скачивается с ModelScope. Полное имя для скачивания лежит в `run.py` (параметр `--model-id`): оно взято
из документации модели, перед скачиванием его надо сверить. Объём: около 5–10 ГБ, оценка. Более старые `CosyVoice2-0.5B` и `CosyVoice-300M`
код тоже понимает: путь к их папке даётся в `--model-dir`.

## Ограничения

- Для обработки текста код сам берёт пакет `wetext`; тянет ли он свои данные из сети при первом вызове, не проверено: если да, это тоже сеть, спросить человека.
- Файл `requirements.txt` оставлен как в исходном проекте: в нём есть пакеты серверов и обучения (gradio, fastapi, grpc, tensorrt, deepspeed), для озвучки лишние; урезать список можно после первой удачной установки.
- Статус `beta`: запуск проверен только в режиме `--dry-run`, расчёт не прогонялся (нет видеокарты и зависимостей).
- Серверы, обучение и веб-интерфейс из исходного проекта убраны: для озвучки они не нужны, а веб-интерфейс слушал всю сеть.
- Платформы публикации могут требовать пометку «синтезированный голос»: сказать человеку до выкладки.
