# Анимационный ролик под озвучку

**Когда брать:** человек принёс готовую озвучку и хочет ролик без съёмки: разбор кейса, новости, объяснение,
обучающий ролик. Картинка рисуется кодом (HTML, CSS 3D, Canvas) и рендерится покадрово.

**Что дать:** озвучку (`mp3`/`wav`), по желанию музыку, нужные пропорции (9:16, 16:9 или оба).

**Команда (старт проекта):**
`cp -R modules/motion-graphics-pipeline/motion-kit "$WORK/<проект>/src" && cd "$WORK/<проект>/src" && bash tools/setup.sh`

**Что получится:** ролики 16:9 и/или 9:16 (mp4, HEVC), обложки 3:4 и 4:3, раскадровка, список источников.

Оглавление: [Шаги](#шаги) · [Состав шаблона](#состав-шаблона) · [Ограничения](#ограничения)

## Шаги

Полный порядок работы, правила раскадровки и вопросы человеку: [guides/motion-graphics-pipeline.md](guides/motion-graphics-pipeline.md)
(по-китайски; пункты нумерованы). Коротко:

1. Спросить пропорции и, если музыки нет, нужна ли синтезированная.
2. Скопировать шаблон `motion-kit/` в папку проекта (команда выше), шаблон не менять.
3. `bash tools/setup.sh` ставит Python-пакеты, Chromium для Playwright и модель распознавания речи.
   Это загрузки из сети: только с согласия человека.
4. Озвучка и музыка: `tools/mix.sh`, распознавание слов `tools/asr.py`, биты `tools/beats.py` или `tools/make_bgm.py`.
5. Определить тип ролика, предложить 2–3 визуальных направления, написать раскадровку и дождаться «да».
6. Собрать сцены в `scenes.js`, проверить кадры `tools/preview.py`.
7. Рендер частями `tools/segs.sh`, склейка `tools/finish.sh`, обложки `tools/cover_shot.py`.
8. Результаты сложить в `$WORK/<проект>/out/`, отчёт: раскадровка, источники, что решено за человека.

## Состав шаблона

Подробная таблица компонентов и команд: [motion-kit/README.md](motion-kit/README.md). Готовые наборы:
объяснение (графики, сравнения, таймлайны), новости (карточки, бегущая строка), обучение (окна, курсор,
подсветка, терминал), интерфейс продукта (телефон, уведомления), вертикальный формат, переходы с камерой,
финальные плашки. Пример целого ролика: `motion-kit/examples/muse/`.

## Ограничения

- Свой рендерер на Playwright и ffmpeg, не движок Cadence `engine/`: ставится отдельно, по согласию.
- Нужны ffmpeg и китайский шрифт Noto Sans CJK SC (если его нет в системе, `setup.sh` скачивает его).
- Рендер долгий (60 кадров/с, размытие в движении): запускать в фоне, ждать файл `segs*/ALLDONE`.
- Не придумывать новости, цифры и цитаты; схематичные данные подписывать «схема».
- Материалы с сайтов брать только из разрешённых источников; источники и лицензии писать в `a/来源.md`.
- Шрифт Inter в `motion-kit/a/fonts/` под лицензией OFL, заметка рядом.
- Справка и пример раскадровки написаны по-китайски.
