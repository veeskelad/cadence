# Анимация в стиле художников и эпох, объясняющие фрагменты

**Когда брать.** Человек хочет анимацию, нарисованную кодом: в стиле художника или эпохи (Ван Гог, Моне, баухаус,
пиксель-арт, тушь, наскальная живопись и ещё десятки), «историю искусства» сменой стилей в одной комнате, либо
объясняющий фрагмент под речь: белая доска, формулы в духе 3Blue1Brown, диаграммы научпопа, график, динамическая
типографика, экран продукта.

**Что дать.** Тему; для фрагмента `spec.json` (примеры в `scripts/engine/examples/`); для целого ролика раскадровку
в виде таблицы кадров (шаблон `references/镜头表模板.md`); размер (1920×1080 или 1080×1920).

**Команда.**
`python3 modules/calligraphy-art-motion/scripts/engine/render.py --spec <spec.json> --out "$WORK/<проект>/out/clip.mp4"`
(одна сцена кадрами: `--solo <id> --stills 0.2,0.6 --out <папка>`).

**Что получится.** MP4 H.264 без звука (или PNG-кадры), точной длины из спецификации; затем проверка кадров и выдача
с карточкой, в которой вердикт пишет скрипт, а не автор.

## Установка и ограничения

- Движок рисует на Canvas в безголовом Chromium через Playwright. Установка отдельная и только с согласия человека:
  `python3 scripts/module_setup.py install calligraphy-art-motion` (пакеты Python около 300 МБ), затем один раз
  `<python модуля> -m playwright install chromium` (около 170 МБ, сеть). Python модуля:
  `python3 scripts/module_setup.py python calligraphy-art-motion`. Нужен ffmpeg.
- Выход по умолчанию писать в `$WORK/<проект>/out/`; сам движок лежит в `modules/` и не меняется (его можно
  скопировать в проект: `cp -R scripts/engine <проект>/engine`, если нужно править сцены).
- Сеть нужна только `scripts/analyze/fetch_reference.py` (скачивает картины-образцы из открытого каталога) и только по
  просьбе человека. Рендер, проверка и выдача работают офлайн. Ключей сервисов нет.
- Голоса и картинок модуль не делает: озвучка в `cadence-sound`, картинки в `cadence-generate`. Готовых демо-фильмов,
  обзорных картинок и шрифтовых начертаний 800/900 в поставке нет (подробности в справке).
- Шрифты в основном латинские и китайские; кириллицу в экранных надписях проверять кадром до обещаний.
- Стили: 36 уже сделанных и 16 исследовательских рецептов. Рецепт описывает ремесло (мазок, цвет, свет), а не готовую
  композицию; композицию под тему строить заново.

## Порядок работы

1. Решить, какой нужен путь: ролик в художественном стиле, объясняющий фрагмент или разбор образца. Таблица маршрутов
   и правила «шести способов испортить» в [guides/art-motion.md](guides/art-motion.md).
2. Раскадровка по шаблону и её проверка: `python3 modules/calligraphy-art-motion/scripts/storyboard_lint.py <раскадровка.md> [--script текст.txt]`.
   Пока есть красные пункты, код не писать.
3. Фрагмент: выбрать грамматику по таблице в `references/09-视频动画语法.md`, взять пример из `scripts/engine/examples/`,
   проверить `scripts/clip_lint.py spec.json`, отрендерить командой выше. Один фрагмент не длиннее 8 секунд.
4. Художественная сцена: карточка стиля в `references/风格配方/`, сцена `scripts/engine/scenes/<id>.js`, рендер
   `render.py --solo <id> --stills ... --out <папка>`.
5. Склейка кадров жёсткими резами и, если нужно, звук: `ffmpeg` по командам из справки.

## Проверка и выдача

- Кадры и динамика: `scripts/qa.py --spec <spec.json> --out <папка>` (для целого проекта `--project <копия движка>`).
- Версия по параметрам: `render.py --spec <spec.json> --audit` проверяет текст на выход за край и перекрытия.
- Выдача: `scripts/deliver.py <ролик.mp4> --spec <spec.json> --out <папка выдачи>`. Красный вердикт значит «не выдавать»:
  скрипт не копирует ролик и печатает, что исправить. Карточку выдачи пишет скрипт, автор дополняет только раздел
  «Описание работы».
- Независимый просмотр: ролик смотрит тот, кто его не делал; без этого вердикт в карточке честно скажет «не просматривал».
