# Запись экрана через инструмент управления устройством

Когда: у человека подключён сервер управления устройствами (iOS-симулятор, эмулятор Android, устройство
Android) с инструментами `screen-recording-start` и `screen-recording-stop`, и надо снять проход по
приложению для ролика. Без такого сервера используй команды из [MODULE.md](../MODULE.md).

Параметры инструментов (`timeLimitSeconds`, `trimStatic`, `showTouches`) и поля результата описаны в
самих инструментах. На одно устройство одна запись одновременно, на разные устройства можно параллельно.

## 1. Главное: не оставлять запись работающей

Забытая запись снимает до срока `timeLimitSeconds`, держит сессию и задерживает файл. Две страховки:

1. В момент старта записи поставь себе напоминание на ожидаемый конец действия. Подойдёт любой инструмент
   напоминаний или фоновая команда `sleep <секунды>`, чьё завершение вернёт тебя в работу. Когда оно
   сработало, вызови `screen-recording-stop`. Памяти доверять нельзя.
2. Читай примечания в ответах инструментов. Пока запись идёт, каждый ответ несёт строку `NOTE:` о ней.
   Если там сказано, что запись уже закончилась, всё равно вызови `screen-recording-stop`: он отдаёт файл.

## 2. Порядок

1. Запусти устройство и приведи приложение к состоянию, с которого начнётся ролик (`list-devices`,
   `launch-app`, управление экраном).
2. Вызови `screen-recording-start` с `udid` и `timeLimitSeconds` чуть больше ожидаемой длины действия.
3. Поставь напоминание из раздела 1. Этот шаг обязателен.
4. Выполни действие. Для плотной последовательности шагов бери `run-sequence`, чтобы задержки между
   вызовами не растягивали видео.
5. Вызови `screen-recording-stop` с тем же `udid`. Прочитай `warning` (остановка по лимиту, ранний выход
   кодировщика, потеря кадров, возможно обрезанный файл) и проверь размер файла, прежде чем показывать.

Где лежит файл. Готовая запись сохраняется у клиента: в `<проект>/.argent/recordings/` (ближайшая папка
выше с `.git`, `package.json` или `.argent`) или в `~/.argent/recordings/` вне проекта. Папку меняет
`argent config set recordings.directory <папка>`. Скажи человеку путь и то, что файл не под git. Для
ролика файл копируется в `$WORK/<проект>/in/`, исходный не двигается.

## 3. Платформы и пределы

- Можно: симуляторы iOS (локальные и удалённые), эмуляторы Android, физические устройства Android.
  Нельзя: физический iPhone, симуляторы tvOS, приложения на Chromium, Vega/Fire TV, HarmonyOS. Для
  одного кадра есть `screenshot`.
- Один размер на видео: размер экрана в начале записи, дальнейшая смена размера даёт чёрные поля. На
  складном симуляторе начинай запись на нужной панели.
- Удалённые симуляторы: видео остаётся в портретной ориентации, горизонтальное устройство играет боком.
- Android: защищённые экраны (оплата, часть полей пароля) в записи чёрные.
- Водяной знак: слабый логотип инструмента ставится слева внизу. Выключить до старта записи командой
  `argent disable video-watermark`; флаг читается при старте. Для промо знак убирать или кадрировать.
