# Перебивки под речь (b-roll-toolkit)

**Когда брать:** есть запись человека, который говорит в камеру (урок, объяснялка, рекламная начитка,
кусок подкаста), и её нужно сделать живее графикой по смыслу слов. Запись не режем, не двигаем и не
масштабируем: поверх неё идёт слой графики, прозрачный там, где виден говорящий, и непрозрачный там, где
графика закрывает кадр. Звук остаётся оригинальным.

**Что дать:** видео с говорящим человеком. Запись лежит в `work/<проект>/in/talk.mp4`; транскрипт и `page.html` кладутся рядом с ней (скрипты ищут транскрипт рядом со страницей), результаты идут в `work/<проект>/out/`.

**Первая команда (от корня Cadence):**
`node modules/b-roll-toolkit/scripts/transcribe.mjs work/<проект>/in/talk.mp4 work/<проект>/in/transcript.json`

**Что получится:** `transcript.json` со словами и временем, план «строка речи → обработка», страница
`page.html`, готовый `film.mp4` и, по желанию, слой графики `b-roll.mov` (ProRes 4444 с прозрачностью)
или `b-roll.webm`, чтобы положить его над записью в DaVinci Resolve, Premiere или Final Cut.

Оглавление не нужно: файл короткий, весь разбор подачи лежит в [guides/talking-head-b-roll.md](guides/talking-head-b-roll.md).

## Шаги

1. Зависимости: `python3 scripts/module_setup.py status b-roll-toolkit`. Не хватает — сказать человеку,
   что установка берёт около 5 МБ из сети (playwright-core), и ставить только после согласия:
   `python3 scripts/module_setup.py install b-roll-toolkit`. Нужны также `ffmpeg`, Node 18+ и Chrome
   (или Chromium Playwright).
2. Речь: команда выше. Распознаёт локальный `whisper-cli` (whisper.cpp) с моделью ggml; ключей и сети нет.
   Если Whisper не стоит, скрипт скажет, чем его поставить. Ставить только с согласия.
3. Шрифты: положить рядом со страницей папку `fonts/` с `fonts.css` из `engine/fonts/` Cadence
   (копия или ссылка). Страница ничего не грузит из сети.
4. План: прочитать весь транскрипт и по каждой строке выбрать одно из трёх: A говорящий один,
   B графика поверх, C графика закрывает кадр. Правила ритма и времени появления графики — в
   [guides/talking-head-b-roll.md](guides/talking-head-b-roll.md). Открывать на A и закрывать на A.
5. Страница: скопировать `templates/b-roll.html` рядом с записью как `page.html`, заполнить `VIDEO`, `W`,
   `H`, `FPS`, `DURATION`, `FACE` (где голова) и `SCENES` с рисунками под каждую строку.
6. Проверка: `node modules/b-roll-toolkit/scripts/render.mjs page.html --check`, затем кадры
   `--sheet 1` и `--stills 12s,20s`; чинить, пока не пройдёт.
7. Рендер: `render.mjs page.html work/<проект>/out/film.mp4`; слой отдельно — `.../out/b-roll.mov`.
   Папка выхода создаётся сама; записать поверх самой записи скрипт откажется.
8. Сдать: `film.mp4`, страницу, план таблицей (время, что сказано, обработка, что на экране) и список
   того, что выбрано без просьбы человека.

## Ограничения

- Текст на экране берётся только из слов говорящего, цифр и имён из транскрипта или материалов
  человека. Цифру, которая не сходится с остальной речью, не выводить и сказать об этом.
- Поверхности по умолчанию светлые; тёмная — только по просьбе или если тема сама тёмная.
- Сам распознаватель может ослышаться; слова на границах проверять на слух.
- Облачные распознаватели в модуле убраны. Сеть нужна только для установки.
- Опубликованное в примерах (`examples/`) — готовые страницы и транскрипты для образца; записей и
  контактных листов там нет.
- `scripts/compare-timing.py` — старый опыт со сдвигом всего слоя, для сравнения; решение по каждому
  элементу он не проверяет.
