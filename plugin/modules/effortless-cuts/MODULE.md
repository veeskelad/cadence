# Effortless Cuts: говорящая голова под ключ

**Когда брать.** Человек принёс сырые дубли, где он говорит в камеру, и хочет готовый ролик с титрами, звуком, обложкой и вариантами под площадки, без выбора шрифтов и децибел. Только паузы убрать или только склеить дубли — проще `scripts/silence_cut.py` и `scripts/takes_cut.py`.

**Что дать.** Папку с дублями и язык речи (язык называть всегда: автоопределение молча переводит речь и ломает все тайминги).

**Команда.** Проверка машины и профиль студии (ничего не ставит, только сообщает, чего не хватает):

```bash
python3 modules/effortless-cuts/scripts/scan.py --json
```

**Что получится.** Рядом с дублями (лучше в копии под `$WORK/<проект>/`) появляется папка `studio/`; исходники не меняются. В `studio/out/` лежат мастер, варианты под площадки, кандидаты обложки и строки, из которых агент пишет пост.

Подробный порядок работы, два стоп-шага и ремесленные правила: [guides/effortless-cuts.md](guides/effortless-cuts.md). Жёсткие правила корректности: [HARD-RULES.md](HARD-RULES.md). Вкусовые правила (хуки, титры, звук, движение): файлы в `rules/`.

## Перед началом

1. `python3 scripts/module_setup.py status effortless-cuts` из корня Cadence: что не хватает. Ставить только с согласия человека (около 450 МБ вместе с браузером для `capture.py`).
2. Нужны программы `ffmpeg`, `ffprobe`, `node` (22+), `whisper-cli` (whisper.cpp). Python-пакеты `pillow`, `playwright` нужны только для кадров-доказательств со страниц.
3. Команды ниже запускать из `modules/effortless-cuts/`: пути `scripts/…` отсчитываются от него. Папку студии задавать явно: `--studio $WORK/<проект>/studio`.

## Шаги (коротко)

| # | Что | Команда |
|---|---|---|
| 1 | вкусовая память студии | `python3 scripts/taste.py --studio <studio> brief` |
| 2 | расшифровка по словам, кэшируется | `python3 scripts/transcribe.py <дубли> --studio <studio> --lang <код>` |
| 3 | читаемый вид `takes.md` | `python3 scripts/pack.py --studio <studio>` |
| 4 | план реза: `edl.json` пишет агент, черновик | `python3 scripts/render.py --studio <studio>` |
| 5 | проверка реза (ворота) | `python3 scripts/verify.py --studio <studio>` |
| 6 | показать рез на localhost, **стоп до одобрения** | `python3 scripts/review.py --studio <studio>` |
| 7 | цвет, титры, правка имён | `grade.py`, `captions.py`, `proofread.py` |
| 8 | кадры-доказательства, иконки, сцены | `capture.py`, `icons.py`, `scenes.py` |
| 9 | звук | `sfx.py plan`, `music.py` |
| 10 | сборка и рендер | `python3 scripts/compose.py --studio <studio> --render` |
| 11 | карта движения, уровни звука | `beats.py`, `sound.py check` |
| 12 | пакет публикации | `python3 scripts/deliver.py --studio <studio>` |
| 13 | запомнить поправки | `python3 scripts/taste.py --studio <studio> add <область> "<правило>" --said "<слова человека>"` |

Точные параметры каждого шага смотреть в `--help` скрипта и в справке.

## Ограничения

- Сеть выключена, пока человек не согласился: `capture.py` открывает страницу по адресу, `icons.py` и `sfx_library.py install` качают иконки и звуки из открытых библиотек, `compose.py` подгружает анимационную библиотеку и движок рендера по сети при первом запуске. Сказать человеку до первого такого вызова.
- Сцены (`scenes.py`) — React-компоненты без анимационной библиотеки, время из `@cadence/frame`. `scenes.py init` ставит в папку студии React, esbuild и TypeScript (около 45 МБ, сеть, с согласия); рендерит общий движок Cadence (`engine/`, `python3 scripts/engine_setup.py status`), по одной композиции на сцену.
- Ключей сервисов модуль не требует. Улучшения голоса через облако, генерации картинок и видео в нём нет: генерацию заказывать навыком `cadence-generate`.
- `cutout_broll.py` (b-roll за вырезанным говорящим) нужен отдельный набор для вырезания фона, который в модуль не входит: без него не предлагать.
- Рез не показывать человеку до проверки (`verify.py`, кадры на каждой границе, уровни звука): «пайплайн отработал» не готово.
- Платформа: macOS и Linux.
