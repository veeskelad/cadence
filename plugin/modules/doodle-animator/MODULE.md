# Рисованная анимация и иллюстрации кодом

**Когда брать.** Человек хочет картинку, зацикленную анимацию, «рисующуюся на глазах» работу, короткий фильм,
эксплейнер, анимированный логотип, графику для сайта или урок рисования, и всё это в узнаваемом рисованном стиле
(32 стиля: гравюра, акварель, бумага, пиксели, тушь, эскиз и другие) или в 3D. Каждый кадр и звук считаются чистой
функцией: один исходник даёт те же пиксели на любой машине, любого размера и длины.

**Что дать.** Идею одной фразой; стиль (или разрешить подобрать); формат (1:1, 9:16, 16:9, 4:5 или любой W×H); длину;
звук (тишина, музыка в выбранном стиле или озвучка); героев.

**Команда (создать проект).**
`node modules/doodle-animator/engine/tools/scaffold.mjs "$WORK/<проект>/doodle" --film intro --format 9x16 --duration 12`
(секунды в `--duration`; для картинки `--still hero`; для разбора готового примера `--example`).

**Что получится.** Папка проекта с копией движка и заготовкой фильма; дальше работа по справке: картинка `still.mjs`,
ролик `render.mjs` (MP4, GIF, WebM, APNG), проверка `gate.mjs`, автономная страница `emit.mjs`.

## Установка и ограничения

- Движок ставится в проект только с согласия человека: `npm install` (esbuild, three, playwright-core, около 100 МБ)
  и `npx playwright-core install chromium` (около 170 МБ, сеть). Нужны Node и ffmpeg. До установки можно создать проект и
  прочитать справку.
- Проект всегда создаётся в `$WORK/<проект>/doodle`, не внутри `modules/`; ничего из движка модуля не меняется.
- Облачные голоса отключены. Озвучка: свои записи (`files`), локальный `kokoro` или системный `say` на macOS (только для
  черновиков). Для речи и слов по таймингу нужен whisper.cpp; без него озвучку не делать.
- Записи настоящих инструментов в поставку не входят: музыка играет на инструментах, собранных кодом. Загрузка пакета
  записей по умолчанию выключена.
- Чужие треки и ключи сервисов модуль не вызывает сам. Исключение: импорт из Figma (`brand.mjs ... --figma`) читает файл
  по `FIGMA_TOKEN` и только по просьбе человека (в паспорте это ключ и сетевой режим `runtime`; без этой просьбы сеть не нужна).
- Музыку и озвучку на слух никто из агентов не проверит: перед выдачей нужен человек, а отчёты проверок покрывают
  только измеримое.
- Звуковой пакет, кириллица в шрифтах движка и озвучка на русском не проверялись; один кадр на пробу перед обещаниями.

## Порядок работы

1. Опрос по `references/workflows/start-here.md`: по одному вопросу, только то, чего просьба не сказала, с рекомендацией.
   Ответы записать в короткий бриф до начала рисования.
2. Таблица «что делаем» в [guides/anidoodle.md](guides/anidoodle.md) ведёт к нужной справке: картинка, зацикленная анимация,
   рисование на глазах, фильм, 3D, эксплейнер, ролик о продукте, фирменный стиль, графика для сайта, урок, стиль по образцу, музыка, озвучка.
3. Один раз доказать вид на ОДНОМ кадре, потом строить целиком. Не больше трёх этапов согласия за фильм.
4. Проверка: `gate.mjs` (детерминизм, контракт, мёртвый эфир), `framecheck`, `ship.mjs` перед показом, независимый
   просмотр свежим агентом по `references/workflows/review.md`.

## Команды движка

Запускать из папки проекта (`cd "$WORK/<проект>/doodle"`), после `npm install`:

```
node tools/still.mjs intro --frame 0 --out out/look.png --scale 2   # кадр с хешем
node tools/render.mjs intro                                        # MP4; --out x.gif|x.webm|x.apng
node tools/gate.mjs intro                                          # детерминизм, контракт, мёртвый эфир
node tools/emit.mjs intro --out out/intro.html                     # одна автономная страница
node tools/narrate.mjs providers                                   # какие голоса доступны на этой машине
```

## Справка

- [guides/anidoodle.md](guides/anidoodle.md) — главная инструкция: семь законов, рабочие процессы, планка качества, инструменты.
- `references/workflows/` — по одному файлу на вид работы (старт, 3D, эксплейнер, ролик о продукте, фильм в фирменном стиле,
  урок, стиль по образцу, озвучка и субтитры).
- `references/styles/INDEX.md` и `references/styles.md` — список стилей и принципы; `references/music/` — музыка и звук.
- `example/` — разобранный пример фильма; `NOTICE` — авторство и сторонние материалы.
