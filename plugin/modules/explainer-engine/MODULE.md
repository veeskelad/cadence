# Эксплейнер с голосом и демо продукта

**Когда брать:** человек просит объяснялку, обучающий ролик, запуск или демо продукта с голосом диктора,
либо короткое вертикальное видео с субтитрами, либо монтаж своей записи по словам.

**Что дать:** тему или готовый текст (его положат в `script.md`), по желанию свою запись голоса, музыку,
скриншоты, адрес сайта для захвата.

**Команда (новый проект):** `node modules/explainer-engine/bin/explainroo.js init "$WORK/<проект>/video"`

**Что получится:** MP4 с озвучкой, субтитрами и обложкой в `<проект>/out/`, при желании web-плеер и папка
для ручной загрузки на площадку.

Оглавление: [Как работает](#как-работает) · [Шаги](#шаги) · [Команды](#команды) · [Ограничения](#ограничения)

## Как работает

Два файла: `script.md` (что говорит голос) и `scenes.js` (что рисуется на экране; каждый рисунок можно привязать
к слову). Озвучка: модель Kokoro на этом компьютере или запись человека; Whisper отмечает время каждого слова.
Кадры рисует Chrome, склейку с музыкой и звуками делает ffmpeg.

Полная инструкция агенту (шаги, ограничения по языкам, порядок проверки): [guides/explainroo.md](guides/explainroo.md).
Подробные темы: `node modules/explainer-engine/bin/explainroo.js docs --list`, текст тем лежит в `docs/`.

## Шаги

1. Один раз поставить зависимости с согласия человека: `python3 scripts/module_setup.py install explainer-engine`,
   затем `node modules/explainer-engine/bin/explainroo.js doctor --fetch` (проверит ffmpeg и Chrome, скачает модели).
2. Создать проект: команда выше. Проект и результат лежат в `$WORK/<проект>/video/`, исходники человека не трогать.
3. Написать `script.md`, озвучить: `... voice <проект>`; нарисовать сцены в `scenes.js`.
4. Проверить: `... check <проект>`, исправить все ошибки; посмотреть кадры `... still`, `... sheet`.
5. Отрендерить: `... render <проект>`; проверить `... verify <проект>`.
6. Для площадки: `... package <проект> --platform tiktok` (папка, которую человек загружает сам).

## Команды

`init`, `voice`, `words`, `preview`, `still`, `sheet`, `check`, `render`, `verify`, `export`, `package`, `clean`,
`cut` (монтаж своей записи по словам: правка списка слов, затем `--apply`), `capture` (снимок сайта по адресу),
`record` (запись шагов в браузере для демо), `doctor`, `docs`. Параметры каждой: `<команда> --help`.

## Ограничения

- Языки озвучки: английский, испанский, французский, итальянский, бразильский португальский, хинди,
  японский, китайский. Немецкий только со своей записью голоса.
- В этой сборке нет платных сервисов, ключей, генерации картинок и клипов, ИИ-ведущих, постинга и загрузки
  в сеть: убраны намеренно. Для картинок рисовать в `scenes.js` или брать файлы человека; опубликует человек сам.
- Сеть нужна только для первой загрузки моделей и шрифтов, для `capture` по адресу, который назвал человек, и
  для `formats add` с явным `--yes`.
- Нужны Node 20.11 и новее, ffmpeg и Chrome или Chromium. Рендер тяжёлый: на слабой машине использовать
  `--draft` и `--workers 1`.
- Примеры в `examples/`; шрифты в `fonts/` под лицензией OFL (заметка рядом). Пример с немецкой записью и
  набор автотестов продукта не перенесены.
- Справка и сообщения программы по-английски.
