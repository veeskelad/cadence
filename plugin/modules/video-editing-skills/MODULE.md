# Приёмы монтажа вертикального ролика (video-editing-skills)

**Когда брать:** есть вертикальный ролик 9:16 с говорящим человеком (или набор своих картинок) и нужен
один из готовых приёмов оформления: экран пополам, графика за человеком, рейтинг, объяснялка,
сторителлинг, три варианта для пробных рилсов или короткий фото-стиль.

**Что дать:** видео (9:16, лучше 1080x1920), файл спецификации JSON с текстом, картинками и временем
(формат в справке выбранного приёма), своё видео и картинки. Образцов фото и видео в модуле нет.

**Команда (от корня Cadence):**
`python3 modules/video-editing-skills/styles/<приём>/build.py work/<проект>/<приём>.json`
Python берётся из модуля: `python3 scripts/module_setup.py python video-editing-skills`.

**Что получится:** `work/<проект>/out/<имя>.mp4` 1080x1920, рядом `<имя>.sheet.jpg` (кадры с красными
зонами, которые закроет интерфейс площадки) и редактируемая композиция. Исходное видео не меняется.

Модуль в статусе beta: код проверен на синтаксис, а рендер общим движком Cadence на живом ролике ещё не прогнан.

## 1. Какой приём выбрать

| Приём | Что на экране | Справка |
|---|---|---|
| `split-screen` | сверху заголовок и окно с пояснением, снизу человек, субтитры на стыке | [guides/split-screen.md](guides/split-screen.md) |
| `behind-the-person` | человек вырезан и стоит перед панелью (сетка постов, график, скриншот), крупные слова на груди | [guides/behind-the-person.md](guides/behind-the-person.md) |
| `explainer` | человек внизу в скруглённой панели, голова выступает над краем, сверху сравнение «до и после» или список | [guides/explainer.md](guides/explainer.md) |
| `ranking-list` | таблица уровней S–F на груди, предметы падают в свои уровни по ходу речи | [guides/ranking-list.md](guides/ranking-list.md) |
| `storytelling` | три картинки сверху, чёрный заголовок, субтитры по 1–3 слова | [guides/storytelling.md](guides/storytelling.md) |
| `trial-reels` | один ролик превращается в три разных по виду версии для проверки, какая зайдёт | [guides/trial-reels.md](guides/trial-reels.md) |
| `shape-shift`, `picture-stack`, `scene-switch`, `visual-notes`, `orbit-reel` | тихие 4,2-секундные фото-шаблоны на своих картинках | [guides/five-photo-styles.md](guides/five-photo-styles.md) и справка каждого приёма |

## 2. Подготовка и установка

1. `python3 scripts/module_setup.py status video-editing-skills`. Не готово: сказать человеку, что
   установка берёт около 350 МБ из сети (Python-пакеты и анимационная библиотека), и ставить только после
   согласия: `python3 scripts/module_setup.py install video-editing-skills`.
2. Движок рендера общий: `python3 scripts/engine_setup.py status`. Нет движка: установка около 300 МБ,
   тоже только с согласия.
3. Распознавание речи локальное (Whisper small), ключей нет. Модель читается с диска; скачать её можно
   с `ALLOW_MODEL_DOWNLOAD=1` перед командой, только после согласия. Для приёмов с вырезкой человека
   так же отдельно скачивается модель вырезки.

## 3. Порядок работы

1. Выбрать приём по таблице, открыть его справку и прочитать шаги.
2. Слова ролика: `"$PY" modules/video-editing-skills/kit/reel.py words <видео>`. Команда печатает
   предложения со временем окончания. Для приёма берётся отрезок целых предложений.
3. Кадр с линией глаз или подбородка: `reel.py frame <видео> <время> frame.jpg`.
4. Спецификация JSON рядом с видео, в `work/<проект>/`; пути в ней считаются от папки спецификации.
5. Сборка командой из шапки. Результат и контактный лист смотреть глазами: зоны интерфейса, читаемость,
   лицо целиком, каждое действие на своём слове.
6. Сдать путь к mp4. Если нужно несколько вариантов, `trial-reels` делает три файла за раз.

## 4. Ограничения

- Картинки, скриншоты, цифры и подписи берутся только от человека; выдумывать их нельзя.
- Вырезка человека — встроенная сегментация macOS (Vision), около 0,05 с на кадр, ничего не скачивается; `--quality accurate` чище у волос и рук, примерно втрое медленнее. Волосы и руки проверять глазами. На Linux вместо Vision — MediaPipe 0.10.21 (Apache-2.0, модель 250 КБ внутри пакета, ставится через `module_setup.py install`), около 0,08 с на кадр; край грубее, чем у Vision: проверять руки и предметы у края кадра.
- Расшифровка использует заранее скачанную модель Whisper.
- Шаблоны на 4,2 секунды правятся в таймлайне вручную, длина сама не растягивается.
- Версия движка Cadence новее той, под которую писались шаблоны: проверять первый рендер каждого приёма.
