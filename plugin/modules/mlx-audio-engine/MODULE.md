# Озвучка и распознавание речи на Mac (Apple Silicon)

**Когда брать.** Нужен закадровый голос или расшифровка речи, и работа идёт на Mac с чипом M1 и новее: модели
считаются на графическом процессоре Mac, видеокарта NVIDIA не нужна. Два режима: `tts` (текст в голос) и `stt` (речь в текст).

**Что дать.** Для озвучки: текст и язык, по желанию образец голоса. Для распознавания: звук или видео с речью.

**Команды** (от корня Cadence):

```bash
python3 modules/mlx-audio-engine/run.py tts --text-file <сценарий.txt> --lang ru --ref-audio <образец.wav> --project <проект>
python3 modules/mlx-audio-engine/run.py stt --audio <запись> --lang ru --format srt --project <проект>
```

**Что получится.** Озвучка: `$WORK/<проект>/out/voiceover.wav`. Распознавание: `<имя>.srt`, `.vtt`, `.txt` или `.json`
(`--words` добавляет время каждого слова) там же. Готовый файл не перезаписывается без `--overwrite`.

> Клонирование чужого голоса: только с согласия владельца голоса. Образец (`--ref-audio`) берём, если человек сказал, чей это голос и что владелец согласен.

## Шаги

1. Проверка без расчёта: `--dry-run` показывает модели и есть ли их веса в кэше.
2. Зависимости: `python3 scripts/module_setup.py status mlx-audio-engine`. Нет — спросить человека и только после согласия
   `python3 scripts/module_setup.py install mlx-audio-engine` (около 3 ГБ вместе с весами; нужен `ffmpeg`).
3. Веса скачиваются отдельно и только по согласию: `--allow-download` (с Hugging Face, кэш `~/.cache/huggingface`).
   Без флага запуск идёт без сети и останавливается, если весов нет. Для озвучки с образцом без `--ref-text` движок сам распознает
   слова образца второй моделью (её веса тоже нужны). Движок может докачать мелкие вспомогательные веса: тогда повторить с `--allow-download`.
4. Запустить на одной фразе, послушать, потом весь сценарий.
5. Всё, чего нет в параметрах `run.py`, уходит в движок как есть: `--temperature 0.7`, `--voice <имя>`, `--instruct "<манера>"`.

## Параметры

| Режим | Параметр | Что делает |
|---|---|---|
| `tts` | `--model` | модель озвучки (по умолчанию `chatterbox-multilingual-v3`, 23 языка) |
| `tts` | `--lang` | код языка: `ru`, `en` и др.; у некоторых моделей названием, например `russian` |
| `tts` | `--ref-audio`, `--ref-text` | образец голоса и слова из него |
| `tts` | `--voice`, `--instruct` | готовый голос или описание манеры, если модель это умеет |
| `stt` | `--model`, `--format`, `--words` | модель (по умолчанию `whisper-large-v3-turbo-asr-fp16`), формат, время слов |
| оба | `--out-dir`, `--project`, `--allow-download` | куда писать; разрешение на скачивание |

## Языки и железо (проверено по коду и справке)

- **Железо:** только Mac с Apple Silicon (движок построен на MLX). На Intel, Linux и Windows не работает.
- **Русский, озвучка:** `chatterbox-multilingual-v3` (в коде проверка `lang_code` по списку из 23 языков, русский там есть).
  По справке русский есть ещё у KugelAudio, Audio8, VoxCPM2 и OmniVoice. У Kokoro русского нет. Умеет ли Qwen3-TTS русский, по коду не видно:
  список языков лежит в весах.
- **Образец голоса:** у `chatterbox-multilingual-v3` встроенного голоса может не быть; тогда движок потребует `--ref-audio`
  (и сообщит об этом). Без образца есть модели с готовыми голосами или описанием голоса словами (см. справку по моделям).
- **Русский, распознавание:** Whisper (99 языков, время слов), Parakeet v3, VibeVoice-ASR.

## Веса моделей (в репозиторий не кладутся)

Скачиваются при первом запуске с `--allow-download`; объём на диске — оценка по числу параметров:

| Для чего | Модель | Объём |
|---|---|---|
| озвучка | chatterbox-multilingual-v3 (и вспомогательная S3TokenizerV2) | около 1–2 ГБ |
| распознавание | whisper-large-v3-turbo-asr-fp16 | около 1,6 ГБ |
| другие | по справке [docs/models/index.md](docs/models/index.md): у каждой модели свой объём | от десятков МБ до десятков ГБ |

## Лицензии весов

У моделей Breeze TTS, Higgs Audio v3, Voxtral TTS, rumik-oss, Echo TTS, DialogueSidon и контрольной точки Granite Speech 5 «-nc»
лицензия весов ограничивает коммерческое использование. `run.py` такие модели отклоняет; флаг `--allow-restricted` только для личного
черновика. Для ролика на публикацию их не брать. Лицензию остальных моделей смотреть на странице модели до выбора.

## Ограничения

- Статус `beta`: запуск проверен только в режиме `--dry-run`, расчёт не прогонялся (зависимости не стоят).
- Веб-интерфейс и серверы движка не используются; интерфейс из пакета убран.
- Справка по моделям: [docs/models/index.md](docs/models/index.md), [озвучка](docs/models/tts/index.md), [распознавание](docs/models/stt/index.md), [клонирование голоса](docs/guides/voice-cloning.md).
- Платформы публикации могут требовать пометку «синтезированный голос»: сказать человеку до выкладки.
