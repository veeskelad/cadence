# Changelog

## 1.1.1 — 2026-10-24

First GitHub release.

- Fixed the CSV folder button: browse accessible drives and project folders even when the path is empty.
- Added working double-click folder navigation, parent navigation, CSV filtering, and recovery from invalid paths.
- Show actionable file-access guidance for unsaved projects and restricted folders.
- Includes CSV text, image, and color bindings; row/range/all composition generation; preview; custom names such as `LowerThird_[FirstName][LastName]`; and template settings saved with the project.

The stock EffectCraft scripting API does not expose a native file picker, so browsing uses the panel’s built-in dialog.
