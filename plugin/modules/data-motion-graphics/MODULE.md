# Кадры из таблицы CSV (Data Driver)

**Когда брать:** человеку нужна серия однотипных кадров (плашки с именами, титры, карточки), которые
отличаются только данными, и у него есть редактор EffectCraft. Для графиков и анимации чисел в Cadence
этот модуль не подходит: их рисует движок `engine/` (навык `cadence-motion`).

**Что дать:** шаблонную композицию в EffectCraft и CSV с заголовками в первой строке.

**Команда (сборка панели):** `node modules/data-motion-graphics/build.mjs --out "$WORK/<проект>/out"`

**Что получится:** `Data Driver.jsx` и `Data Driver.jsx.sha256` в указанной папке. Файл ставится в
EffectCraft как панель ScriptUI; дальше человек работает в самой панели.

## Что умеет панель

- читает CSV (кавычки, запятые внутри ячеек, переносы строк, BOM) и показывает строки;
- привязывает столбцы к слою шаблона: текст, цвет заливки или обводки, цвет фигуры, картинка;
- собирает композиции для выбранных строк (`1, 3-7` или все), имя композиции задаётся шаблоном вроде
  `LowerThird_[FirstName][LastName]`;
- ячейки CSV всегда данные, а не команды: в именах и путях ничего не вычисляется;
- картинки только по локальным путям, адреса из сети отклоняются.

## Шаги

1. Собрать панель командой выше.
2. Попросить человека поставить `Data Driver.jsx` в EffectCraft (меню скриптов) и открыть шаблон.
3. Дальше всё в панели: загрузить CSV, привязать столбцы, выбрать строки, создать композиции.
4. Пример данных: `examples/sample.csv` и проект `examples/Data Driver Demo.ecproj`.

## Ограничения

- Работает только внутри EffectCraft. В Resolve, hyperframes и remotion панель не запускается.
- Без установленного EffectCraft проверить можно лишь чистую часть (разбор CSV): `node tests/run.mjs`
  из папки модуля. Остальные проверки (`tests/ui.mjs`, `tests/picker.mjs`) требуют живой экземпляр
  EffectCraft с управляющим портом 9888 и запускаются вручную; им нужна сборка в `dist/`
  (`node build.mjs --out dist`).
- Результаты прогонов `tests/run.mjs` складываются в `$CADENCE_WORK/data-motion-graphics/out/`.
- Исходники человека (его CSV, проекты) модуль не перезаписывает.
