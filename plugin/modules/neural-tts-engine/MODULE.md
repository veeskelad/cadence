# Озвучка: диктор, голос по описанию, голос по образцу

**Когда брать.** Нужен закадровый голос, и важно управлять им словами («спокойный низкий мужской голос, говорит
неторопливо») или выбрать готового диктора, либо повторить тембр по образцу. Модель сильная, но тяжёлая: нужна видеокарта NVIDIA.
На Mac без NVIDIA брать `mlx-audio-engine`.

**Что дать.** Текст (`--text` или `--text-file`), режим `--mode`, язык по-английски (`Russian`, `English`, `Auto`).

**Команда** (от корня Cadence):

```bash
python3 modules/neural-tts-engine/run.py --mode design --text-file <сценарий.txt> --language Russian \
  --instruct "Спокойный низкий мужской голос, говорит неторопливо" --project <проект>
```

**Что получится.** `$WORK/<проект>/out/voiceover.wav`. Длинный текст режется по предложениям (до 300 знаков в куске),
между ними пауза 0,35 с. Готовый файл не перезаписывается без `--overwrite`.

> Клонирование чужого голоса: только с согласия владельца голоса. Режим `clone` берём, если человек сказал, чей это голос и что владелец согласен.

## Режимы

| `--mode` | Что делает | Нужно дополнительно |
|---|---|---|
| `design` | голос по описанию словами | `--instruct` с описанием голоса |
| `custom` | готовый диктор, манеру можно уточнить словами | `--speaker`; неверное имя — скрипт покажет список дикторов |
| `clone` | тембр из образца | `--ref-audio` (локальный wav, 10–30 секунд чистой речи) и `--ref-text` (дословно, что сказано); без `--ref-text` тембр грубее |

`--size 0.6B` берёт модель поменьше (быстрее, слабее). Не для каждого режима есть малая модель: если загрузка не находит её, взять `1.7B`.

## Шаги

1. Проверка без расчёта: `--dry-run` показывает модель, объём весов и есть ли они в кэше.
2. Зависимости: `python3 scripts/module_setup.py status neural-tts-engine`. Нет — спросить человека и только после
   согласия `python3 scripts/module_setup.py install neural-tts-engine` (около 6 ГБ вместе с весами).
3. Веса скачиваются отдельно и только по согласию: `--allow-download` (с Hugging Face, кэш `~/.cache/huggingface`).
   Без флага запуск идёт без сети и останавливается, если весов нет.
4. Запустить на первой фразе, послушать, потом гнать весь сценарий.

## Язык и железо

- **Русский:** по коду не подтверждается. Список языков в модуле читается из настроек самих весов
  (`codec_language_id` в `config.json`), в коде его нет. По описанию модели русский входит в десять языков; перед работой проверить:
  скрипт после загрузки сам сверяет `--language` со списком модели и называет доступные, если языка нет.
- **Железо:** рассчитано на NVIDIA (CUDA, bfloat16). Флаг `--flash-attn` включает ускорение, если пакет flash-attn стоит.
  Apple Silicon: в коде есть только мелкая оговорка для `mps` в позиционных вычислениях, остальное не проверено, режим
  `--device mps` экспериментальный. На процессоре модель считает очень медленно.

## Веса моделей (в репозиторий не кладутся)

Скачиваются при первом запуске с `--allow-download`; объём на диске — оценка по числу параметров:

| Режим | Модель | Объём |
|---|---|---|
| `design` | Qwen3-TTS-12Hz-1.7B-VoiceDesign | около 4–5 ГБ |
| `custom` | Qwen3-TTS-12Hz-1.7B-CustomVoice (0.6B: меньше) | около 4–5 ГБ (0.6B около 2–3 ГБ) |
| `clone` | Qwen3-TTS-12Hz-1.7B-Base (0.6B: меньше) | около 4–5 ГБ (0.6B около 2–3 ГБ) |

## Ограничения

- Образец голоса только локальным файлом: ссылки и base64 скрипт не принимает.
- Обучение голоса и веб-демо из исходного проекта убраны: они не нужны для озвучки.
- Платформы публикации могут требовать пометку «синтезированный голос»: сказать человеку до выкладки.
- Статус `beta`: запуск проверен только в режиме `--dry-run`, расчёт на этой машине не прогонялся (нет видеокарты и зависимостей).
