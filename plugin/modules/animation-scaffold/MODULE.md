# Рисованный мультик с героем

**Когда брать:** человек хочет короткую анимацию, которая выглядит нарисованной кистью и тушью: герой
играет эмоции, поворачивается, ходит, берёт предметы. Текста и 3D в кадре нет по правилам модуля.

**Что дать:** идею в одном предложении и, если есть, трек (темп и время первой доли). Остальное агент
собирает сам: раскадровку, сцены, листы проверки.

**Команда:** `python3 modules/animation-scaffold/run.py <проект> --clip --out=out/video.mp4`

**Что получится:** MP4 в `$WORK/<проект>/out/`. Рядом по запросу: контактные листы, полосы кадров,
PNG-кадры, циклы.

Оглавление: [Первый запуск](#первый-запуск) · [Шаги](#шаги) · [Параметры render](#параметры-render) ·
[Ограничения](#ограничения) · [Справка](#справка)

## Первый запуск

1. Зависимости (около 45 МБ, сеть только на установку, нужно согласие человека):
   `python3 scripts/module_setup.py install animation-scaffold`. Проверка без сети:
   `python3 scripts/module_setup.py status animation-scaffold`.
2. Нужны `node`, `ffmpeg` и браузер Chrome или Chromium. Если Chrome лежит в нестандартном месте,
   путь передаётся как `--chrome=<путь>` или в переменной `CHROME_PATH`.
3. Копия сцен для правки: `python3 modules/animation-scaffold/run.py <проект> --init`. Она создаёт
   `$WORK/<проект>/scaffold/` (`studio.html`, `src/`). Встроенные файлы модуля не правятся.

## Шаги

1. Прочитать [правила и справочник](guides/animation-guide.md) целиком до первой строки кода: там
   правила кисти, тайминг и устройство движка. Листы героя: [эмоции](docs/emotions.jpg) и
   [ракурсы](docs/views.jpg).
2. Решить, о чём ролик, и записать раскадровку: что происходит в каждом шоте и что зритель должен
   понять. Историю встроенного примера не повторять.
3. Задать `duration`, `bpm`, `offset` в `$WORK/<проект>/scaffold/src/config.js`, написать сцену в новом
   файле в `src/scenes/` и подключить его в `studio.html` вместо `demo.js`.
4. Посмотреть кадры, не доверяя коду: лист `--sheet=...`, полоса `--strip=a:b`, вырез `--crop=x,y,w,h`.
   Минимум: лист на каждый шот, полоса на каждое ключевое движение, вырез на каждое лицо.
5. Отрендерить: `--clip --out=out/video.mp4`; для длинного ролика параллельно `--frames --workers=4`,
   потом `--encode --out=out/video.mp4`.
6. Звук: свой файл через `--audio=<путь>` (или поле `audio` в `config.js`). Музыку и громкость по
   правилам навыка `cadence-sound`; сам модуль звук не делает.

## Параметры render

Всё после имени проекта уходит в `render.mjs`. `out/...` в аргументах означает `$WORK/<проект>/out/...`.

| Аргумент | Что делает |
|---|---|
| `--sheet=0.5,1,2 [--cols=4] [--w=480]` | контактный лист выбранных моментов |
| `--strip=2.0:2.5` | каждый кадр отрезка, для проверки движения |
| `--crop=x,y,w,h`, `--crop-at=x,y,w,h` | вырез в полном размере (второй следует за точкой мира) |
| `--stills=1.2,3.4` | PNG-кадры в полном размере |
| `--clip [--range=0:4]` | сразу в MP4 одним потоком |
| `--frames [--workers=4]`, `--encode` | параллельные JPEG-кадры, потом сборка |
| `--loop=emotions`, `--png` | отдельный цикл (эмоции, ракурсы) как кадры для GIF |
| `--fps=24`, `--audio=<файл>`, `--chrome=<путь>` | частота, звук, браузер |
| `--soft-gl`, `--gpu-angle=vulkan` | без видеокарты и на сервере с картой NVIDIA |

Проверить, на какой видеокарте окажется WebGL: `node modules/animation-scaffold/gpu_probe.mjs <путь к Chrome>`.

## Ограничения

- Кадры считаются только от времени: никаких счётчиков и `Math.random()` в сценах (подробно в справке).
- Шрифт для редких надписей `letter()`: если на машине нет Permanent Marker, берётся Comic Sans MS
  или любой рукописный. Сеть для шрифта выключена.
- Рендер идёт в один рабочий процесс по умолчанию; на слабом компьютере больше 2–3 воркеров не ставить.
- Герой Clawd: фирменный талисман чужого продукта, его дизайн можно менять или заменить своим героем.
  Для публикации с этим талисманом сначала спросить человека.
- Исходный пример `src/scenes/demo.js` показывает возможности и шаблоном не является.
