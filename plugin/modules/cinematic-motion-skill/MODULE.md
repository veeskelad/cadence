# Фильм-рассказ под голос, нарисованный кодом

**Когда брать:** человек хочет фильм со сценарием и голосом, который выглядит как шоурил моушн-дизайнера:
продукт, разбор цифр, объяснение механизма, история на 30 секунд – 4 минуты. Картинка целиком из кода и
пересобирается точно.

**Что дать:** бриф (кому, какая одна мысль, источники), записи голоса по строкам сценария, по желанию
скриншоты и бренд-материалы.

**Команда (создать проект):** `sh modules/cinematic-motion-skill/scripts/init.sh "$WORK/<проект>/film" --preset blank`

**Что получится:** фильмы 16:9 и 9:16 (`renders/*.mp4`), сценарий, раскадровка, журнал проверок.

Оглавление: [Шаги](#шаги) · [Что где лежит](#что-где-лежит) · [Ограничения](#ограничения)

## Шаги

Полный порядок (десять шагов, два обязательных «стоп» с согласованием) и правила:
[guides/cinematic-motion-skill.md](guides/cinematic-motion-skill.md). Коротко:

1. Бриф: один раунд вопросов человеку (кому, одна мысль, источники, длина, форматы).
2. История и сценарий: показать человеку и дождаться «да» до любого звука.
3. Создать проект командой выше (`init.sh` один раз ставит общий набор: Python-пакеты и Chromium в
   `~/.cache/motion-film`, это загрузки из сети: только с согласия человека).
4. Голос: записи человека в `audio/vo/<id>.wav`, затем `layout_vo.py`, `vo.py`, `sync.mjs`.
5. Стиль и список кадров: согласовать с человеком.
6. Музыка: `music_source.py` (встроенная синтетика, свой трек, локальная `ace` или без музыки) и субтитры `captions.py`.
7. Сборка сцен в `film/film.js`, проверка кадров `render.mjs --sheet`, `--lint`, `--seams`.
8. Звук: `sfx_layout.py`, `mix.py`.
9. Раунды критики: независимый проверяющий по `reference/CRITIQUE.md` и «слепое чтение» по `reference/BLIND.md`.
10. Итоговый рендер `render.mjs --all` и отчёт со списком «не проверено».

## Что где лежит

- `reference/` справка по этапам (правила, сюжет, форматы, стили, движок, реквизит, библиотека сцен);
- `engine/` движок на canvas и WebGL, `library/` каталог сцен, значки и фигуры;
- `scripts/` конвейер (рендер, синхронизация, микс, критика, поиск готовых сцен `scenes.mjs`);
- `templates/`, `presets/blank/`, `examples/readme-demo/` шаблоны и пример проекта.

## Ограничения

- Свой движок рендера (Chromium и ffmpeg), не `engine/` Cadence: ставится отдельно и только по согласию.
- Синтез голоса, платные сервисы музыки, генерация видео-вставок, загрузка звуков и проверка обновлений
  в эту копию не вошли. Голос только записи человека; без точных таймингов слов `layout_vo.py` раскладывает
  слова по длине.
- Вырезка человека с фона и карта глубины фото (`scripts/vision.py`) качают модели только с флагом `--download`.
- Захват сайта (`capture.mjs`) ходит по адресу, который назвал человек.
- Рендер долгий (около десяти минут на формат для двух с половиной минут) и тяжёлый для процессора.
- Источники и лицензии составных частей: `NOTICE.md`, `UPSTREAM.md`; тексты лицензий автора и вложенных
  частей — `licenses/` и рядом с ассетами.
