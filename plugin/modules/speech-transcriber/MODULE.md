# Распознавание речи: субтитры и время слов

**Когда брать.** Нужен текст речи с таймкодами в SRT, VTT, TXT или список слов с временем, а основной путь
`scripts/captions_whisper.py` не подошёл: нужна другая модель (например, `large`), формат VTT или JSON,
или у него не завелись зависимости. Модуль запасной к функции `captions` (субтитры по речи).

**Что дать.** Видео или звук с речью; язык (по умолчанию `ru`, `auto` — определить самому); размер модели.

**Команда** (от корня Cadence):

```bash
python3 modules/speech-transcriber/run.py <видео или звук> --language ru --project <проект>
```

**Что получится.** В `$WORK/<проект>/out/`: `<имя>.srt` и `<имя>.words.json` (слова с временем). Другие
форматы — `--formats srt,vtt,txt,json,words`. Исходник не меняется; готовый файл не перезаписывается без `--overwrite`.

## Шаги

1. Проверить без расчёта: добавить `--dry-run`. Скрипт покажет модель, есть ли её веса на диске и какие файлы запишет.
2. Зависимости: `python3 scripts/module_setup.py status speech-transcriber`. Нет — спросить человека и только
   после согласия `python3 scripts/module_setup.py install speech-transcriber` (около 1,2 ГБ вместе с моделью `small`).
3. Веса модели скачиваются отдельно и только по согласию: `--allow-download` (адреса и контрольные суммы
   зашиты в `whisper/__init__.py`, папка кэша `~/.cache/whisper`). Без флага и без весов скрипт останавливается.
4. Запустить команду. Длинное видео считается минуты; на CPU дольше.
5. Нужны субтитры по правилам Cadence (длина строки, пауза, скорость чтения) или вшить их в ролик: собрать их
   из слов этого модуля без повторного распознавания:
   `python3 scripts/captions_whisper.py <видео> --words-in <имя>.words.json`.

## Параметры

| Параметр | Что делает |
|---|---|
| `--language` | код языка (`ru`, `en` и др., 99 языков) или `auto` |
| `--model` | `tiny`, `base`, `small` (по умолчанию), `medium`, `large` (large-v3), `turbo` (large-v3-turbo) |
| `--formats` | какие файлы записать |
| `--out`, `--project` | куда писать: своя папка или проект в `$WORK` |
| `--max-line-width`, `--max-line-count` | длина строки и число строк в SRT/VTT (32 и 2) |
| `--allow-download` | разрешить скачать веса (сеть, только с согласия) |

## Языки и железо

- Русский есть: в коде `LANGUAGES["ru"]` (`whisper/tokenizer.py`), модели многоязычные. Точность на русском растёт с размером модели.
- Устройство: NVIDIA (CUDA), иначе процессор. На Apple Silicon код модели считает на процессоре: ускорения через MPS в нём нет.

## Веса моделей (в репозиторий не кладутся)

Размер файла на диске, оценка: `tiny` 75 МБ, `base` 145 МБ, `small` 470 МБ, `medium` 1,5 ГБ, `large` (large-v3) 3 ГБ,
`turbo` (large-v3-turbo) 1,6 ГБ. Скачиваются при первом запуске с `--allow-download`.

## Ограничения

- Модель иногда «додумывает» текст на тишине, музыке и шуме: сверить результат на слух, особенно вступление и концовку.
- Не распознавать записи людей без их ведома.
- Другой язык, чем задан флагом `--language`, модель не расшифрует, а выдаст пересказ на заданном: не знаешь язык, ставь `auto`.
