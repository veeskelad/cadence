# Медиа для ролика: цвет, звук, субтитры, вырезание фона

**Когда:** нужно разобраться с цветом и «взглядом» на живом материале (тёмное, плоское, ретро, скрыть лицо, раскрытие), с LUT, со сведением дорожек, субтитрами по словам, распознаванием речи и вырезанием фона. В Cadence берётся только локальная часть набора: облачные каталоги, генерация голоса, музыки и аватаров не используются.

> Файлы набора: `modules/declarative-video-frames/kits/media-use/`.

Медиа попадает в проект локальным файлом в `assets/`. Всё ниже работает на машине человека, без входа в сервисы и без оплаты.

## Взгляд на живой материал

Жалоба «тёмное», «плоское», «скучное», «нужно ретро или печатный вид», «спрятать лицо», «нужно раскрытие» это задача про обработку, а не про CSS. Осмотреть настоящие `<img>` и `<video>`, выбрать одно намерение и идти по `media-treatments.md`. Оттенки, зерно, размытие и виньетки на живом видео делаются через `npx hyperframes media-treatment`, а не через CSS-фильтры.

## Один раз предложить, молча не добавлять

Просмотреть собранный ролик один раз на конкретные пробелы (текст на экране без озвучки, эмодзи вместо иконок, заглушки вместо картинок, немые склейки, 10 секунд и больше без музыки, цветовой сдвиг) и предложить исправления одним вопросом. Нет сигнала нет предложения; «ничего не добавляй» соблюдать.

## Ограничения в Cadence

- Музыку, голос и озвучку по тексту делает навык `cadence-sound`, а не этот набор.
- Нужен только локальный звук и картинка: загрузки из облачных каталогов, генерация образов и аватаров не используются.
- Команды `npx hyperframes media-use resolve --type grade|lut` работают без сети; остальные типы `media-use` в Cadence не запускать.
- Звуковые эффекты из комплекта (19 файлов `mp3`) и их авторы перечислены в `audio/assets/sfx/CREDITS.md`; ссылку на авторов надо оставить с проектом.
