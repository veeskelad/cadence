# Блоки и приёмы для движка hyperframes

**Когда брать:** до того как собирать вручную переход, титр, плашку, шейдерный фон, карусель, чат,
уведомление или график; и когда нужно вспомнить правила композиции, команд движка, швов и переходов.
Движок Cadence (`engine/`, пакет hyperframes) уже стоит, второй движок этому модулю не нужен.

**Что дать:** словами, какой эффект нужен (или тег, или тип: блок, компонент, пример).

**Команда:** `node modules/declarative-video-frames/scripts/registry.mjs <слово ...> [--type block|component|example] [--tag <тег>]`

**Что получится:** список подходящих элементов с описанием, размером, длительностью и путём к папке.
Нужную папку копируют в проект ролика и подключают по её `BLOCK.md` или `README.md`.

Оглавление: [Как пользоваться](#как-пользоваться) · [Что внутри](#что-внутри) · [Справки](#справки) · [Ограничения](#ограничения)

## Как пользоваться

1. Найти элемент: команда выше, например `registry.mjs glass --type block` или `registry.mjs chart`.
2. Открыть папку элемента в `registry/blocks/<имя>/` или `registry/components/<имя>/`:
   `<имя>.html` (композиция), `registry-item.json` (описание, переменные, список файлов),
   `assets/` (шрифты, картинки, скрипты), у семи блоков ещё `BLOCK.md` с подробностями.
3. Скопировать папку в проект ролика (`compositions/<имя>/`), оставить пути `assets/…` как есть.
   Движок анимации и общий шейдерный пакет блоки берут из корня проекта: `/lib/cadence-tween.min.js`,
   `/lib/shaders.iife.js` — их кладёт сборка `engine/build.mjs` (папка `engine/lib`).
4. Подставить свои значения в переменные из `registry-item.json` (тексты, цвета, длительность).
5. Проверить кадры командами движка: `check`, `snapshot` (справка `guides/hyperframes-cli.md`).

| Папка | Что |
|---|---|
| `registry/blocks/` | 209 готовых сцен 1920×1080 и вертикальных: титры, чаты, карусели, 3D, шейдерные фоны, графики, карты |
| `registry/components/` | 238 деталей: переходы, субтитры, курсоры, плашки, счётчики, подсветки; список в `registry/components/CATALOG.md` |

| `registry/registry.json` | индекс элементов (имя и тип) |
| `registry/catalog-artifact/` | векторный индекс для поиска по смыслу; справочно, в Cadence поиск идёт по словам |
| `themes/` | три темы с общим контрактом токенов |
| `docs/` | понятия движка, справочник атрибутов и правил проверки, гайды по приёмам, примеры запросов |
| `guides/` | справки по работе (ниже); их файлы лежат в `kits/<имя>/` |

## Ограничения

- Модуль только знания и заготовки (`status: docs`): рендерит ролик движок `engine/`.
- Справки и описания блоков по-английски; команды движка из них запускать через `engine/`, облачные,
  авторизационные и опубликующие команды в справки не вошли.
- У части блоков (карусели) картинки в исходном реестре лежали на внешнем хранилище и не вошли:
  в `registry-item.json` у таких файлов стоит `"bundled": false`; подставить свои картинки в те же пути.
  У блока `blue-sweater-intro-video` не включён звуковой файл (больше 2 МБ).
- Блоки с моделью `macbook.glb` (по 2,4 МБ) повторяют один и тот же файл в трёх местах.
- Из набора звуковых эффектов взяты только файлы с разрешением на коммерческое использование,
  авторы в `kits/media-use/audio/assets/sfx/CREDITS.md`.
- Не перенесены: загрузка и публикация роликов, облачный рендер, голоса и аватары по подписке,
  презентации, импорт из дизайн-редакторов, шаблоны по подписке.
