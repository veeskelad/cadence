# Десять секунд мотиона в готовом стиле

**Когда брать:** человек хочет короткий ролик (10 с) «в стиле …» и ни трека, ни кадров у него нет:
плоская векторная графика, линия, изометрия, 3D, нарисованное от руки, коллаж, жидкость, баухаус,
синтвейв, стеклянные градиенты, цветной текст, пиксели, интерфейс как в кино. Модуль даёт пятнадцать
готовых образцов с кодом и звуком, из которых делается ролик про его тему.

**Что дать:** тему и текст ролика, стиль (номер или имя из таблицы ниже), по желанию свой трек.

**Команда:** `python3 modules/motion-graphics-presets/run.py <фильм> render --noaudio`

**Что получится:** `$WORK/<проект>/out/<фильм>.mp4` (1920×1080, 30 кадров/с, 10 с) и рабочая копия
фильма `$WORK/<проект>/mg/demos/<фильм>/`, которую можно переписывать под свою тему.

## Стили

Подсказки к стилям лежат в `prompts/<фильм>.md` (текст на английском и китайском, внутри полная подсказка
для создания ролика). Исходник каждого фильма: `demos/<фильм>/`.

| Фильм | Стиль | Формат | Особенности |
|---|---|---|---|
| `01-flat-vector` | плоская векторная графика, один дубль | 16:9, 30 | SVG |
| `02-line-art` | линия, один росчерк | 16:9, 30 | нужна текстура зерна (есть) |
| `03-isometric` | изометрия 2.5D, город растёт | 16:9, 30 | three.js |
| `04-3d-render` | 3D-рендер мягких форм | 16:9, 24 | нужен Blender (только код и подсказка) |
| `05-cel-boil` | покадровый рисунок, дрожащая линия | 16:9, 24 | бумага в комплекте |
| `06-collage` | бумажный коллаж, вырезки | 16:9, 30 | нужны свои картинки (только код и подсказка) |
| `07-liquid` | жидкость, капля | 16:9, 30 | WebGL, шейдеры |

`cues.json` рабочей копии переписывается, шрифт берётся с кириллицей (см. ограничения).

## Первый запуск

1. Зависимости (около 420 МБ: Node-пакеты и Python-библиотеки звука; сеть только на установку,
   нужно согласие человека): `python3 scripts/module_setup.py install motion-graphics-presets`.
   Проверка без сети: `python3 scripts/module_setup.py status motion-graphics-presets`.
2. Нужны `node`, `ffmpeg`, `python3` и браузер Chrome или Chromium. Если Chrome лежит не в обычном
   месте, путь задаётся переменной `MG_CHROME`.
3. Список фильмов: `python3 modules/motion-graphics-presets/run.py --films`. Фильм указывается номером
   (`05`), полным именем или уникальной частью имени (`cel`).

## Шаги

1. Выбрать стиль вместе с человеком: показать таблицу, прочитать подсказку `prompts/<фильм>.md`
   выбранного (там сказано, что составляет узнаваемость стиля, и этого не убирать).
2. Сделать рабочую копию: `run.py <фильм> init --project <имя>`. Править только её.
3. Переписать тему, текст и цвета в `index.html` и `cues.json` копии. Время событий задаёт `cues.json`:
   звук и картинка сверяются с ним.
4. Посмотреть кадры до полного рендера: `run.py <фильм> render --project <имя> --stills 0.5,3,6,9.5`
   (PNG в `out/stills/` рабочей копии). Показать человеку, поправить.
5. Отрендерить: `run.py <фильм> render --project <имя> --noaudio`. Полный рендер 10 с занимает
   минуты; по умолчанию один рабочий процесс, на слабом компьютере `--workers` не повышать.
6. Звук: либо свой трек через `--audio <файл>` и правила `cadence-sound`, либо дорожка фильма
   (`run.py <фильм> audio`, нужны Python-библиотеки и образцы инструментов, см. ниже), потом render без
   `--noaudio`: готовый `out/audio.wav` подхватывается сам.
7. Проверка перед показом: длина 10,000 с, громкость около −14 LUFS, нет чёрных кадров и застывших
   отрезков; готовый файл проверяет `scripts/check_reel.py`.
8. Отдать человеку путь к MP4 и исходник рабочей копии; промежуточные кадры и дорожки убрать.

## Команды

| Команда | Что делает |
|---|---|
| `run.py --films` | список фильмов |
| `run.py <фильм> init [--project <имя>]` | рабочая копия фильма в `$WORK/<проект>/mg/` |
| `run.py <фильм> render [--project <имя>] [аргументы]` | MP4 в `$WORK/<проект>/out/<фильм>.mp4` |
| `run.py <фильм> audio [--project <имя>]` | звуковая дорожка фильма в `out/audio.wav` рабочей копии |
| `run.py <фильм> samples --keys marimba,piano` | сеть: скачать образцы инструментов (с согласия) |

Аргументы `render`: `--stills 1,2.5` (PNG-кадры; значения через пробел, не через `=`), `--from 0 --to 4` (отрезок), `--scale 0.5` (быстрый
превью), `--w`, `--h`, `--fps`, `--mb 4` (размытие движения), `--workers N`, `--audio <файл>`, `--noaudio`,
`--crf 14`, `--mkv <файл>` (без потерь для монтажа).

## Ограничения

- Текстура бумаги `assets/textures/paper/Paper001_4K_color.jpg` пережата для размера (качество 72); по ней сделаны
  пластины бумаги в `05-cel-boil`, их исходные файлы лежат рядом с фильмом.
- Шрифты фильмов не поставляются (лицензии разные): браузер подставляет системные, и вид букв отличается
  от образцов, у китайских текстов могут быть пустые квадраты. Список нужных файлов — `assets/fonts/README.md`.
  Для русского текста брать шрифты с кириллицей из `engine/fonts/` Cadence и подключать в рабочей копии.
- Не рендерятся без недостающих файлов, которых в модуле нет по размеру (`run.py` скажет об этом сразу,
  а не будет ждать загрузки): `04-3d-render` собирается из кадров Blender (`demos/04-3d-render/README.md`:
  нужны Blender, файл `assets/hdri/studio_small_09_2k.hdr` и сетки букв из `blender/make_letters.py`);
  `06-collage`, `18-hanazi`, `19-paperclip` ждут картинки (вырезки, герои, наклейки), которые человек даёт
  свои или их генерируют. Код и подсказки этих четырёх остаются образцом; у остальных одиннадцати все файлы, на которые ссылается страница, на месте (кроме шрифтов).
- Звук: часть `audio.py` берёт записи инструментов (пианино, маримба, гонг и другие, открытая лицензия).
  Их нет в модуле; без них такие дорожки падают с понятной ошибкой. Выход: `run.py <фильм> samples
  --keys <инструменты>` (сеть, только с согласия, файлы идут в `$WORK/_cache/mg-samples`) или свой трек.
- Фильмы `04-3d-render`, `05-cel-boil`, `06-collage`, `08-morph`, `19-paperclip` содержат скрипты подготовки исходников (`tools/`, `work/`,
  `blender/`): им нужны библиотеки из `requirements-prep.txt`, они не ставятся по умолчанию.
- Рендер использует видеокарту через браузер; без неё идёт очень медленно. На слабом компьютере не
  запускать несколько рендеров сразу: модуль сам ограничивает число полных рендеров тремя.
- Модуль не публикует ролики и не вызывает облачных сервисов.
