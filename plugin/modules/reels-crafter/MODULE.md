# Рилс из своих кадров (reels-crafter)

**Когда брать:** есть папка своих клипов и фото и нужен готовый вертикальный рилс 1080x1920 с голосом,
субтитрами, эффектами, музыкой, обложкой и подписью. Или есть запись человека, который говорит в камеру,
и её надо собрать в короткое видео с субтитрами на каждое слово. Либо нужен сценарий и разбор готового
рилса глазами режиссёра.

**Что дать:** путь к клипам, свой голос (`vo/vo.mp3`) или тему для сценария, язык субтитров. Чужой сток
и чужие клипы не берём: только материал человека.

**Команда (от корня Cadence), создаёт папку рилса с шаблоном:**
`bash modules/reels-crafter/bin/reel new work/<проект>`
Дальше в этой инструкции `reel` значит `bash modules/reels-crafter/bin/reel`.

**Что получится:** `work/<проект>/out/reel.mp4`, `cover.jpg`, `caption.txt`, `qa_sheet.jpg` (кадры с
красными зонами интерфейса) и печатный отчёт проверок удержания. Исходные клипы не меняются.

Модуль в статусе beta: код проверен на синтаксис, полный прогон рендера после переноса не делался.

## 1. Подготовка и установка

1. `reel doctor`: показывает, что есть и чего не хватает, без сети.
2. Не готово: сказать человеку, что установка берёт около 400 МБ из сети (Python-пакеты, Playwright и
   three.js), и ставить только после согласия: `python3 scripts/module_setup.py install reels-crafter`.
3. Браузер для рендера кадров нужен установленный Chrome или Chromium: путь в `CHROME=/путь/к/браузеру`
   (для говорящей головы `CHROME_PATH`). Свой Chromium Playwright скачивается только с согласия.
4. Модель Whisper читается с диска. Скачать её можно только с `ALLOW_MODEL_DOWNLOAD=1` перед командой и
   после согласия человека (small около 0,5 ГБ).
5. Маски человека для `cover` и `orbit` считает macOS (Vision, нужен `swiftc`). Без macOS эти два эффекта
   недоступны, остальное работает.

## 2. Порядок работы над рилсом

1. Бриф одним сообщением: аккаунт и аудитория, язык, чего должен добиться рилс, длина, где кадры.
2. Сценарий: [guides/reel-script.md](guides/reel-script.md) (структуры, хуки, проверка фактов в
   [references/](references/structures.md)). Человек утверждает текст до записи голоса.
3. Кадры: [guides/footage-scout.md](guides/footage-scout.md). `reel sheet папка/* -o sheets/` даёт
   контактные листы, по ним выбираются места `ss` для каждого сегмента.
4. План и эффекты: [guides/reel-director.md](guides/reel-director.md). Выбрать 3–5 эффектов, каждый на
   своём ударе; каталог — [guides/effects.md](guides/effects.md).
5. Раскадровка до рендера: [guides/reel-storyboard.md](guides/reel-storyboard.md). Без «да» человека
   полный рендер не запускать.
6. Сборка: `reel build work/<проект> --stills` (минута: кадры, слова, субтитры, `qa_sheet.jpg`,
   проверки удержания из [guides/retention.md](guides/retention.md)), правки в `reel.json`, затем
   `reel build work/<проект>` (4–5 минут на 60 секунд). Поля `reel.json` — в
   [guides/reel-builder.md](guides/reel-builder.md).
7. Проверка глазами: кадры вокруг каждого эффекта и перехода (`reel stills work/<проект> 0.5,7.8`),
   громкость около -14 LUFS, текст вне красных зон.
8. Сдать: `out/reel.mp4`, `out/cover.jpg` (вырез 3:4 для сетки профиля), `out/caption.txt`.

## 3. Говорящая голова

Для видео, где человек говорит в камеру: очистка голоса, черновая таблица реплик и вырезание
слов-паразитов с согласия человека, затем отрисовка по списку правок: субтитры на каждое слово, смена
раскладок, карточки, увеличение на акценте. Шаги и формат `edit.json` — в
[guides/talking-head-edit.md](guides/talking-head-edit.md); команды `reel th lines|tighten|cut|qa|clean|transcribe|render`.

## 5. Ограничения

- Голос только свой: сервисов озвучки в модуле нет. Синтетический голос принимается как готовый файл от человека.
- Музыка: встроенная заготовка `synth` или файл, права на который есть у человека; на слух выбирает человек.
- Облачных монтажных сервисов в модуле нет; результат всегда обычный mp4.
- Не публиковать и не загружать ролик без отдельного решения человека.
- В кадре не должно быть чужих лиц, переписок, номеров машин и личных экранов без разрешения; кадры
  проверяются в полном размере.
- Фильтры слов-паразитов настроены на английский и украинский; для другого языка добавить свои слова в `talking-head/prep/common.py`.
