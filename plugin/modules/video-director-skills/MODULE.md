# Режиссура ролика: сценарий, план битов, графика кодом

**Когда брать.** Человек хочет придумать и собрать ролик по режиссёрскому плану: сценарий по битам, раскадровка графики под голос, субтитры, шаблонная графика и наезды камеры поверх говорящего видео, звук. Если нужна готовая форма ролика целиком без съёмки, берут `cadence-structures`; если только нарезка и субтитры, `cadence-cut`.

**Что дать.** Маршрут A: готовая нарезка 9:16. Маршрут B: готовая нарезка 16:9. Маршрут C: запись голоса, лица в кадре нет. Только сценарий: идея, заметки или ссылка. Свои логотипы, скриншоты, музыку и звуки человек приносит сам: в модуле их нет.

**Команда** (от корня Cadence, `$WORK` даёт `scripts/cadence_paths.py`):

```bash
OUT_DIR="$WORK/<проект>/out" bash modules/video-director-skills/routes/video-edit/scripts/render.sh <нарезка.mp4>
```

**Что получится.** Превью, а после «да» человека финальный MP4 в `$WORK/<проект>/out/`. Исходник не меняется. Промежуточные файлы лежат в `~/.cache/video-edit/<имя>_<хеш>/`, там же собранный проект движка `hf-project/`.

**Чем рендерится.** Графика маршрутов написана на React и рендерится общим движком Cadence (HyperFrames, `engine/`). `hyperframes/build.mjs` собирает маршрут в проект движка: один бандл, статичные `<video>` для каждого клипа, локальные шрифты, список картинок для предзагрузки. Время в композициях считается от номера кадра (`hyperframes/frame.tsx`), без библиотек анимации.

## 1. Выбор маршрута

| Что делаем | Маршрут | Папка | Справка |
|---|---|---|---|
| говорящая голова 9:16 | A | `routes/video-edit` | `guides/video-edit.md` |
| длинное видео 16:9 или вступление до 30 с | B | `routes/video-edit-longform` | `guides/video-edit-longform.md` |
| ролик без лица, голос за кадром | C | `routes/motion-design-edit` | `guides/motion-design-edit.md` |
| только сценарий | D | нет кода | `guides/reel-script.md` |

Не угадывать маршрут: спросить человека, что делаем, и открыть `guides/make-video.md`. Три маршрута идут из одного исходного набора и различаются графикой и скриптами, поэтому папки `routes/*/scripts` похожи, но не совпадают: брать скрипты того маршрута, который выбран.

## 2. Установка (с согласия человека)

Установка идёт через сеть и занимает около 2,7 ГБ, почти всё это WhisperX с torch. Пакеты композиций (React, esbuild, шрифты @fontsource) весят около 30 МБ. Спросить человека до установки. Движок Cadence общий для всех модулей: `python3 scripts/engine_setup.py status` должен дать `ready`.

```bash
python3 scripts/module_setup.py status video-director-skills      # без сети
python3 scripts/module_setup.py install video-director-skills     # с согласия
```

Пакеты композиций ставятся один раз в `hyperframes/` и служат всем трём маршрутам, подробности в `guides/setup.md`. Интерпретатор модуля передаётся скриптам через `VIDEO_DIRECTOR_PYTHON` (его печатает `python3 scripts/module_setup.py python video-director-skills`).

## 3. Порядок работы

1. Прочитать `guides/motion-style.md` до плана битов и кода анимации.
2. Один раз настроить бренд (цвета, шрифты): `guides/setup.md`, раздел про бренд. Пока бренда нет, рендерится пример-пресет.
3. Расшифровка речи: `"$PY" routes/<маршрут>/scripts/transcribe.py <файл>` (локальный WhisperX), потом прочитать текст глазами и поправить `words.json`.
4. План битов `broll_plan.json` по справке маршрута, затем проверка `scripts/lint_plan.py` того же маршрута.
5. Превью, правки до одобрения. Финал только после явного «да»: `QUALITY=final`.
6. Всегда абсолютный `OUT_DIR`, иначе результат ляжет рядом с исходником.

Полный порядок для одного ролика: `guides/execution.md`.

## 4. Ограничения

- Сеть в работе выключена. Шаг `polish_transcript.py` (внешний сервис) включается только `POLISH_TRANSCRIPT=1` и ключом `ANTHROPIC_API_KEY`; без них он не запускается. Модель вырезки говорящего (`rembg`) скачивается при первом использовании.
- Скачивание стоковых кадров, скриншотов и генерация картинок из справок выполняются только с согласия человека; сами скрипты ничего не качают.
- Музыки и звуков нет: класть свои в `routes/video-edit/music/` и `assets/sfx/` (имена файлов описаны в `guides/setup.md`). Без них ролик собирается без музыкальной подложки.
- Бренд-токены лежат в файлах `routes/*/hyperframes/src/...` (`hfBrand.ts`, `tokens.ts`, `paperBrand.ts`); менять их только по просьбе человека.
- Рендер тяжёлый: одновременно один (скрипт держит замок, движок тоже ждёт чужой рендер). По умолчанию один воркер Chrome; `RENDER_WORKERS=2` быстрее, но тяжелее для машины.
- Вырезки, транскрипция по словам и слежение камеры требуют установленных пакетов; без них скрипты предупреждают и откатываются на статичный наезд.
- Маршрут «без лица, 16:9» в исходном наборе не реализован.

## 5. Справка

- `guides/make-video.md`: выбор маршрута и порядок.
- `guides/reel-script.md`: сценарий по шести формам рассказа.
- `guides/video-edit.md`, `guides/video-edit-longform.md`, `guides/motion-design-edit.md`: правила маршрутов и виды графики.
- `guides/motion-style.md`: постоянная система движения и вида.
- Все шаблоны сразу, без исходного видео (из папки модуля): `node hyperframes/build.mjs routes/video-edit/hyperframes --composition StyleShowcase --out /tmp/showcase`, затем `npm --prefix <cadence>/engine run snapshot -- /tmp/showcase --at 5,20,40`. Другие превью: `StyleShowcaseLandscape`, `DarkGridFrame`, `LightGridFrame`, у маршрута B ещё `CinematicDemo` и `OverlayDemo`, у маршрута C `PrShowcase`.
- `guides/execution.md`, `guides/setup.md`: порядок работы и установка.
- Знания маршрутов (правила монтажа, библиотека шаблонов, неприкосновенные правила): `routes/*/knowledge/*.md`; законы графики и режиссёр графики для маршрута B: `routes/video-edit-longform/motion/`.
