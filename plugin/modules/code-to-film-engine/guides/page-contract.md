# Страница фильма: что она обязана делать

Когда: ты пишешь или правишь свою страницу фильма (папка с `index.html`), которую рендерит `run.py`. Здесь только то,
что проверяет код рендерера; описание стилей в модуль не входит, образцы читаются как код.

## Что должна выставить страница

| Имя в `window` | Что | Кто читает |
|---|---|---|
| `READY` | `true`, когда загружены шрифты и картинки и первый кадр можно рисовать. До этого рендерер ждёт до 180 секунд, через 20 секунд печатает подсказку | все инструменты |
| `DUR` | длина фильма в секундах, число больше нуля | `video`, `events`, `readcheck` |
| `render(t)` | рисует кадр для времени `t` (секунды) и возвращается, когда кадр готов. Результат зависит только от `t`: никакого накопленного состояния, счётчиков и `Math.random()` (для случайного бери `hash`/`mulberry` из `core/lib.js`) | `video`, `still` |
| `EV` | по желанию: список звуковых событий; его форму выбирает страница, `events` просто сохраняет список | `events` |
| `TEXTS(t)` | по желанию: все тексты в кадре в момент `t`: `[{id, text, x0, y0, x1, y1}]` | `readcheck` |

Размер кадра по умолчанию 1920×1080, меняется `--size WxH` (оба числа чётные, от 16 до 8192, например `1080x1920`
для вертикали). Скорость кадров по умолчанию 24 (`--fps`).

## Как страница подключает общее

- Адреса абсолютные от корня модуля: `/core/lib.js`, `/core/fonts/fonts.css`, `/node_modules/three/build/three.module.js`.
  Сама папка фильма лежит под адресом `/@film/`, свои файлы подключаются относительно страницы (`./film.js`).
- Сервер слушает только `127.0.0.1`, файлы вне корня модуля и вне папки фильма не отдаёт.
- Ошибка скрипта или 404 на скрипт останавливает рендер сразу. 404 на картинку, шрифт или данные только предупреждение:
  страница обязана сама справиться без них. Шрифт, которого нет, значит текст другим шрифтом: рендерер называет файл.
- WebGL: если контекст потерян (виртуальная видеокарта, больше 16 холстов), рендер падает, а не отдаёт чёрные кадры.
  Запасной вариант: переменная `LEMO_ANGLE=swiftshader` (программный рендер, медленнее). На macOS по умолчанию
  `metal`; свой браузер — `PLAYWRIGHT_CHROME=<путь>`.

## Что делает каждый инструмент

| Действие `run.py` | Что делает | Куда пишет |
|---|---|---|
| `still t1 t2 ...` (`--range a:b:шаг`, `--q ключ=значение`, `--prefix`) | кадры JPEG на выбранные моменты | `$WORK/<проект>/out/stills/` |
| `video` (`--fps`, `--workers`, `--q`, `--size`) | кадр за кадром в MP4 без звука; каждый процесс браузера снимает свой отрезок, потом отрезки склеиваются без перекодирования | `$WORK/<проект>/out/video.mp4` |
| `events` (`--q`) | пишет `{dur, ev}` из `window.DUR` и `window.EV` | `$WORK/<проект>/out/events.json` |
| `readcheck` (`--step`, `--latin-cps`, `--cjk-cps`, `--pad`, `--min`) | проверяет, что каждый текст в кадре держится дольше времени чтения: символы ÷ скорость чтения плюс запас; код выхода 0 успех, 1 есть нарушения, 2 проверку не удалось сделать | консоль |

`--q 'a=1&b=2'` передаёт странице параметры адреса (ими страница выбирает вариант: без субтитров, другая версия текста).
Два рендера в один `--out` не пускаются: рядом лежит `.lock`, устаревший замок снимается сам.
`--workers` по умолчанию 3, один рендер на свободной машине выдерживает до 6; на слабом компьютере ставь 1–2.
Переменная `RENDER_SLOTS=<число>` ограничивает число одновременных полных рендеров на машине.

## После рендера (запускаются напрямую из корня Cadence)

- Звук и громкость: `sh modules/code-to-film-engine/core/render/mux.sh <video.mp4> <mix.wav> <out.mp4> [fps] [зерно]`.
  Нужен ffmpeg версии 7 и новее. Двойной проход `loudnorm` на −14 LUFS, истинный пик не выше −1 dBTP, потом проверка
  замеров; зерно 2 по умолчанию, 0 для пикселей и векторной графики. Файл пишется сначала во временный и переименовывается.
  Саунд-дизайн и баланс громкостей по правилам навыка `cadence-sound`.
- Субтитры: `python3 modules/code-to-film-engine/core/render/srt.py <cues.json> <out.srt>`, где
  `cues.json` = `[{"t0": 1.2, "t1": 3.4, "text": "..."}]`.
- Контактный лист: `python3 modules/code-to-film-engine/core/render/sheet.py <out.jpg> <кадр1> <кадр2> ... [--cols 4] [--w 480]`.

## Общий код (`core/`)

- `core/lib.js`: плавность и кривые (`clamp`, `lerp`, `seg`, `ss`, `eio`, `eo`, `ei`, `back`, `spring`), детерминированный
  шум (`mulberry`, `hash`, `vnoise`), `monotone` и `track` для интерполяции по ключам, `env` для входа и выхода.
- `core/post/crt.js`: ЭЛТ и плёночные видеоэффекты (WebGL2): свечение, сдвиг цвета, строки развёртки, включение.
- `core/three/post.js`: постобработка сцены three.js (глубина резкости, свечение, обработка тона).
- `core/fonts/`: несколько шрифтов в woff2 с лицензией OFL (`fonts.css`, `OFL.md`); кириллица в них не гарантирована, для
  русского текста брать `engine/fonts/` Cadence.
- `core/audio/`: процедурные звуки `sfx.py`, струнные `pluck.py` (нужен набор `requirements-music.txt`), сэмплер `sampler.py`
  (библиотеки образцов в модуль не входят). Импорт: `PYTHONPATH=modules/code-to-film-engine python3 -c "from core.audio import sfx"`.
- `core/tts/`: `tts.py` (офлайн-голос, модель нужно положить рядом вручную) и `asr_check.py` (сверка речи по словам
  через Whisper; при первом запуске качает модель, это сеть). Оба в голосовом наборе, по умолчанию не поставлены.
