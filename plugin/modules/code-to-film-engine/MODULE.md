# Фильм кодом в одном из 56 стилей

**Когда брать:** человек хочет фильм-объяснение или мини-кино на одну-несколько минут, целиком нарисованный
кодом, в узнаваемом стиле (школьная доска, чертёж, пиксельная игра, гравюра, интерфейс, бумажная вырезка).
Это общий рендерер страниц и 56 готовых образцов, на которых можно учиться и от которых отталкиваться.
Ролик на десять секунд по готовому стилю быстрее взять в `motion-graphics-presets`; ролик в бит под трек
в движке Cadence (`engine/`).

**Что дать:** идею, текст или сценарий, выбранный образец, по желанию голос и музыку.

**Команда:** `python3 modules/code-to-film-engine/run.py <проект> video`

**Что получится:** `$WORK/<проект>/out/video.mp4` (кадр 1920×1080, 24 кадра/с, без звука), рядом
кадры для проверки (`still`), события для звука (`events`) и отчёт о читаемости текста (`readcheck`).

## Первый запуск

1. Зависимости: `python3 scripts/module_setup.py install code-to-film-engine` (около 380 МБ вместе с
   браузером для рендера; сеть только на установку, нужно согласие человека). Проверка без сети:
   `python3 scripts/module_setup.py status code-to-film-engine`.
2. Браузер для рендера (отдельный шаг, сеть, с согласия): из папки модуля
   `node node_modules/playwright-core/cli.js install chromium-headless-shell`. Либо свой браузер:
   `PLAYWRIGHT_CHROME=<путь к chrome-headless-shell>`.
3. Нужны `node`, `ffmpeg` (для сведения звука версии 7 и новее) и `python3`.
4. Список образцов: `python3 modules/code-to-film-engine/run.py --styles`.

## Шаги

1. Выбрать образец вместе с человеком: показать группы из таблицы ниже и список `--styles` (там название
   и о чём пример). Образец читается как код: `styles/<стиль>/demo/` (страница, сцены, сборка).
2. Копия для работы: `run.py <проект> init <стиль>`. Это `$WORK/<проект>/film/`, править только её.
3. Переписать тему, текст и цвета под идею человека. Страница обязана выставить `READY`, `DUR` и
   `render(t)`: правила в [guides/page-contract.md](guides/page-contract.md). Образец стиля шаблоном
   не считать: сюжет, тексты и знак брать из идеи человека.
4. Посмотреть кадры до полного рендера: `run.py <проект> still 1 5 12 30`, открыть JPEG и править.
5. Проверить текст: `run.py <проект> readcheck`. Нарушения (текст исчезает раньше, чем его прочтёшь)
   исправляются удлинением показа, не ускорением чтения.
6. Отрендерить: `run.py <проект> video --workers 2`. Длинный фильм идёт десятки минут: оценить по
   первым кадрам журнала и сказать человеку.
7. Звук: события `run.py <проект> events`, дорожку собрать правилами `cadence-sound` (либо `core/audio/`
   модуля), потом свести с картинкой `core/render/mux.sh` (команды в справке).
8. Передать человеку MP4 и путь к исходнику `film/`. Не нужные кадры и промежуточные файлы убрать.

## Команды

Все команды: `python3 modules/code-to-film-engine/run.py <проект> <действие> [аргументы]`.

| Действие | Что делает |
|---|---|
| `init <стиль>` | копия страницы-образца в `$WORK/<проект>/film/` |
| `still 0.5 3 8` | кадры JPEG в `$WORK/<проект>/out/stills/` (`--range a:b:шаг`) |
| `video` | MP4 в `$WORK/<проект>/out/video.mp4` (`--fps`, `--workers`, `--size 1080x1920` для вертикали) |
| `events` | события звука страницы в `out/events.json` |
| `readcheck` | проверка времени чтения текста |
| `--style <стиль> <проект> video` | образец прямо из модуля, без копии |

## Образцы

В исходном наборе 99 образцов, в модуль вошли 56: те, чей код небольшой и не требует ни
съёмочного материала, ни картинок и сеток, которых в модуле нет. Подробности каждого стиля (название,
о чём пример, длина) в `styles/index.json`.

| Группа | Образцы |
|---|---|
| 3D и миниатюра | `crayon-world`, `glass-product`, `isometric-picture-book`, `lowpoly-island`, `memphis-diorama` |
| Мультфильм | `cel-anime-80s`, `midcentury-toon`, `rubber-hose`, `scifi-toon` |
| Данные и карты | `dataviz`, `pip-simulation`, `transit-map` |
| Плёнка и лента | `ascii-crt`, `scratch-film` |
| Игры | `hd-2d`, `pixel-rpg` |
| Графика и шрифт | `art-deco`, `bauhaus-shapes`, `pictogram-motion`, `silhouette-rhythm`, `swiss-motion` |
| Приборы и улики | `dark-documentary`, `microscope`, `security-xray`, `thermal-camera` |
| Свет и линии | `circuit-board`, `firefly-pointillism`, `oscilloscope-math` |
| Линейные схемы | `assembly-line-diagram`, `blueprint`, `iso-infographic`, `pen-plotter`, `precise-mechanism` |
| Живопись и иллюстрация | `colored-pencil`, `crayon-book`, `impasto` |
| Печать и гравюра | `engraving`, `pop-art`, `printed-long-take`, `silkscreen-poster` |
| Экраны и интерфейсы | `desktop-flythrough`, `one-bit-dither`, `spreadsheet` |
| Эскиз и доска | `chalkboard`, `ipad-sketch`, `marker-paper`, `sketchnote`, `stick-explainer`, `whiteboard` |
| Традиционные ремёсла | `gilded-illumination`, `ink-wash`, `paper-lantern`, `papercut-red`, `shadow-puppet`, `stained-glass`, `ukiyoe` |

Два образца, `firefly-pointillism` и `oscilloscope-math`, рисует Python (`demo/film.py`), а не страница: через `run.py` они не рендерятся, их `demo/build.sh` и `demo/film.py` читаются как пример другого подхода. В остальных 54 образцах: `demo/index.html` (страница), скрипты сцен, данные, `demo/build.sh`, `demo/CREDITS` (источники и подпись).
`build.sh` показывает порядок, в каком собирался исходный фильм (голос, музыка, сведение, рендер). Это справка,
а не команда для запуска: она ссылается на инструменты, которых в модуле нет (скачивание шрифтов и образцов
звука, облачный голос).

## Необязательные наборы

Не ставятся по умолчанию; ставятся вручную и только с согласия человека.

- Голос: `requirements-voice.txt` (`core/tts/tts.py`, офлайн-голос; файлы модели kokoro нужно положить в
  `core/tts/` самому, около 350 МБ; `core/tts/asr_check.py` сверяет озвучку по словам и при первом запуске
  скачивает модель Whisper). Для готовой озвучки в Cadence есть `cadence-sound`.
- Струнные и образцы: `requirements-music.txt` (`core/audio/pluck.py`); библиотеки образцов
  `core/audio/sampler.py` в модуль не входят, автоскачивание выключено (`LEMO_FETCH=1` включает его, только
  с согласия).

## Ограничения

- Шрифтов образцов в модуле нет (в `core/fonts/` несколько шрифтов с лицензией OFL, кириллица не гарантирована):
  рендерер называет недостающий файл и подставляет другой. Для русского текста взять шрифты из `engine/fonts/` Cadence.
- Образцы не включают озвучку, музыку и картинки больше 300 КБ. Страницы, которым нужна картинка из внешнего
  источника, в модуль не вошли. Образцы без этих файлов рисуются кодом сами, но для готового ролика звук нужно
  делать отдельно.
- В нескольких образцах на финальной карточке стоит подпись исходного набора (искать слово `Opus` в
  `styles/*/demo`; подпись есть и в файлах `CREDITS`, их оставлять как есть); перед показом своего ролика заменить её подписью человека или убрать.
- Один рендер занимает процессор и видеокарту; несколько рендеров подряд, а не вместе. WebGL-образцам нужна
  видеокарта, на виртуальной машине см. `LEMO_ANGLE=swiftshader` в справке.
- Это бета: рендер самих образцов в рамках переноса не прогонялся (нет установки зависимостей).

## Справка

- [guides/page-contract.md](guides/page-contract.md): что обязана делать страница фильма, что делает каждый
  инструмент, как свести звук, сделать субтитры и контактный лист, что лежит в `core/`.
- `REUSE.toml`: перечень лицензий файлов исходного набора (код под MIT, документы и картинки под другими).
  Документы исходного набора (описания стилей и руководства) распространяются на других условиях, чем код,
  поэтому в модуль не включены; текст этого модуля написан заново по коду.
